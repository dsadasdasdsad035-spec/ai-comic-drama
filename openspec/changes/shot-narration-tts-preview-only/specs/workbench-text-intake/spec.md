## MODIFIED Requirements

### Requirement: 台词列分离台词、旁白与音效

台词/声音列 MUST 区分三类内容：带说话人的台词、旁白、以及音效/音乐等非语言声。角色台词与旁白 MUST 均进入镜头 `dialogue`（结构化数组或等价存储）；音效与音乐 MUST NOT 进入 `dialogue`，MUST 被保留为声音说明。旁白 MUST 标记为非角色说话人，MUST NOT 被当作出场角色，MUST NOT 仅写入画面描述以替代台词。同一单元格里混排的多段内容 MUST 被拆成多条。单元格内的 `<br>`、`<br/>` 与 `<br />` MUST 先归一化为换行再切分，使被 Markdown 表格挤成一行的多段台词能恢复原有分段。

#### Scenario: 旁白

- **WHEN** 台词列为「旁白：那天晚上，我以为自己活不过去了。」
- **THEN** 生成一条说话人为旁白的台词写入该镜 `dialogue`，且该镜出场角色不含旁白

#### Scenario: 纯音效

- **WHEN** 台词列为「雨声、远处车声。」
- **THEN** 该镜不产生台词，这段文字作为声音说明保留

#### Scenario: 混合内容

- **WHEN** 台词列为「脚步声停止。人类轻声：小家伙，你怎么在这里？」
- **THEN** 拆成一条声音说明与一条说话人为人类的台词

#### Scenario: 音乐提示

- **WHEN** 台词列为「音乐由紧张转柔和」
- **THEN** 不产生台词，作为声音说明保留

#### Scenario: 单元格用 br 分隔多段台词

- **WHEN** 台词列为「陈默：又是这里。<br>林小雨：你认得这条路？」
- **THEN** 拆成两条台词，说话人分别为陈默与林小雨，不被合并成一条

#### Scenario: br 写法变体

- **WHEN** 台词列同时出现 `<br>` 与 `<br />` 两种写法
- **THEN** 两者都被当作换行处理，分段结果一致

#### Scenario: 旁白与对白同格

- **WHEN** 台词列为「旁白：三年前的那个冬夜。<br>陈默：你终于来了。」
- **THEN** `dialogue` 含旁白与角色各一条，旁白不进 `cast`
