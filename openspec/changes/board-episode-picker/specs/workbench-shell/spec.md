# Spec Delta

## MODIFIED Requirements

### Requirement: 项目与集只出现一次

项目 MUST 在全局带只出现一次。集号在角色、素材等视图仍由全局带 `EpPicker` 提供；在画布集目录阶段全局带不显示 `EpPicker`；在画布单集阶段当前集号在画布上下文带展示一次，换集通过「返回集列表」完成。其他区域 MUST NOT 重复项目名或集号充当第二套换集入口；聊天面板头部 MUST NOT 重复集号。

#### Scenario: 单一项目入口

- **WHEN** 用户依次打开全部视图
- **THEN** 每个视图只有一个项目选择器，且没有第二处项目名文本

#### Scenario: 单一集入口

- **WHEN** 用户在角色或素材视图查看当前集
- **THEN** 集号只由全局带的集选择器显示，聊天面板头部不再重复集号

#### Scenario: 角色素材仍用全局集选择器

- **WHEN** 用户在角色或素材视图
- **THEN** 全局带仍显示集选择器，且行为与变更前一致

#### Scenario: 画布目录无顶栏换集

- **WHEN** 用户在画布集目录屏
- **THEN** 全局带不显示集下拉，也不在其他区域重复项目集号充当换集入口

#### Scenario: 画布单集上下文显示集号

- **WHEN** 用户在画布单集模式编辑 `E02`
- **THEN** 用户能在上下文带或工具条看到当前为 `E02`，并有一键返回集列表
