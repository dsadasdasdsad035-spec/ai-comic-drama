# Spec Delta

## Purpose

让画布「连播」成为可听、可看、可定位时间的成片预览，而不是只按镜头推进的视觉 animatic。

## ADDED Requirements

### Requirement: 连续播放头

连播 SHALL 维护一个基于剪辑序列的连续播放头，用实际已播放时间而不是当前镜头结束点显示进度；播放头 MUST 驱动当前画面、TTS/native 音频和字幕 cue。用户 MUST 能在当前镜头内 seek，并能点击任一分段跳到该段的可见起点；有入场效果转场时跳过重叠，直接显示该段。

#### Scenario: 镜头内时间连续
- **WHEN** 一个 5 秒静帧镜头播放到第 2.4 秒
- **THEN** 头部显示当前序列时间（含前序镜头与接缝），而不是直接显示 5 秒

#### Scenario: 镜头内 seek
- **WHEN** 用户拖动当前镜头进度或点击当前段的不同位置
- **THEN** 画面、音频和字幕一起跳到对应时间并继续播放

#### Scenario: 分段跳转
- **WHEN** 用户点击底部某个镜头或转场分段
- **THEN** 播放头跳到该段可见起点；有入场转场时跳过重叠，当前段时间和字幕状态同步更新

### Requirement: TTS 与 native 音频播放

有 `voiceUrl` 的镜头 MUST 播放 TTS 音频，并按 `voiceOffset` 对齐；native 镜头 MUST 使用视频自带音轨。播放、暂停、seek 和静音 MUST 同步作用于音频；音频 MUST 在当前段离开后停止，不能继续盖住后续镜头。

#### Scenario: TTS 镜头出声
- **WHEN** 连播进入一个有 TTS 配音且有台词的镜头
- **THEN** 能听到该镜配音，且从 `voiceOffset` 指定的位置开始

#### Scenario: native 镜头出声
- **WHEN** 连播进入 `audioMode=native` 的视频镜头
- **THEN** 使用视频音轨，不额外播放该镜 TTS

#### Scenario: 暂停与 seek
- **WHEN** 用户暂停或拖动播放头
- **THEN** TTS/native 音频同步暂停或跳到对应时间

#### Scenario: 静音
- **WHEN** 用户点击静音或调整音量
- **THEN** 所有镜头音频遵循该设置，画面和字幕继续

### Requirement: 转场期间的音频调度

当后一段的时间线起点落在前一段的转场重叠区内时，后一段音频 MUST 从自己的时间线起点开始，而不是等画面切换完成；前一段音频 MAY 继续到自己的段末。预览的音频起止 MUST 与导出使用相同的段起点。

#### Scenario: 效果转场重叠
- **WHEN** 两个镜头用 0.5 秒叠化，后一段的起点是前一段结束前 0.5 秒
- **THEN** 后一段 TTS 在叠化开始时进入，前一段音频可继续到自己的段末

#### Scenario: 没有配音的转场
- **WHEN** 生成转场片段没有台词
- **THEN** 不产生额外对白音频，只有前后镜头的音频按各自起点参与

### Requirement: 播放控制与全屏

连播 MUST 提供播放/暂停、上一镜/下一镜、当前镜头内 seek、静音/音量和全屏；空格、左右方向键 MUST 可用。全屏时 Esc 先退出全屏，不全屏时 Esc 关闭连播。点击画面 MUST 继续切换播放/暂停。

#### Scenario: 键盘控制
- **WHEN** 连播打开且焦点在播放器内，用户按空格或左右方向键
- **THEN** 播放/暂停或切换镜头生效，画布快捷键不被触发

#### Scenario: 全屏
- **WHEN** 用户点击全屏
- **THEN** 播放器进入全屏；Esc 退出全屏后仍停留在连播

### Requirement: 播放状态呈现

连播头部 MUST 显示当前段、当前时间和总时长、音轨来源（TTS / native / 无配音）、画面类型（视频 / 静帧）和字幕开关状态。没有配音、没有画面、转场需重生成等状态 MUST 显式显示，不能只用静音表现。

#### Scenario: TTS 状态
- **WHEN** 当前镜头有 TTS 配音
- **THEN** 头部显示 TTS 和配音时长

#### Scenario: 无配音
- **WHEN** 当前镜头既没有 TTS 也没有 native 音轨
- **THEN** 头部明确显示「无配音」，而不是让用户以为播放器坏了

#### Scenario: 静帧
- **WHEN** 当前镜头只有图片
- **THEN** 头部显示「静帧」，播放头仍按镜头时长推进

### Requirement: 导出控制与播放控制分区

导出分辨率、烧录字幕开关、导出/下载 MUST 与播放控制分区展示，不得与播放/暂停/seek 混在同一行主控制区。导出运行中 MUST 显示进行中和已用时间；导出完成后 MUST 保留成片和 SRT 入口。

#### Scenario: 分区展示
- **WHEN** 用户打开连播
- **THEN** 播放控制在一行，导出设置和导出按钮在独立区域

#### Scenario: 导出状态
- **WHEN** 用户点击导出成片
- **THEN** 显示合成中状态和已用时间，完成后出现下载入口

### Requirement: 下一段预加载与缺失媒体

连播 MUST 在进入下一段前预加载其图片或视频，避免转场开始才挂载造成空白；媒体加载失败或缺失时 MUST 在画面上显示明确状态。

#### Scenario: 预加载
- **WHEN** 当前段还剩不到一个转场时长
- **THEN** 下一段的图片或视频已经开始加载

#### Scenario: 缺失媒体
- **WHEN** 当前段没有图片也没有视频
- **THEN** 画面显示「这一镜还没有画面」，时间与音频行为仍可继续

### Requirement: 模态无障碍

连播 MUST 以模态对话框呈现，具备可读标题、焦点陷阱、打开时聚焦播放器、关闭时把焦点还给触发按钮；所有播放控制 MUST 有可读标签。字幕 overlay MUST 不抢焦点。

#### Scenario: 打开与关闭
- **WHEN** 用户打开连播再按 Esc 关闭
- **THEN** 焦点回到打开连播的按钮

#### Scenario: Tab 循环
- **WHEN** 用户在连播内连续按 Tab
- **THEN** 焦点只在播放器控件内循环，不跑到画布

### Requirement: 播放顺序只由镜号决定

连播、时间线和导出 MUST 在同一集内按镜号自然排序；`project.json` 的 shots 数组顺序和画面轨拖动 MUST NOT 改变播放顺序。要换序 MUST 修改镜号。

#### Scenario: 项目数组乱序
- **WHEN** 项目的 shots 数组顺序是 S02、S01
- **THEN** 连播仍按 S01、S02 播放，时间线和导出也使用同一顺序

#### Scenario: 拖动画面块
- **WHEN** 用户在时间线左右拖动画面块
- **THEN** 只选中/查看该镜，播放顺序和镜号都保持不变

### Requirement: 不改变剪辑序列与项目数据

连播的播放头、seek、跳段和音频调度 MUST 使用与导出一致的 `buildEditList` 序列；预览操作 MUST NOT 修改镜头顺序、接缝或项目数据。

#### Scenario: 跳段不换序
- **WHEN** 用户在连播里点击任意分段
- **THEN** 镜头顺序、画布节点和 project.json 都不变

#### Scenario: 预览与导出一致
- **WHEN** 同一项目分别连播和导出
- **THEN** 段顺序、效果转场和生成转场位置一致
