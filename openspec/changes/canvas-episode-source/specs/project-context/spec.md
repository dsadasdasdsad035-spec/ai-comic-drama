# Spec Delta

## MODIFIED Requirements

### Requirement: 画布状态按项目隔离

系统 SHALL 按项目保存和加载画布的镜头节点、连线、素材卡和布局；切换项目 MUST 加载目标项目的画布，MUST NOT 把上一项目的节点同步到目标项目。画布 UI 中的**当前集**（`epNo`）MUST 作为该项目画布存档的一部分写入与读出，MUST NOT 依赖无项目键的全局画布存档作为真源。

#### Scenario: 两个项目各自有画布

- **WHEN** 项目 A 和 B 都有镜头
- **THEN** 切到 A 时画布只显示 A 的节点，切到 B 时只显示 B 的节点

#### Scenario: 项目镜头进入画布

- **WHEN** 用户在当前项目的画布导入分镜，或 Agent 写回本集镜头
- **THEN** 这些节点带该项目的 `shotId`，参与该项目画布的状态和同步

#### Scenario: 编辑不跨项目

- **WHEN** 在 B 的画布上移动、删除或新增节点
- **THEN** A 的画布状态和镜头数据保持不变

#### Scenario: 没有项目时不写画布

- **WHEN** 未选择项目时打开画布
- **THEN** 系统不把演示节点或旧画布写入任何项目

#### Scenario: 各项目记住自己的当前集

- **WHEN** 用户在项目 A 停在集 3、在项目 B 停在集 1，分别切换并返回
- **THEN** 再次打开 A 时当前集为 3，打开 B 时为 1，互不覆盖
