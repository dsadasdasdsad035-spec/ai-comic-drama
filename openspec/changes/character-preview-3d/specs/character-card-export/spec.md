# Spec Delta

## Purpose

让角色卡可以脱离应用被单独交付：导出一个双击即可打开、断网也能完整展示角色造型、表情、音色与文案的静态文件。

## ADDED Requirements

### Requirement: 从预览导出单文件 HTML

预览 MUST 提供导出入口，导出的结果 MUST 是一个自包含的 HTML 文件，文件名 MUST 包含角色名与该角色的来源标识。导出 MUST 只在用户显式点击后执行，MUST NOT 触发生成或计费。

#### Scenario: 导出成功
- **WHEN** 用户在预览页点击导出并选择保存位置
- **THEN** 得到一个以角色名命名的 .html 文件，双击后在浏览器中完整显示该角色预览

#### Scenario: 不触发生成
- **WHEN** 用户导出预览
- **THEN** 不产生任何生图或语音合成请求，角色数据不被修改

#### Scenario: 未保存角色也能导出
- **WHEN** 角色有可展示的图片但尚未生成试音
- **THEN** 导出成功，文件中的音色区域只显示文字信息，不出现破损播放器

### Requirement: 导出文件离线可用

导出文件 MUST 在无网络、无应用、无服务端的条件下完整可用。图片与音频 MUST 内联进文件，MUST NOT 依赖站内相对路径、外部 CDN、远程字体或任何第三方脚本。

#### Scenario: 断网打开
- **WHEN** 用户在关闭服务端并断网的机器上打开导出文件
- **THEN** 造型、转盘、表情、文案与试音全部正常显示和播放

#### Scenario: 拷到另一台机器
- **WHEN** 用户只把这个 .html 文件拷到没有该项目的机器上打开
- **THEN** 内容完整，不出现空图或加载失败提示

#### Scenario: 不发起外部请求
- **WHEN** 在浏览器开发者工具中观察导出文件的网络请求
- **THEN** 除文件自身外没有任何外部请求

### Requirement: 导出前压缩并提示体积

导出 MUST 把图片转为 WebP 以控制体积。预估体积超过设定阈值时 MUST 在写文件之前提示实际大小，MUST 由用户确认后才继续；用户取消时 MUST NOT 产生文件。

#### Scenario: 常规体积
- **WHEN** 角色只有一个三视图与少量帧
- **THEN** 直接导出压缩后的文件，体积不因内联而失控

#### Scenario: 超阈值提示
- **WHEN** 预估体积超过设定阈值
- **THEN** 提示预估大小并等待确认，不静默写出超大文件

#### Scenario: 取消导出
- **WHEN** 用户在体积提示处取消
- **THEN** 不产生文件，也没有任何角色数据被修改

### Requirement: 导出范围只含当前角色

导出文件 MUST 只包含当前角色快照内的展示数据，MUST NOT 包含其他角色、项目绝对路径、设置内容、密钥或其他项目资产。快照中的资产引用 MUST 在导出时被替换为内联数据，文件中 MUST NOT 出现可反查本机目录的路径。

#### Scenario: 多角色项目
- **WHEN** 项目里有三个角色，用户导出其中一个
- **THEN** 文件里只有该角色的图片、文案与试音，其余两个角色完全不可见

#### Scenario: 不泄露本机路径
- **WHEN** 检查导出文件的源码
- **THEN** 不出现项目目录、用户名或其他本机绝对路径

### Requirement: 导出与页内预览同源渲染

导出的文件 MUST 由与应用内预览同一套渲染产出，两者在相同角色数据下 MUST 呈现一致的外观与交互，MUST NOT 维护第二套排版实现。

#### Scenario: 视觉一致
- **WHEN** 同一角色分别在应用内预览与导出文件中打开
- **THEN** 造型、文案、角度与播放行为一致，不出现两套布局

#### Scenario: 交互一致
- **WHEN** 在导出文件中拖动转盘或播放试音
- **THEN** 行为与应用内预览一致

### Requirement: 导出内容带版本与来源标识

导出文件 MUST 内嵌快照版本号、生成时间与角色身份指纹，并 MUST 在界面上可见地显示生成时间。当角色外观在此之后发生变化时，MUST 能据此判断文件已过期。

#### Scenario: 显示生成时间
- **WHEN** 用户打开导出文件
- **THEN** 可以看到该角色卡的生成时间

#### Scenario: 识别过期文件
- **WHEN** 角色外观锚点在导出后被修改
- **THEN** 文件中记录的身份指纹与当前角色不一致，据此可判定该文件需要重新导出

### Requirement: 导出文件对用户文本转义

导出 MUST 把角色名、身份、外观描述等用户文本安全地写入文档，MUST NOT 因文本内容破坏文档结构或执行脚本。导出文件 MUST NOT 执行任何来自角色数据的代码。

#### Scenario: 含特殊字符的文案
- **WHEN** 角色描述包含尖括号、引号或脚本片段
- **THEN** 导出文件正常显示这些字符的文本内容，不执行其中的脚本，页面结构不被破坏

#### Scenario: 含特殊字符的角色名
- **WHEN** 角色名包含斜杠、引号或表情符号
- **THEN** 导出文件名被安全处理，文件仍可正常保存与打开
