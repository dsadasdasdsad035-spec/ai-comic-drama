# Spec Delta

## MODIFIED Requirements

### Requirement: agent 工具集受控且最小化

运行时 SHALL 只向 agent 暴露受控工具：读取当前镜头上下文、提交场景代码、渲染试运行、抓取关键帧、视觉验收和结束。上下文工具 MUST 只返回显式附件清单与必需镜头元数据（镜号、时长、画幅），MUST NOT 自动附带未显式加入的文本、图片、媒体 brief、上次会话选择或其他镜头内容。工具 MUST NOT 提供任意 shell、文件写入、网络请求、跨镜头修改或自动保存/渲染能力，MUST NOT 提供 Blender 控制台、任意 Python 求值或对本机文件的直接读写。

#### Scenario: 允许的上下文读取

- **WHEN** agent 调用上下文工具
- **THEN** 只返回当前镜头的显式附件清单、必需元数据和当前代码摘要

#### Scenario: 未附加内容不出现

- **WHEN** 当前镜头有首帧、角色、台词和上次选择，但用户本次没有把某项加入附件
- **THEN** 上下文工具结果不包含该项

#### Scenario: 禁止越权

- **WHEN** agent 尝试修改其他镜头、访问网络或直接操作本机文件
- **THEN** 没有可用工具能完成该操作，请求被拒绝

#### Scenario: 不自动保存

- **WHEN** agent 完成代码和验收
- **THEN** 代码只作为草稿，保存仍需用户操作

#### Scenario: 不绕过渲染协议

- **WHEN** agent 需要看到场景画面
- **THEN** 只能通过固定渲染作业获取帧，不能自行启动进程或求值代码

### Requirement: 运行轨迹必须可审计

运行时 MUST 记录每次模型调用、本轮上下文清单（附件标识与数量、镜头元数据）、工具调用、工具结果、渲染作业标识、失败原因和修复次数，并通过可消费的事件流逐步提供给聊天 UI；MUST NOT 暴露模型隐藏推理或 chain-of-thought，只展示可观察动作、参数摘要、面向用户的简短说明和结果。

#### Scenario: 成功轨迹

- **WHEN** agent 完成场景
- **THEN** 轨迹包含模型轮次、每轮上下文摘要、工具顺序、每次渲染结果和验收结论

#### Scenario: 失败轨迹

- **WHEN** agent 达到上限失败
- **THEN** 轨迹保留失败步骤和错误，不删除中间记录

#### Scenario: 不展示隐藏推理

- **WHEN** 聊天渲染轨迹
- **THEN** 只显示工具事件、模型面向用户的简短说明和摘要，不显示模型内部思维过程

#### Scenario: 模型轮次事件

- **WHEN** agent 调用一次模型
- **THEN** 事件流产生该轮开始和结束事件，结束事件包含可展示的简短说明或明确的空说明状态

#### Scenario: 轮次上下文

- **WHEN** 一次模型调用完成
- **THEN** 事件流包含该轮实际发送的附件标识、数量和元数据摘要，不包含图片字节或模型 Key

#### Scenario: 事件去重

- **WHEN** 同一工具调用同时产生生命周期事件和领域结果
- **THEN** 事件带有稳定标识，消费方更新同一张卡片，不产生重复的孤立卡片
