# Spec Delta

## ADDED Requirements

### Requirement: 双镜参考与分镜视频同源合并

系统 SHALL 为每条生成转场边合并上镜与下镜的视频出片参考，解析规则 MUST 与分镜 `buildShotVideoRequest` 所用来源一致：表情参考、角色连线、相邻分镜 token、图片素材连线、手工 URL、参考视频素材。合并 MUST 按 URL 去重，再应用与分镜相同的参考图上限与省略说明。结构首尾帧 MUST 占用首尾槽位，MUST NOT 用各镜静帧预览替代边界帧。

#### Scenario: 两镜均有画布连线参考

- **WHEN** 上镜与下镜均连有角色或场景参考且用户展开转场生成出片预览
- **THEN** 参考列表包含两镜解析出的条目，编号与用途标注与分镜视频 Tab 一致

#### Scenario: 相邻镜 token 纳入

- **WHEN** 上镜 refIds 含下一镜相邻参考或下镜含上一镜相邻参考
- **THEN** 合并结果包含对应相邻镜画面参考，与单镜出片行为一致

### Requirement: 转场生成壳仅保留接缝三态

转场面板 MUST 在全局保留接缝选择 `硬切 | 效果 | 生成` 及效果预设、智能建议等转场专属控件。接缝为「生成」时的出片交互 MUST 嵌入与分镜视频 Tab 同构的出片工作台（模型、分辨率、参考摘要、本次出片提示词、底栏），MUST NOT 要求用户在转场面板重复维护与分镜画面 Tab 无关的出图/构图能力。

#### Scenario: 生成模式工作台可见

- **WHEN** 用户将接缝设为「生成」
- **THEN** 面板显示与分镜视频 Tab 同序的出片控件，且接缝三态仍位于面板顶部

### Requirement: 转场原生音频展示策略

转场出片 MUST NOT 合并或提交上镜/下镜的 `audioMode: native` 或音色参考。系统 MUST 展示与分镜相同的原生音频区块，但控件固定为禁用态，并说明环境声与对白须写入转场「声音描述」进提示词。请求 MUST NOT 附带 `audioRef` 或等价音色附件。

#### Scenario: 禁用态与分镜一致

- **WHEN** 用户查看转场生成出片工作台
- **THEN** 原生音频区域可见且不可启用，footnote 指向声音描述字段

#### Scenario: 声音描述进正文

- **WHEN** 用户填写声音描述且未手改全文
- **THEN** 最终发送正文包含该描述片段

### Requirement: 参考视频与分镜首期规则一致

合并参考视频后，系统 MUST 至多提交一条参考视频，其余 MUST 列入 omitted 并说明与分镜相同的原因。在模型与锚点策略允许时，预览列出的参考视频 URL MUST 与实际请求一致。

#### Scenario: 两镜各连一条视频素材

- **WHEN** 上镜与下镜均连线视频素材且策略允许提交
- **THEN** 面板标明一条将提交、其余一条列入省略说明

## MODIFIED Requirements

### Requirement: 转场出片只有一个拼装结果

系统 SHALL 为每条生成转场边提供单一拼装结果，同时给出最终提示词、结构锚点附件、参考图与参考视频附件（含省略项）、锚点策略及阻止原因；转场面板展示的正文 MUST 与实际 `/api/seedance` 转场请求中的 `prompt` 逐字一致，结构首尾帧与（在策略允许时）参考图、参考视频 MUST 与面板列出的附件一致。

#### Scenario: 预览与请求一致

- **WHEN** 用户展开「本次转场出片」并点击「生成转场视频」
- **THEN** 面板「最终发送正文」与请求 `prompt` 完全相同，且列出的首尾帧 URL 与请求 `transition.boundaryOut` / `boundaryIn`（或关键帧字段）一致

#### Scenario: 互斥时清单诚实

- **WHEN** 锚点策略为首尾直变且当前模型禁止同时提交尾帧与 reference_image
- **THEN** 面板仍将参考图列出，并标明「本次未提交」及原因；生成不因隐藏项而静默丢参考

#### Scenario: 允许提交时参考图一致

- **WHEN** 锚点策略与模型允许同时提交风格参考图
- **THEN** 请求 `refImages` 与面板标记为「将提交」的参考图 URL 集合一致

### Requirement: 风格参考可继承、排除与增补

系统 SHALL 自两镜合并得到参考清单；用户 MUST 能逐项在转场级排除 token（`excludeRefIds`），并从项目候选增补仅在本转场有效的 token（`refIds`）。排除与增补 MUST 持久化在转场 `generated` 配置中。默认 MUST 合并两镜全部分镜规则解析出的参考；用户关闭「继承两镜参考」时 MUST 仅保留转场增补 token 与结构首尾帧。

#### Scenario: 排除继承项

- **WHEN** 用户对某条继承自上镜的参考点击排除
- **THEN** 该参考不再出现在将提交列表，`excludeRefIds` 含其 token

#### Scenario: 增补素材

- **WHEN** 用户从候选列表添加一条未在两镜连线中的场景图
- **THEN** 该参考出现在统一参考列表并持久化于 `refIds`

### Requirement: 出片信息分区顺序

「生成」模式下的出片工作台 MUST 按与分镜视频 Tab 相同的扫读顺序展示：出片模型与分辨率、原生音频（禁用展示）、参考摘要与列表、blocking/warnings、本次出片提示词（含分层输入与最终正文）。接缝控件与效果区 MUST 位于该工作台之上；底栏主操作 MUST 位于面板底部且在折叠区外。

#### Scenario: 扫读顺序

- **WHEN** 用户展开本次转场出片
- **THEN** 先看到模型与参考清单，再看到提示词与正文，主生成按钮在面板底栏
