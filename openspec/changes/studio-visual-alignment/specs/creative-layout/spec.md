# Spec Delta

## ADDED Requirements

### Requirement: 创意正文与侧栏使用应用正文字号

创意视图 MUST 用应用正文字号呈现宿主对话正文、侧栏导航标签与会话列表标题，三处 MUST 一致。宿主自身的字号偏好 MUST NOT 覆盖该值。

#### Scenario: 打开有消息的会话

- **WHEN** 操作员在日间或夜间主题下打开一个有消息的创意会话
- **THEN** 对话正文、输入区文字、侧栏导航标签与会话列表标题的字号都与应用其它视图正文相同，不出现同一侧栏内导航小而会话大的混排

#### Scenario: 宿主字号偏好已保存

- **WHEN** 宿主设置里保存过与默认值不同的正文字号
- **THEN** 创意视图仍按应用正文字号呈现，宿主偏好不改变视觉结果

### Requirement: 创意侧栏顶部不保留空带

创意侧栏顶部行 MUST 只承载折叠控件，其高度 MUST NOT 明显大于该控件本身。展开态与折叠态下，顶部 MUST NOT 出现只含空白的大段区域。

#### Scenario: 展开侧栏

- **WHEN** 操作员展开宿主侧栏并查看顶部
- **THEN** 顶部不再出现约 60px 的空白带，折叠控件的垂直中心与右侧对话标题行的中心相差不超过 4px

#### Scenario: 折叠侧栏

- **WHEN** 侧栏处于折叠轨道状态
- **THEN** 轨道顶部同样不出现空带，展开控件位置不因此下沉

### Requirement: 创意侧栏导航行与应用导航同密度

创意侧栏的导航行 MUST 使用与应用左栏导航相同的行高与行内留白，两者并排出现时 MUST NOT 呈现明显不同的疏密。

#### Scenario: 并排比较导航行

- **WHEN** 操作员同时看到应用左栏与宿主侧栏
- **THEN** 两侧导航行的实际高度相差不超过 2px，左右留白观感一致

#### Scenario: 会话与导航同列

- **WHEN** 侧栏同时显示导航行与会话列表
- **THEN** 两类行的高度与文字大小一致，不出现一组更高更松的情况

### Requirement: 尺度对齐失效时静默退化

宿主类名或结构漂移导致尺度规则无法命中时，创意视图 MUST 退回宿主默认尺度，MUST NOT 阻断加载、报错或改变会话功能。

#### Scenario: 类名漂移

- **WHEN** 宿主升级后侧栏类名变化，注入的尺度规则不再命中
- **THEN** 创意视图按宿主默认尺度正常显示，会话列表、消息流与输入区均可用，控制台不出现错误

#### Scenario: 注入失败

- **WHEN** 同源文档不可写或样式注入失败
- **THEN** 创意视图继续加载并工作，只是保留宿主默认尺度
