# Spec Delta

## ADDED Requirements

### Requirement: 分集剧本导入零门禁

分集剧本「导入剧本大纲」对任意非空文本 SHALL 产出至少一集、至少一场的 `episodes` 预览草案，并允许用户确认合并写入项目。系统 MUST NOT 因 Markdown 场标题形态、`script-v1` 契约校验失败或 `detectFormat` 判定为自由文本而阻止预览或禁用「确认导入」。解析推断与占位补全 MAY 记入 warnings，但 MUST NOT 以此禁用确认按钮。内嵌镜号表头分镜表 SHALL 仍忽略并提示走画布导入。

#### Scenario: 纯文本无场标题

- **WHEN** 用户粘贴无任何 `##` 场标题的长文本并打开导入预览
- **THEN** 系统将全文归入建议集号的单一场次，预览可确认，合并后不阻断写入

#### Scenario: 畸形场标题不整份拒绝

- **WHEN** 文件含 `## 第一场 咖啡厅` 等不符合 short-drama 严格语法的二级标题
- **THEN** 系统仍产出 `episodes` 预览，warnings 说明推断规则，确认按钮可用

#### Scenario: 契约字段由占位满足

- **WHEN** 解析结果缺少地点或时间等 `script-v1` 必填字符串
- **THEN** 导入路径在写入前自动填入可见占位（如「未命名地点」「未注明时间」），不因契约校验 blocked

#### Scenario: 合体文件仍忽略分镜表

- **WHEN** 同一份文本既含场次正文又含首列为「镜头」的分镜表
- **THEN** 剧本导入只写 `episodes`，预览说明已忽略分镜表并提示画布导入

### Requirement: 分集剧本宽松场切分

分集剧本 Markdown 解析 SHALL 在识别到 short-drama 严格场标题时保持与既有导出往返一致的字段映射。无法严格匹配时 SHALL 将任意 `##` 行（非 `###` 表头）视为新场边界，并启发式拆分内外景、地点与时间；无法拆分时 MUST 使用占位字段而 MUST NOT 使整次解析失败。无法识别任何场边界时 MUST 将全文作为单场的 `beats`。场正文 MUST 原样拼接为 `beats`，MUST NOT 改写对白或编造情节。

#### Scenario: 严格标题仍优先

- **WHEN** 文件含 `## EP001-SC001 内 · 咖啡厅 · 日`
- **THEN** slug、place、time、space 与现有严格解析一致

#### Scenario: 任意二级标题开新场

- **WHEN** 文件含 `## 内景·家·夜` 与下一段 `## 外景·街道·晨`
- **THEN** 预览显示两场，beats 分别为两标题之间的原文

## MODIFIED Requirements

### Requirement: 文本工作台提供导入入口

剧本与画布两个视图 SHALL 各自提供「导入」入口。分集目录剧本导入 MUST 支持 `.md`、`.markdown` 与 `.txt` 文件及粘贴的等价纯文本。非空粘贴或文件内容 MUST 进入分集剧本零模型解析，MUST NOT 仅因格式未识别而拒绝预览。画布导入 MUST 继续支持表格、JSON 与粘贴文本，并保留镜号列等既有门禁。分集剧本入口 MUST NOT 要求先经过模型；MUST 在未选择项目时不可用并说明原因。

#### Scenario: 上传文件

- **WHEN** 用户在有项目的画布点击「导入」并选择一个表格文件
- **THEN** 系统读取该文件并进入解析与预览流程，不要求用户先点生成

#### Scenario: 粘贴文本

- **WHEN** 用户把一段分镜文本粘贴进画布导入框并确认
- **THEN** 系统以同样的解析与预览流程处理该文本

#### Scenario: 分集剧本上传文本文件

- **WHEN** 用户在有项目的剧本视图导入 `.txt` 或 `.md` 文件
- **THEN** 系统读取并进入分集剧本宽松解析与合并预览

#### Scenario: 画布导入纯提示词表

- **WHEN** 用户在画布上传只含镜号与首帧提示词两列的表格
- **THEN** 预览标明只更新提示词列，应用后分镜结构字段保持原值

#### Scenario: 没有项目

- **WHEN** 用户尚未选择项目时查看导入入口
- **THEN** 导入入口不可用，并显示先选择项目的提示
