# Spec Delta

## ADDED Requirements

### Requirement: 创意宿主写回后画布与水合

经创意视图（DSH 专家会话）成功执行平台写工具并落库后，当顶栏项目与写库目标一致时，分镜画布与时间线 MUST 在不重启应用的前提下反映最新落库（新增/更新/删除的镜头、分集元数据及其他写工具改动的字段）。水合 MUST 复用壳内既有「重读项目 + 水合镜头」路径，MUST NOT 重置视口 fit，MUST NOT 丢弃操作员在同一项目内未落库的手改.canvas 几何（在 revision 与既有防抖规则允许范围内）。

#### Scenario: 创意写镜后切画布可见

- **WHEN** 操作员在创意视图批准 `submit_shots` 写入当前顶栏项目，随后切换到分镜画布视图
- **THEN** 画布出现新写入的镜头节点与连线，与 `GET /api/project` 一致，无需重启桌面应用

#### Scenario: 写分集剧本后目录更新

- **WHEN** 操作员在创意视图批准 `submit_episodes` 写入当前项目
- **THEN** 分集目录中的标题、场次与钩子与落库一致，无需切换项目或重启

#### Scenario: 仍在创意 tab 时后台水合

- **WHEN** 操作员停留在创意视图且写工具已成功
- **THEN** 外壳仍完成快照刷新；当操作员稍后再打开画布时数据已是新的，不要求在创意内再操作一次
