# Spec Delta

## ADDED Requirements

### Requirement: 外部写路径变更当前项目时壳须重载

当顶栏已选某项目时，若项目数据经**非壳内直接编辑**的成功路径被修改（含创意宿主工具桥执行的平台写工具），系统 MUST 在合理延迟内重载该项目的全局上下文（镜头、分集、角色、素材摘要等壳所持有的快照），使各视图与落库一致。重载 MUST NOT 把未保存的**项目级表单脏状态**静默写入其他项目；对画布防抖未落库的手改，行为 MUST 与既有 revision 门控及写后实况推送规则一致。

#### Scenario: 同项目专家写后不串数据

- **WHEN** 顶栏选中项目 A，创意专家在项目 A 成功 `submit_characters`
- **THEN** 角色视图与后续 `GET /api/project` 展示 A 的新角色表，仍不混入项目 B 的数据

#### Scenario: 未选项目时不刷壳

- **WHEN** 顶栏无项目，创意工具因缺项目而失败
- **THEN** 外壳不发生项目快照重载

#### Scenario: 切换项目仍走完整加载

- **WHEN** 操作员从项目 A 切换到 B
- **THEN** 仍执行既有「切换项目时重载项目数据」流程；本变更不削弱该行为
