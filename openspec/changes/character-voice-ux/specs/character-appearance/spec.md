# Spec Delta

## ADDED Requirements

### Requirement: 角色声音页分区展示引擎音色与试音

角色卡声音 Tab SHALL 将配置分为三个可见区块：配音引擎、说话音色、试音样本（Seedance 参考）。页面底部 MUST 用固定说明区分「镜头台词配音在画布 Inspector」，本页仅配置角色声线与试音。试音生成 MUST 使用单一主按钮；删除样本与编辑试音稿 MUST 为次要操作。

#### Scenario: 三块分区可见

- **WHEN** 用户打开角色卡声音 Tab
- **THEN** 用户能依次看到配音引擎选择、音色选择与试音样本区，且每区有明确标题

#### Scenario: 镜头配音说明

- **WHEN** 用户阅读声音 Tab 底部说明
- **THEN** 说明指出台词配音在画布 Inspector，而非本页

#### Scenario: 试音主按钮

- **WHEN** 用户需要生成或重生成试音
- **THEN** 试音区有一个主要「生成试音」按钮；删除样本不为同级主按钮

### Requirement: 声音配置状态轨

系统 SHALL 在声音 Tab 顶部提供单行状态展示，反映当前最高优先级阻塞或就绪状态（例如缺项目、引擎无音色、未选音色、渠道不一致、试音需重生成、试音可用）。状态轨 MUST 最多提供一个主修复动作（如重选音色、打开设置说明、生成试音），且与试音按钮禁用逻辑一致。

#### Scenario: 渠道不一致

- **WHEN** 角色 voiceProvider 与当前配音引擎渠道不一致
- **THEN** 状态轨说明不一致，并提供「重选音色」或等价主操作；试音主按钮禁用

#### Scenario: 未选固定音色

- **WHEN** 角色未选择具体音色或选择了「跟随镜头」
- **THEN** 状态轨提示需选择音色后才能生成试音

#### Scenario: 引擎无音色目录

- **WHEN** 当前配音引擎下没有返回任何音色
- **THEN** 状态轨提示检查设置页 Key 或更换引擎，并引导用户前往设置相关入口

### Requirement: 切换配音引擎后引导重选音色

当用户更改角色配音引擎且当前 voiceId 不属于新引擎目录时，系统 MUST 引导用户重新选择音色；MUST NOT 在渠道已变化的情况下仍允许试音生成使用跨渠道 voiceId 且无明确警告。用户显式保留未知 voiceId 时 MUST 显示警告并需确认后再生成。

#### Scenario: 引擎切换且音色失效

- **WHEN** 用户将配音引擎从 MiniMax 换为火山且原 voiceId 不在火山目录
- **THEN** 系统清空或标记需重选音色，并提示重新选择；旧试音样本标记需重生成

#### Scenario: 引擎切换音色仍有效

- **WHEN** 用户切换引擎后当前 voiceId 仍在新目录中
- **THEN** 保留 voiceId 并更新元数据；若试音指纹变化则标记样本 stale

### Requirement: 角色卡摘要外显声音状态

角色卡底部摘要 MUST 显示配音引擎简称、音色标签与试音状态（未生成、需重生成、可用或不可用），使用户不打开声音 Tab 也能感知配置是否完整。

#### Scenario: 摘要含引擎与试音

- **WHEN** 角色已绑定引擎、音色且试音可用
- **THEN** 摘要一行包含引擎、音色名与试音可用标识

#### Scenario: 摘要缺试音

- **WHEN** 角色已选音色但未生成试音
- **THEN** 摘要标明试音未生成或需配置
