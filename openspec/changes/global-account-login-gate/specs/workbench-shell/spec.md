# Spec Delta

## ADDED Requirements

### Requirement: 账号入口属于全局而非项目视图

账号与充值 MUST NOT 作为项目视图出现在项目侧栏或 `ViewId` 清单中。它 SHALL 作为全局入口出现在项目大厅，与任何具体项目无关；已登录与未登录用户 MUST 都能到达该入口。

#### Scenario: 项目侧栏无账号项

- **WHEN**: 用户打开任一项目的侧栏
- **THEN**: 导航项中不存在「账号与充值」，也没有空的「账户」分组占位

#### Scenario: 大厅有账号入口

- **WHEN**: 用户停留在项目大厅
- **THEN**: 顶栏提供账号入口；未登录时其文案表明需要登录，已登录时显示当前账号身份

#### Scenario: 账号页不依赖项目

- **WHEN**: 用户在大厅点击账号入口
- **THEN**: 进入账号页，该页面不显示项目名、集选择器或任何项目级工具

#### Scenario: 账号页自带返回大厅的出口

- **WHEN**: 用户位于账号页（未登录或已登录）
- **THEN**: 页面上有明确的返回项目大厅入口，点击后可回到大厅；MUST NOT 只能靠修改地址栏离开

#### Scenario: 旧项目内账号链接

- **WHEN**: 用户访问形如 `#/p/<项目>/account` 的历史链接
- **THEN**: 被重定向到全局账号页，MUST NOT 落到「未知视图回落到概览」
