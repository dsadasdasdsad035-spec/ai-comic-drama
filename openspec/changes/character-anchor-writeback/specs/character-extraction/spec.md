# Spec Delta

## MODIFIED Requirements

### Requirement: 角色合并只影响当前项目

系统 SHALL 把拆出的角色合并到当前项目，并保留已有手改外观锚点；MUST NOT 覆盖或删除其他项目的角色。

合并结果 MUST 以与当前项目既有角色相同的字段形态写入，落库后从当前项目读回的角色 MUST 与合并结果一致：新增角色保留本次提交的外观锚点，被跳过的已有角色保留原锚点。合并阶段保留、写入阶段丢失 MUST NOT 发生。

#### Scenario: 新增角色
- **WHEN** 拆出当前项目里不存在的角色
- **THEN** 追加到当前项目角色列表

#### Scenario: 已有手改角色
- **WHEN** 拆出的角色与当前项目已有角色同名且已有外观锚点
- **THEN** 保留已有锚点，按既有规则只补空字段

#### Scenario: 其他项目角色
- **WHEN** 在项目 B 拆角色
- **THEN** 项目 A 的角色列表不被读取或修改

#### Scenario: 合并结果写入后可读回
- **WHEN** 拆出的角色合并进当前项目并保存成功
- **THEN** 重新读取该项目角色时，新增角色的外观锚点非空，被跳过的同名角色锚点与合并前相同

#### Scenario: 角色字段缺失时合并继续
- **WHEN** 项目中某个已有角色没有中英文外观锚点字段
- **THEN** 合并按「无锚点」处理并继续写入其余角色，MUST NOT 整次提交失败
