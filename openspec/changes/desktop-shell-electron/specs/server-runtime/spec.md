# Spec Delta

## ADDED Requirements

### Requirement: 运行期状态根可配置

系统 SHALL 从环境变量解析运行期状态根目录，用于暂存文件、渲染作业、场景草稿、平台登录态与计费数据库等运行期写入。未配置该变量时 MUST 回退到应用根目录下的原有路径，使现有开发与容器行为不变。

#### Scenario: 未配置时保持旧行为

- **WHEN** 未设置运行期状态根变量启动服务
- **THEN** 暂存、作业、草稿与计费数据库仍落在应用根目录下的原有位置

#### Scenario: 自定义状态根后重启仍在

- **WHEN** 运行期状态根指向另一个可写目录并完成一次会写入状态的操作
- **THEN** 写入落在该目录，且服务重启后仍能从该目录读到之前的状态

#### Scenario: 与媒体根相互独立

- **WHEN** 只设置媒体根或只设置运行期状态根
- **THEN** 未设置的那一侧仍按自身默认规则解析，两者互不覆盖
