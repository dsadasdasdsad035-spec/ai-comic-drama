# Spec Delta

## MODIFIED Requirements

### Requirement: 修复与验收循环必须有上限

运行时 MUST 限制代码生成/修复轮次、视觉验收轮次、图执行步数和总运行时长；步数与总时长 MUST 来自已保存的 Agent 运行设置，未配置时使用默认值。达到上限 MUST 停止并返回可读失败结果；总超时 MUST 与用户取消区分，不能显示成已取消。

#### Scenario: 修复成功

- **WHEN** 沙箱返回错误且修复次数未超限
- **THEN** agent 可以提交新代码并再次试运行

#### Scenario: 达到修复上限

- **WHEN** 连续修复达到配置上限仍未通过
- **THEN** 循环停止，显示失败原因和已尝试次数

#### Scenario: 达到步骤上限

- **WHEN** 图执行步数达到设置中的最大步数
- **THEN** 循环停止，错误包含当前步数上限，并提示可在设置页调整

#### Scenario: 用户取消

- **WHEN** 用户在工具执行中取消
- **THEN** 后续工具不执行，旧代码和视频不被改动，状态显示为已取消

#### Scenario: 整体超时

- **WHEN** 整个 agent 运行超过设置中的总运行时长
- **THEN** 运行被终止并显示运行超时，不写入半成品，也不显示成用户取消
