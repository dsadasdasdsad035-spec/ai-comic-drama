# Spec Delta

## Purpose

让 3D agent 的总运行时长可以像模型一样在设置页调整并持久化，同时明确不提供总步骤上限；没有时间边界时，长时间循环会无限消耗模型和沙箱资源。

## ADDED Requirements

### Requirement: Agent 总运行时长可在设置页配置

设置页 SHALL 提供总运行时长配置，默认 300 秒；用户修改后 MUST 随现有设置一起保存，并在后续 agent 运行中生效。设置页 MUST NOT 提供最大执行步数配置。

#### Scenario: 默认值

- **WHEN** 设置中没有保存过 Agent 总运行时长
- **THEN** 使用 300 秒

#### Scenario: 修改并保存

- **WHEN** 用户把总运行时长改为 600 秒并保存设置
- **THEN** 重新读取设置时仍得到 600，并用于下一次 agent 运行

#### Scenario: 不提供步骤上限

- **WHEN** 用户打开 Agent 运行设置
- **THEN** 只能配置总运行时长，看不到最大图步骤/调用次数设置

### Requirement: 总运行时长必须校验并向后兼容

总运行时长 MUST 是有限整数，并限制在 60–1800 秒；非法或越界输入 MUST 被夹取或回退默认值，MUST NOT 让 agent 进入无时间边界运行。旧设置中的 `maxSteps` MUST 被忽略，其他模型、渠道和规则设置 MUST 保持不变。

#### Scenario: 越界输入

- **WHEN** 用户输入 0 秒或 9999 秒
- **THEN** 保存后的有效值落在 60–1800 秒内，界面显示实际生效值

#### Scenario: 非数字输入

- **WHEN** 输入为空或不是数字
- **THEN** 使用默认 300 秒，不把空值当成 0

#### Scenario: 旧设置兼容

- **WHEN** 读取仍带有旧 `maxSteps` 字段的设置
- **THEN** 不恢复步骤上限，只使用/补默认总时长

#### Scenario: 不影响其他设置

- **WHEN** 只保存总运行时长
- **THEN** 模型表、环节默认、计价和规则不被清空或重置
