# Spec Delta

## Purpose

让 3D agent 的运行上限可以像模型一样在设置页调整并持久化，避免每次触顶都要改代码；同时让默认值和范围有明确边界。

## ADDED Requirements

### Requirement: Agent 运行上限可在设置页配置

设置页 SHALL 提供最大执行步数和总运行时长两个数字配置，默认值分别为 24 步和 300 秒；用户修改后 MUST 随现有设置一起保存，并在后续 agent 运行中生效。

#### Scenario: 默认值

- **WHEN** 设置中没有保存过 Agent 运行上限
- **THEN** 最大步数为 24，总运行时长为 300 秒

#### Scenario: 修改并保存

- **WHEN** 用户把最大步数改为 48、总时长改为 600 秒并保存设置
- **THEN** 重新读取设置时仍得到 48 和 600，并用于下一次 agent 运行

#### Scenario: 步数含义

- **WHEN** 用户查看最大步数配置
- **THEN** 界面说明它按图执行步数计算，约 3 步对应一轮模型/工具循环

### Requirement: Agent 运行上限必须校验并向后兼容

运行上限 MUST 是有限整数；最大步数 MUST 限制在 12–120，总时长 MUST 限制在 60–1800 秒。非法或越界输入 MUST 被夹取到有效范围或回退默认值，MUST NOT 让 agent 进入无上限运行。

#### Scenario: 越界输入

- **WHEN** 用户输入 0 步或 9999 步
- **THEN** 保存后的有效值落在允许范围内，界面显示实际生效值

#### Scenario: 非数字输入

- **WHEN** 输入为空或不是数字
- **THEN** 使用默认值，不把空值当成 0

#### Scenario: 旧设置兼容

- **WHEN** 读取没有 Agent 运行上限字段的旧设置
- **THEN** 其他模型、渠道和规则设置保持不变，运行上限补默认值

#### Scenario: 不影响其他设置

- **WHEN** 只保存 Agent 运行上限
- **THEN** 模型表、环节默认、计价和规则不被清空或重置
