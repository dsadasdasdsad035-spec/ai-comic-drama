# Spec Delta

## ADDED Requirements

### Requirement: 工具调用使用当前项目作为默认上下文

工具执行请求未携带项目名时，系统 SHALL 使用服务端记录的当前项目作为上下文，MUST NOT 因请求未带项目名而直接拒绝。服务端记录的当前项目 MUST 来自操作员最近一次通过创意视图推送的项目，且 MUST 是项目列表中真实存在的目录名。调用显式携带的项目名 MUST 优先于该记录。

#### Scenario: 未带项目名的读取

- **WHEN** 宿主发起 `read_source` 且请求体项目名为空，服务端已记录当前项目 `rain-night`
- **THEN** 该工具读取 `rain-night` 的原著与设定并正常返回

#### Scenario: 切换项目后立即生效

- **WHEN** 操作员从项目 A 切到项目 B，下一次工具调用未带项目名
- **THEN** 工具读写只发生在 B，A 的数据不被读取或修改

#### Scenario: 显式项目优先

- **WHEN** 调用参数显式指定项目 B，而服务端记录的是 A
- **THEN** 该次调用作用于 B，服务端记录不变

### Requirement: 当前项目只在合法时被采纳

系统 MUST 拒绝把不在项目列表中的目录名记录为当前项目，并在拒绝时保留原值。当前项目被删除后，工具调用 MUST 返回可读的「项目不存在」失败，MUST NOT 回退到其它项目继续读写。

#### Scenario: 推送不存在的项目

- **WHEN** 前端推送的项目名在项目列表中不存在
- **THEN** 请求被拒绝并说明原因，服务端记录仍是原先合法的项目

#### Scenario: 当前项目已被删除

- **WHEN** 服务端记录的项目已在磁盘上删除，模型调用读取工具
- **THEN** 该调用返回「项目不存在」的可读失败，不写入任何项目

### Requirement: 项目清单工具可供模型发现当前项目

系统 SHALL 提供一个只读工具返回项目清单，包含当前项目名与所有项目的目录名、标题、画风、画幅、集数、镜头数与更新时间。该工具 MUST NOT 依赖项目上下文、MUST NOT 需要用户确认、MUST NOT 返回项目正文内容。项目清单为空时 MUST 明确告知「还没有项目」。

#### Scenario: 未选项目时先列清单

- **WHEN** 未选项目且模型调用项目清单工具
- **THEN** 返回空当前项目与已有项目列表，模型据此向操作员询问要读哪个项目

#### Scenario: 列出项目不受当前项目限制

- **WHEN** 当前项目为 A，模型调用项目清单工具
- **THEN** 返回当前项目为 A 以及全部项目条目，包括非 A 的项目
