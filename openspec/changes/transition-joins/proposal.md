# Proposal

## Why

画布上分镜之间的连线目前只是视觉标注：`relation` 只影响边的样式和导出的 JSON，播放与导出完全按 Timeline 顺序硬切拼接，连线本身不参与成片。用户无法通过连线表达真正的转场，已有的角色/素材参考与图生视频能力也没有被用于镜头之间的过渡。这个变更让「分镜之间那条线」第一次成为可渲染的接缝：默认立刻给 0.5 秒叠化，并可以升级为带角色/素材参考生成的一段转场视频。

## What Changes

- 分镜连线新增「接缝」语义：硬切 / 效果转场 / 生成转场；效果与生成两套配置并存，模式切换不销毁已有产物。
- 标记为转场时默认立刻应用 0.5 秒叠化；缺省值在读时兜底，不批量改写旧存档。
- 效果转场支持叠化、擦除（左/右/上/下）、推移（左/右/上/下），时长可调；成片采用重叠模型（A + B − T）。
- 生成转场采用「先出关键帧、再图生视频」：自动抽取 A 尾帧与 B 首帧，关键帧接受角色与素材参考，生成片段插入成片并在两端用短叠化接上（A + T + B − 2f）。
- 生成转场逐条手动触发，不做自动批量；界面显示生成状态与「需要重生成」状态。
- 预览、时间线与导出共用同一份剪辑序列（edit list），转场参与时长计算，配音与字幕随接缝正确移位。
- 转场数据按 `fromShotId/toShotId` 进入项目数据；相邻镜头产物或边界帧变化后标记为需要重生成。
- 非相邻镜头的转场连线不参与成片，并给出明确提示。

明确不做：

- 不做生成式转场的全片自动批量，也不做自动选型。
- 不改变现有 `relation` 四种叙事标签的语义（闪回、分支仍是标签，不参与渲染）。
- 生成转场片段不带音频。
- 不引入新的图像或视频模型渠道，只复用现有路由与能力。

## Capabilities

### New Capabilities

- `shot-transitions`: 分镜接缝的语义与默认行为、效果转场预设、生成转场的参考与产物流程、成片合成中的时间模型、持久化与失效判定。

### Modified Capabilities

（无）

## Impact

- 画布：`ShotEdge` 的边数据与 chip 交互、连线面板、转场状态展示。
- 数据：`ShotEdgeType` 与项目数据新增转场结构；画布存档读取时做默认值兜底。
- 合成：`buildAnimatic` 从单条 `concat` 直链改为按接缝折叠（硬切走 concat、效果走 xfade）；总时长、段起点、字幕与配音基准改由 edit list 提供。
- 预览与时间线：`Preview`、`Timeline`、播放列表共用 edit list，不再各自累加镜头时长。
- 生成：新增转场关键帧与转场视频任务，复用现有 Seedream / Seedance 路由、参考解析与计费口径。
- 服务端：复用现有抽帧接口；合成路由新增 xfade 链与混合接缝折叠。
- 成本：效果转场零成本；生成转场按视频时长计费，逐条手动触发。
