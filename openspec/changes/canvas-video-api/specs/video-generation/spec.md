# Spec Delta

## Purpose

画布中的镜头可以通过配置好的视频渠道生成动态视频，任务提交、状态查询与产物落盘都由应用自身完成，不依赖开发机上的外部脚本或命令行工具。

## ADDED Requirements

### Requirement: 出片任务通过视频渠道 API 提交

系统 SHALL 在收到画布出片请求后，通过 HTTP 向当前视频渠道提交生成任务，使用设置中选择的模型与凭据，并立即返回本地任务 id；提交流程 MUST NOT 启动外部进程，也不得依赖项目目录外的脚本。

#### Scenario: 首帧模式提交

- **WHEN** 客户端提交首帧图片、提示词、时长与比例，且视频渠道有可用 Key
- **THEN** 系统向该渠道的任务接口发送包含文本与 `first_frame` 图片的请求，并返回本地任务 id，状态为运行中

#### Scenario: 尾帧约束与参考图互斥

- **WHEN** 请求同时包含首帧、尾帧与参考图
- **THEN** 系统只采用参考图模式，不发送尾帧，且参考图最多 4 张

#### Scenario: 参考图部分失效

- **WHEN** 请求包含多张参考图且其中部分文件不存在
- **THEN** 系统跳过失效图片继续提交，并在响应中返回被跳过的路径；全部失效时返回 400 且不提交任务

#### Scenario: 渠道缺少 Key

- **WHEN** 当前视频渠道没有可用 API Key
- **THEN** 系统返回 400 与 `no-key` 标识，不向服务商提交任务

#### Scenario: 非方舟协议渠道

- **WHEN** 当前视频模型绑定到不支持方舟视频协议的渠道
- **THEN** 系统返回可读错误，提示切换到方舟渠道的视频模型，不提交任务

#### Scenario: 使用渠道 Base URL

- **WHEN** 视频渠道配置了自定义 Base URL
- **THEN** 任务提交与状态查询都发往该 Base URL 下的任务路径

#### Scenario: 调试提交内容

- **WHEN** 请求带有 dryRun 标记
- **THEN** 系统返回将要提交的请求内容，不发起任何网络请求

### Requirement: 任务状态与前端轮询契约保持兼容

系统 SHALL 维护本地任务状态，并通过出片任务查询接口返回 `running`、`succeeded` 或 `failed`，在终态附带稳定的本地视频地址、尾帧地址、错误信息与耗时；服务商的排队状态 MUST 映射为 `running`。

#### Scenario: 运行中查询

- **WHEN** 客户端查询仍在执行的任务
- **THEN** 返回 `running`，客户端可以继续按既有间隔轮询

#### Scenario: 查询不存在的任务

- **WHEN** 客户端查询未知任务 id
- **THEN** 返回 404 与 `failed` 状态

#### Scenario: 成功后查询

- **WHEN** 服务商任务完成且产物已下载
- **THEN** 返回 `succeeded`、站内视频路径与可用的尾帧路径

#### Scenario: 失败后查询

- **WHEN** 服务商返回失败、过期或取消
- **THEN** 返回 `failed` 与服务商错误信息，不返回半成品地址

### Requirement: 完成任务的产物必须立即落盘

系统 SHALL 在服务商任务成功后立即下载视频与尾帧到本地可访问目录，并返回站内路径；视频下载失败 MUST 使任务失败，尾帧下载失败 MUST NOT 影响视频结果。

#### Scenario: 视频与尾帧下载成功

- **WHEN** 服务商返回视频地址与尾帧地址
- **THEN** 视频写入本地视频目录并返回 `/videos/...` 路径，尾帧写入本地生成目录并返回 `/generated/...` 路径

#### Scenario: 尾帧下载失败

- **WHEN** 视频下载成功但尾帧地址下载失败
- **THEN** 任务仍为 `succeeded`，尾帧字段为空

#### Scenario: 视频下载失败

- **WHEN** 视频地址无法下载
- **THEN** 任务标记为 `failed`，不向画布返回不可用的视频地址

#### Scenario: 轮询超时

- **WHEN** 任务在约定时限内未进入终态
- **THEN** 任务标记为 `failed` 并提示等待超时

### Requirement: 提交前校验模型支持的时长与分辨率

系统 SHALL 在提交前按所选模型声明的时长范围与分辨率档位校验参数；已知模型收到越界值时 MUST 返回 400 并列出允许范围，且不提交任务；未登记的模型 MUST 原样提交，由服务商判断。

#### Scenario: 不支持的时长

- **WHEN** 使用支持 4~12 秒的模型请求 3 秒
- **THEN** 返回 400，提示允许的时长范围，不创建远端任务

#### Scenario: 支持的时长与分辨率

- **WHEN** 使用支持 2~12 秒的模型请求 3 秒与 720p
- **THEN** 正常提交任务

#### Scenario: 时长上限边界

- **WHEN** 使用支持 2~12 秒的模型请求 12 秒
- **THEN** 正常提交任务

#### Scenario: 未登记的模型

- **WHEN** 模型 ID 不在内置档位表中
- **THEN** 系统不阻止提交，按客户端参数发送

### Requirement: 健康检查与设置提示反映 API 模式

系统 SHALL 以"是否存在可用的视频渠道凭据"判断出片可用性；健康状况与设置界面 MUST NOT 再依赖或宣称外部 CLI 脚本。

#### Scenario: 有 Key 但无外部脚本

- **WHEN** 配置了可用的视频 Key 且机器上没有外部脚本
- **THEN** 健康检查报告出片可用

#### Scenario: 没有 Key

- **WHEN** 没有任何可用的视频 Key
- **THEN** 健康检查报告出片不可用

#### Scenario: 设置页提示

- **WHEN** 用户查看视频渠道设置
- **THEN** 提示说明出片通过渠道 API 调用，不再出现 CLI 表述
