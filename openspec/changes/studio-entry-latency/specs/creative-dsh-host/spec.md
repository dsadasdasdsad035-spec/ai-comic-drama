# Spec Delta

## ADDED Requirements

### Requirement: 已就绪宿主的转发路径不做重复配置准备

宿主处于就绪状态时，`/studio/` 下的请求 MUST 直接转发，MUST NOT 再次执行模型配置写入、专家 preset 编译或技能根同步。这些派生配置的更新 MUST 由设置变更事件驱动，MUST NOT 依赖每次请求顺带完成。

#### Scenario: 连续请求不产生写盘

- **WHEN** 宿主已就绪，客户端连续发起多次 `/studio/` 请求
- **THEN** 专家 preset 与模型配置文件的修改时间与写入次数均不变

#### Scenario: 设置变更仍然生效

- **WHEN** 操作员在设置页修改模型或专家后宿主重启
- **THEN** 宿主读到的仍是修改后的配置，不因跳过请求路径同步而回退到旧值

#### Scenario: 宿主未就绪时仍先对齐配置

- **WHEN** 用户进入创意视图且宿主尚未启动
- **THEN** 该次启动前先同步模型与专家配置，再拉起宿主

## MODIFIED Requirements

### Requirement: 创意入口在首次访问前完成宿主预热

应用 SHALL 在自身启动完成后、操作员首次进入创意视图之前主动拉起创意会话宿主。预热 MUST 只在创意入口启用时进行，入口关闭时 MUST NOT 拉起宿主。预热 MUST 复用首次进入时的同一套配置同步与启动路径，MUST NOT 让宿主读到上一次运行遗留的模型或专家配置。预热失败 MUST NOT 无限自动重试，MUST 记录可读原因。宿主处于启动中时 MUST NOT 记为预热已触发或已失败；该次启动成功后 MUST 允许再安排一次预热。首次进入时若宿主仍在启动中，该请求 MUST 等待同一次启动完成，MUST NOT 并行拉起第二个宿主进程。桌面端 MUST NOT 把预热的固定延迟落在操作员正面等待的路径上。

#### Scenario: 预热成功后首次进入

- **WHEN** 应用启动完成、创意入口启用，且操作员在宿主就绪后首次进入创意视图
- **THEN** 宿主已就绪，界面不出现等待宿主启动的提示

#### Scenario: 入口关闭

- **WHEN** 创意入口被关闭后启动应用
- **THEN** 不拉起宿主进程，创意入口不可进入

#### Scenario: 预热期间进入

- **WHEN** 预热尚未完成时操作员进入创意视图
- **THEN** 请求复用同一次启动，系统中只存在一个宿主进程，就绪后直接呈现外壳

#### Scenario: 预热失败

- **WHEN** 预热启动失败
- **THEN** 记录可读失败原因、不自动无限重试，操作员进入时由入口错误页提供重试

#### Scenario: 预热撞上启动中

- **WHEN** 预热触发时宿主正处于启动中
- **THEN** 本次启动完成后重新安排并执行一次预热，不出现「该进程生命周期内再无预热」

#### Scenario: 桌面端预热时点

- **WHEN** 桌面应用完成本地服务握手并加载界面
- **THEN** 宿主预热在该时刻即被触发，不等待固定的秒级延迟

### Requirement: 加载期呈现应用自有加载态

宿主外壳尚未挂载完成时，创意视图 MUST 呈现应用自己的加载态，MUST NOT 呈现宿主的品牌启动页（产品名、插件加载提示等宿主自有文案）。加载态 MUST 跟随应用当前主题。加载态文案 MUST 区分「宿主尚未就绪」与「外壳正在加载」两种阶段，MUST NOT 用同一句不分阶段的说明覆盖两种等待。外壳就绪后加载态 MUST 退场，且在同一视图内 MUST NOT 再次出现。宿主不可用时 MUST 呈现应用自己的中文错误说明与重试入口，并 SHOULD 提供可读的失败原因摘要。

#### Scenario: 首次进入的首帧

- **WHEN** 首次进入创意视图且宿主外壳尚未挂载
- **THEN** 界面显示应用加载态，不显示宿主产品名或插件加载文案

#### Scenario: 等待宿主启动

- **WHEN** 进入创意视图时宿主进程仍在启动
- **THEN** 加载态展示与「等待宿主启动」对应的说明，而非外壳加载说明

#### Scenario: 就绪后退场

- **WHEN** 宿主外壳挂载完成
- **THEN** 加载态消失，且停留在该视图期间不再出现

#### Scenario: 两套主题下的加载态

- **WHEN** 分别在日间与夜间主题下首次进入创意视图
- **THEN** 加载态的表面与文字配色与应用当前主题一致

#### Scenario: 宿主不可用

- **WHEN** 宿主启动失败或运行中崩溃
- **THEN** 显示中文错误说明与重试入口，并可查看失败原因摘要，不显示空白页或无限加载
