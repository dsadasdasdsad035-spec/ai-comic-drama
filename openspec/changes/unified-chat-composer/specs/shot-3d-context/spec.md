# Spec Delta

## MODIFIED Requirements

### Requirement: 选择结果按镜头持久化

选择结果 SHALL 按项目和镜头持久化；切换镜头、关闭编辑器、刷新页面后 MUST 恢复。不同项目、不同镜头 MUST NOT 混用选择；被删除或改名的资源 MUST 显示为缺失并保留可移除状态。聊天输入区里的上传与素材选择 MUST 写入同一份持久化选择，MUST NOT 只存在于聊天会话内。

#### Scenario: 刷新恢复

- **WHEN** 用户选好参考内容后刷新页面并重新打开该镜头
- **THEN** 之前的选择和顺序恢复

#### Scenario: 项目隔离

- **WHEN** 项目 A 和项目 B 都有 S01
- **THEN** 各自只读取自己项目的 S01 选择

#### Scenario: 资源被删除

- **WHEN** 已选角色图从项目删除
- **THEN** 该条目显示缺失，用户可移除且不阻塞其他条目

#### Scenario: 聊天里加入的图片随镜头保存

- **WHEN** 用户在 3D 聊天输入区上传或选择一张图片，然后保存并重新打开该镜头
- **THEN** 该图片仍在已选内容里，与在左侧选择器里勾选的结果一致

#### Scenario: 不同镜头不串图

- **WHEN** 用户在镜头 A 的聊天里加入一张图，随后切到镜头 B
- **THEN** 镜头 B 的已选内容不包含这张图

### Requirement: 选择内容必须真正进入生成和聊天

代码生成和聊天 MUST 只使用当前已选媒体和文本，加上运行所必需的镜头元数据（时长、画幅、镜号）；MUST NOT 静默加入未选角色、素材或全项目图片。聊天输入区 MUST 显示当前已选项，并允许在发送前移除。聊天输入区 MUST 同时提供上传本地图片与从项目素材选择两个入口。

#### Scenario: 只选一张图

- **WHEN** 用户只选择一张分镜生成图并发送聊天
- **THEN** 聊天上下文只包含该图和必要镜头元数据，不包含其他项目图片

#### Scenario: 未选台词

- **WHEN** 用户没有选择台词
- **THEN** 聊天不会因为台词存在于镜头里就自动发送台词

#### Scenario: 聊天前移除

- **WHEN** 用户在聊天输入区移除一个已选素材
- **THEN** 下一条聊天不再包含该素材

#### Scenario: 上传后立即参与生成

- **WHEN** 用户在 3D 聊天输入区上传一张图片并立刻让 agent 生成或预览
- **THEN** 该图片已进入本轮参考素材，代码生成与预览都能读到它，不需要用户再次勾选

#### Scenario: 从项目素材加入视频

- **WHEN** 用户从素材入口选择一个项目视频
- **THEN** 该视频进入已选内容，并按既有规则以关键帧或原生视频参与生成
