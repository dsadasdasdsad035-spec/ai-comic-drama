# Spec Delta

## Purpose

让「项目」成为全站唯一入口：启动先到项目大厅选择或新建项目，进入项目后又有一个最小概览页回答「这个项目做到哪一步、下一步做什么」，而不是把项目埋在顶栏下拉里。

## ADDED Requirements

### Requirement: 大厅是唯一启动入口

系统 SHALL 以项目大厅作为启动页。应用启动时 MUST NOT 自动打开任何项目；用户在大厅打开项目后 MUST 进入该项目的工作区，未知项目或不存在的项目 MUST 回落大厅且不创建数据。

#### Scenario: 冷启动

- **WHEN** 应用启动且本机存在多个项目
- **THEN** 界面显示项目大厅，不自动加载任何项目的镜头或画布

#### Scenario: 打开项目

- **WHEN** 用户在大厅点击一个项目卡片
- **THEN** 进入该项目工作区，并显示该项目上次离开的视图

#### Scenario: 项目已不存在

- **WHEN** 用户通过链接或返回键打开一个已被删除的项目
- **THEN** 界面回到大厅并提示项目不存在，不创建同名项目

### Requirement: 项目卡片提供可辨认信息

每张项目卡片 MUST 显示标题、风格、画幅、集数、镜头数、总时长与最近更新时间；数值 MUST 使用等宽数字。卡片 SHOULD 显示封面，缺少封面时 MUST 使用按画幅比例裁切的占位块，MUST NOT 出现拉伸变形的图片。

#### Scenario: 有完整数据

- **WHEN** 用户查看一个有 3 集 12 镜、总时长 72.5 秒的项目
- **THEN** 卡片显示 3 集、12 镜、1:12.5 与最近更新时间

#### Scenario: 没有封面

- **WHEN** 项目还没有任何可用画面
- **THEN** 卡片显示按项目画幅比例裁切的占位块，不显示破图图标

### Requirement: 项目卡片暴露风险状态

项目卡片 SHALL 显示该项目当前的风险徽标：缺首帧数量、缺锚点数量与项目是否损坏。空项目 MUST 显示为空项目状态，MUST NOT 显示为「0 镜、0 秒」的正常卡片。

#### Scenario: 缺首帧

- **WHEN** 项目有 10 镜且其中 4 镜没有首帧
- **THEN** 卡片显示「缺首帧 4」徽标

#### Scenario: 项目损坏

- **WHEN** 项目数据无法读取
- **THEN** 卡片以警示样式显示「损坏」，打开入口不可用

### Requirement: 大厅提供最近项目与全部项目

大厅 MUST 分区显示最近打开的项目与全部项目。全部项目 MUST 按最近更新时间倒序；最近项目 MUST 最多 5 个且不重复出现在两组之外。大厅 MUST 提供按标题或目录名筛选的搜索框。

#### Scenario: 最近项目

- **WHEN** 用户最近打开过 3 个项目
- **THEN** 大厅顶部显示这 3 个项目，顺序为最近打开优先

#### Scenario: 搜索

- **WHEN** 用户在搜索框输入项目标题的一部分
- **THEN** 全部项目区只显示匹配的项目，且不改动后端数据

### Requirement: 大厅空态只给创建入口

当本机没有任何项目时，大厅 MUST 只显示新建项目的入口与一句说明，MUST NOT 显示空网格、假项目卡或空统计数据。

#### Scenario: 没有项目

- **WHEN** 本机项目列表为空
- **THEN** 大厅显示「还没有项目」与新建项目按钮，不显示项目网格

### Requirement: 打开项目记住上次视图

系统 SHALL 按项目记住用户最后停留的视图。项目有历史视图时 MUST 恢复到该视图；没有历史时 MUST 落在项目概览。记住的视图属于单个项目，切换项目 MUST NOT 复用上一个项目的视图。

#### Scenario: 回到画布

- **WHEN** 用户上次在项目 A 的画布离开，之后从大厅重新打开 A
- **THEN** 进入 A 的画布，而不是概览

#### Scenario: 新项目

- **WHEN** 用户新建项目并第一次打开
- **THEN** 进入该项目的概览页

### Requirement: 项目概览一屏回答进度与下一步

项目概览 MUST 在一屏内显示集数、镜头数、总时长、缺首帧数量与缺锚点数量，并列出各集的镜数与时长。概览 MUST 提供进入画布与导入分镜的入口。

#### Scenario: 有内容的项目

- **WHEN** 用户打开一个有 3 集 12 镜的项目概览
- **THEN** 一屏内可看到 3 集、12 镜、总时长、缺首帧与缺锚点数量，以及三行的集列表

#### Scenario: 空项目

- **WHEN** 项目还没有任何镜头
- **THEN** 概览显示空项目状态与导入分镜入口，不显示伪造的集或镜头

### Requirement: 概览页只有一个主强调操作

概览页 MUST 最多用一个强调样式按钮表达下一步动作，并按内容状态切换：没有镜头时为导入分镜，有镜头且存在缺首帧时为去画布补帧，全部就绪时为打开画布。其余入口 MUST 使用次级样式。

#### Scenario: 没有镜头

- **WHEN** 项目为 0 镜
- **THEN** 「导入分镜」是唯一强调按钮

#### Scenario: 缺首帧

- **WHEN** 项目有镜头且缺首帧数量大于 0
- **THEN** 「去画布补帧」是唯一强调按钮

#### Scenario: 全部就绪

- **WHEN** 项目有镜头且没有缺首帧
- **THEN** 「打开画布」是唯一强调按钮

### Requirement: 从工作区返回大厅

工作区 MUST 在左栏提供固定可见的返回大厅入口。返回大厅 MUST NOT 删除项目数据或改变当前项目；再次打开同一项目 MUST 回到上次视图。

#### Scenario: 返回再进入

- **WHEN** 用户从项目 A 的画布返回大厅，再次打开 A
- **THEN** 仍在 A 的画布，项目数据未变
