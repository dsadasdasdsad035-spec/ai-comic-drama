# Spec Delta

## MODIFIED Requirements

### Requirement: 全局带提供常驻的新建入口

系统 SHALL 在项目大厅提供常驻的新建项目入口，并在工作区左栏项目菜单提供同一入口；入口 MUST 在任何视口宽度下可用。任何项目视图内 MUST NOT 再出现重复的新建项目入口。目录名 MUST 只接受字母、数字、下划线与短横且不超过 40 字符；同名项目已存在时 MUST 失败且 MUST NOT 覆盖。

#### Scenario: 大厅新建

- **WHEN** 用户在大厅点击新建项目并提交合法目录名
- **THEN** 新项目创建成功，大厅列表刷新，同名项目不被覆盖

#### Scenario: 工作区新建

- **WHEN** 用户从左栏项目菜单选择新建项目
- **THEN** 新建成功后进入新项目的概览页，左栏项目块更新为新项目

#### Scenario: 窄宽度仍可新建

- **WHEN** 用户把窗口缩到窄宽度或折叠左栏
- **THEN** 大厅的新建入口与左栏项目菜单里的新建入口仍然可用

#### Scenario: 视图内没有重复入口

- **WHEN** 用户打开画布、角色、素材、创意或设置视图
- **THEN** 该视图的工具条与内容区不再出现新建项目按钮

#### Scenario: 目录名不合法

- **WHEN** 用户输入包含空格、斜杠或超过 40 字符的目录名
- **THEN** 系统拒绝创建并说明允许的字符与长度

#### Scenario: 同名项目

- **WHEN** 用户新建一个已存在的项目名
- **THEN** 系统报错说明项目已存在，原项目数据保持不变
