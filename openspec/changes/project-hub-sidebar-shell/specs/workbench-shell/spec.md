# Spec Delta

## REMOVED Requirements

### Requirement: 固定的两条操作带

**Reason**: 视图导航从左栏取代头部横排后，外壳不再由两条横向上沿构成；「全局带固定成分与顺序」的契约无法描述左栏 + 头部的新结构。

**Migration**: 由新增的「左栏承载项目视图导航」「头部承载项目位置与集上下文」「视图工具条留在内容列」三条需求替代。全局带的项目身份迁入左栏项目块，集与全局工具留在头部，视图范围/设置/动作迁入内容列顶部的视图工具条。

### Requirement: 全局带承载项目生命周期动作

**Reason**: 项目选择器与项目生命周期入口不再位于头部；新建、管理、删除改由项目大厅与左栏项目菜单承载。

**Migration**: 新建项目入口移到项目大厅；管理项目与删除可从大厅项目卡片菜单或左栏项目菜单进入；设置页保留同一管理面板的次要入口。项目选择器本身迁入左栏项目块。

### Requirement: 顶栏不含提示词视图

**Reason**: 头部不再承载视图导航，改用「工作区导航不含提示词视图」表述同一约束，避免继续引用已不存在的顶栏导航。

**Migration**: 首帧与视频提示词编辑仍只在画布视图提供（单镜 Inspector 与画布内 Agent）；工作区导航不得出现「提示词」或「镜头表」入口。

## ADDED Requirements

### Requirement: 左栏承载项目视图导航

系统 SHALL 在工作区提供固定左栏，承载项目身份、项目菜单与全部项目视图导航。左栏 MUST 在全部视图保持同一位置与结构；当前视图 MUST 同时用 `aria-current` 与视觉激活态表达。左栏 MUST NOT 承载只对单个视图有意义的工具。

#### Scenario: 切换视图不移动左栏

- **WHEN** 用户在概览、创意、角色、素材、画布与设置之间依次切换
- **THEN** 左栏位置、宽度与导航顺序保持不变，只有激活项变化

#### Scenario: 当前项双通道表达

- **WHEN** 用户位于画布视图
- **THEN** 画布项带 `aria-current="page"`，并有可见的激活背景与边条

#### Scenario: 左栏不含视图工具

- **WHEN** 用户打开画布视图
- **THEN** 标注、批量出图、连播与新建素材不出现在左栏

### Requirement: 头部承载项目位置与集上下文

头部 MUST 显示「项目 / 当前视图」的面包屑，并只在这一处提供集选择器。全局工具（任务中心、导出、更多）MUST 位于头部右端。头部 MUST NOT 重复项目选择器、视图导航或项目生命周期动作。

#### Scenario: 面包屑

- **WHEN** 用户在项目 A 的画布视图
- **THEN** 头部显示项目 A 与「画布」，不显示第二个项目名

#### Scenario: 集只出现一次

- **WHEN** 用户依次打开概览、创意、角色、素材与画布
- **THEN** 每个视图只有头部一个集选择器，内容区不重复集号选择控件

#### Scenario: 设置无集上下文

- **WHEN** 用户打开设置视图
- **THEN** 头部不显示集选择器

### Requirement: 视图工具条留在内容列

视图的范围、视图级设置与动作 MUST 放在内容列顶部的视图工具条中，MUST NOT 进入左栏或头部。没有视图级内容的视图 MUST NOT 显示空的工具条占位。视图工具条 MUST 按「范围、设置、动作」固定三段位排列。

#### Scenario: 画布工具条

- **WHEN** 用户打开画布视图
- **THEN** 分镜摘要、目标时长与导入/插入/拆镜助手出现在内容列顶部的工具条里

#### Scenario: 无视图级内容

- **WHEN** 用户打开设置视图
- **THEN** 内容列顶部不显示空的工具条

### Requirement: 左栏可折叠为图标栏

左栏 SHALL 可折叠为 64px 图标栏，并记住用户在当前会话的选择。画布视图在可用宽度低于 1400px 时 MUST 自动折叠；用户手动展开后 MUST 以手动状态为准，不在该视图内再次自动折叠。折叠态每个入口 MUST 保留可读标签（tooltip 或 `aria-label`）与激活指示。

#### Scenario: 手动折叠

- **WHEN** 用户手动折叠左栏后切换到角色视图
- **THEN** 左栏保持折叠，角色入口仍可通过图标与 tooltip 辨认

#### Scenario: 画布自动折叠

- **WHEN** 用户在 1280px 宽的窗口打开画布视图
- **THEN** 左栏折叠为图标栏，画布获得剩余宽度

#### Scenario: 手动优先

- **WHEN** 用户在画布视图手动展开左栏后继续操作
- **THEN** 左栏保持展开，不因视图内操作自动折叠

### Requirement: 工作区导航不含提示词视图

工作区导航 MUST NOT 包含「提示词」或「镜头表」入口；首帧与视频提示词编辑 MUST 只在画布视图提供（单镜 Inspector 与画布内 Agent）。

#### Scenario: 导航项列表

- **WHEN** 用户查看左栏的项目视图导航
- **THEN** 不存在指向 `prompts` 或 `table` 视图的入口

## MODIFIED Requirements

### Requirement: 项目与集只出现一次

系统 MUST 让项目与集各自只在一个固定位置出现一次：项目由左栏项目块表达，集由头部集选择器表达。其他区域 MUST NOT 重复显示项目名、项目路径或集号来充当状态。

#### Scenario: 单一项目入口

- **WHEN** 用户依次打开全部视图
- **THEN** 每个视图只有左栏一个项目块，且没有第二处项目名文本

#### Scenario: 单一集入口

- **WHEN** 用户在任一项目视图查看当前集
- **THEN** 集号只由头部集选择器显示，聊天面板头部不再重复集号

### Requirement: 视图专属工具留在视图内

只对一个视图有意义的工具 MUST 呈现在该视图内部或视图工具条中，MUST NOT 占据头部。画布的标注、批量操作、新建素材、导入、连播与分镜摘要 MUST 以画布内工具条或视图工具条呈现。

#### Scenario: 画布工具位置

- **WHEN** 用户打开画布视图
- **THEN** 标注、批量操作、新建素材、导入与连播出现在画布内的浮动工具条或视图工具条中

#### Scenario: 其他视图的全局带

- **WHEN** 用户打开设置视图
- **THEN** 头部与视图工具条中不出现标注、批量出图或连播控件

### Requirement: 上沿不放常驻说明文字

头部与视图工具条 MUST 只承载操作与状态摘要；长篇说明 MUST NOT 常驻。空板提示 SHOULD 以一行可关闭提示呈现，有内容后 MUST 消失。

#### Scenario: 板内有内容

- **WHEN** 角色板或素材板已有卡片
- **THEN** 上沿不显示多行说明段落

#### Scenario: 空板

- **WHEN** 角色板或素材板为空
- **THEN** 显示一行可关闭的起始提示，关闭后本次会话不再出现

### Requirement: 窄宽度下保持可读

头部标签 MUST 保持词内完整或以省略号截断，MUST NOT 逐字换行。左栏在窄屏 MUST 折叠为图标栏或抽屉，MUST NOT 把导航折成多行。视图工具条在内容列变窄时 MUST 收起次要信息而不是让控件折行。

#### Scenario: 中等宽度

- **WHEN** 视口宽度为 1440px 且左栏展开
- **THEN** 头部与视图工具条不出现「项/目」「模/型」这类逐字换行

#### Scenario: 聊天抽屉挤压内容列

- **WHEN** 用户打开工作台聊天，内容列变窄
- **THEN** 视图工具条收起范围细节并保留主操作，控件不换行

#### Scenario: 窄屏

- **WHEN** 视口宽度低于应用窄屏断点
- **THEN** 左栏折叠为图标栏或抽屉，头部保留面包屑与当前视图名，导航仍完整可用

### Requirement: 外壳的键盘与语义

左栏导航 MUST 用 `aria-current` 标识当前视图；集选择 MUST 使用可键盘操作的弹出列表语义，支持展开、方向键选择、Esc 关闭与焦点归还。左栏折叠 MUST 可用键盘触发并保持每个入口的可读标签。外壳 MUST 按视觉顺序提供可预测的 Tab 顺序：左栏 → 头部 → 视图工具条 → 内容。

#### Scenario: 当前视图语义

- **WHEN** 用户位于画布视图
- **THEN** 画布项暴露当前项状态，屏幕阅读器可识别

#### Scenario: 键盘选择集

- **WHEN** 用户聚焦集选择器并按方向键、回车或 Esc
- **THEN** 可在不离开键盘的情况下切换或取消切换集，焦点回到触发按钮

#### Scenario: Tab 顺序

- **WHEN** 用户从页面顶部开始按 Tab
- **THEN** 焦点依次经过左栏项目块、左栏导航、头部集选择与全局工具、视图工具条、内容

#### Scenario: 键盘折叠

- **WHEN** 用户按下左栏折叠快捷键
- **THEN** 左栏在展开与折叠间切换，焦点留在触发按钮上
