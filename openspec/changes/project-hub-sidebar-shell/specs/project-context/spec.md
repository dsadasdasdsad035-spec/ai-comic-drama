# Spec Delta

## MODIFIED Requirements

### Requirement: 全站可见的项目选择

系统 SHALL 以项目大厅作为项目选择入口，并在工作区左栏的项目块显示当前项目或「未选项目」状态。左栏项目块 MUST 提供切换最近项目、管理项目与返回大厅的菜单。切换项目 MUST 立即更新全局项目上下文。各项目视图 MUST NOT 再各自提供项目选择器。

#### Scenario: 各视图都能看到项目

- **WHEN** 用户依次打开概览、创意、角色、素材、画布和设置页
- **THEN** 左栏项目块始终显示当前项目名，且提供项目菜单

#### Scenario: 切换项目更新上下文

- **WHEN** 用户在左栏项目菜单选择另一个项目
- **THEN** 全局项目名更新，所有视图再次打开时使用新项目，并落回该项目的上次视图

#### Scenario: 大厅选择项目

- **WHEN** 用户从项目大厅打开一个项目
- **THEN** 左栏项目块显示该项目，内容区显示该项目上次视图

#### Scenario: 发布页显示当前项目

- **WHEN** 用户打开发布页
- **THEN** 待发布列表与发布记录只使用左栏当前项目，页面不重复显示项目名

#### Scenario: 没有项目

- **WHEN** 用户通过返回键回到大厅或本机没有任何项目
- **THEN** 工作区不再显示任何项目上下文，大厅显示「还没有项目」与新建入口，不自动创建项目

### Requirement: 切换项目时重载项目数据

系统 SHALL 在项目切换后重新加载该项目的剧本、分集、镜头、角色、素材、画布状态、成片版本与发布配置；上一项目的未保存编辑 MUST NOT 静默写入新项目。切换项目时左栏项目块、头部面包屑与集选择器 MUST 在同一帧更新为目标项目的上下文。

#### Scenario: 切换后读取新项目

- **WHEN** 用户从项目 A 切换到项目 B
- **THEN** 剧本、画布、角色和发布页展示 B 的数据，不保留 A 的项目数据

#### Scenario: 未保存的剧集编辑

- **WHEN** 剧本页有未保存的分集，用户切换项目
- **THEN** 系统提示先保存或放弃，不把未保存分集带到 B

#### Scenario: 画布不串项目

- **WHEN** 用户从 A 切换到 B 后继续编辑画布
- **THEN** 写入只发生到 B，A 的镜头和画布状态不被修改

#### Scenario: 发布配置不串项目

- **WHEN** 用户在 A 的发布台配置文案、封面或发布方式后切换到 B
- **THEN** B 的发布台不显示 A 的成片与配置，A 的发布配置不被修改

#### Scenario: 外壳同步更新

- **WHEN** 用户从左栏菜单切换到项目 B
- **THEN** 左栏项目块、头部面包屑与集选择器同时显示 B 的上下文，不残留 A 的项目名或集号

### Requirement: 删除项目后的全局上下文回退

项目被删除后，系统 SHALL 立即更新项目大厅列表；若删除的是当前项目，MUST 清除该项目上下文并返回项目大厅，MUST 清除该项目的浏览器画布状态。删除非当前项目时 MUST 留在当前工作区。回退后 MUST NOT 显示已删除项目的镜头、角色、成片或发布记录，也 MUST NOT 把旧项目数据写入任何其他项目。

#### Scenario: 删除当前项目

- **WHEN** 用户删除当前正在使用的项目
- **THEN** 系统返回项目大厅，工作区不再显示该项目的镜头、角色或成片

#### Scenario: 删除非当前项目

- **WHEN** 用户删除一个不是当前项目的项目
- **THEN** 当前项目与各视图内容保持不变，只有大厅列表少一项

#### Scenario: 画布状态被清除

- **WHEN** 删除项目后用同名重新创建并打开画布
- **THEN** 画布不恢复被删除项目的节点与连线

#### Scenario: 删除最后一个项目

- **WHEN** 系统中只剩一个项目且被删除
- **THEN** 界面停留在大厅并显示空态，系统不自动创建新项目

#### Scenario: 删除后不再写入旧项目

- **WHEN** 用户删除项目后在回退后的上下文里保存数据
- **THEN** 写入只发往回退后的项目，不触发针对已删除项目的请求
