# Spec Delta

## REMOVED Requirements

### Requirement: 创意视图不改变全局导航位置

**Reason**: 创作导航已迁入固定左栏，不再存在头部横向导航；「切换创意后导航水平位置偏移不超过 2px」不再描述任何真实结构。

**Migration**: 由 `workbench-shell` 的「左栏承载项目视图导航」替代：左栏在全部视图保持同一位置与宽度，创意视图也必须保留项目身份、集选择与左栏导航。

## ADDED Requirements

### Requirement: 创意继承当前项目上下文

创意视图 MUST 绑定当前项目，使用该项目的风格、角色、素材与集上下文。创意视图 MUST 在左栏项目块之外再显示当前项目名与集号的状态摘要；MUST NOT 在无项目状态下允许向项目写入产物。

#### Scenario: 有项目

- **WHEN** 用户从项目 A 的左栏打开创意
- **THEN** 创意使用 A 的风格、角色与本集上下文，产物提升后写入 A

#### Scenario: 无项目

- **WHEN** 用户没有打开任何项目
- **THEN** 创意入口不可用或明确提示先选择项目，不产生跨项目写入

### Requirement: 创意会话按项目隔离

创意会话列表 MUST 只列当前项目的会话。历史遗留的未绑定项目会话 MUST 收纳在独立的「未绑定」分组， MUST NOT 与当前项目会话混排。打开未绑定会话 MUST 标记其未绑定状态；用户未明确绑定到当前项目前，MUST NOT 向其发送会写入项目的请求。

#### Scenario: 只看到本项目会话

- **WHEN** 当前项目有 2 个会话，本机另有 3 个未绑定会话
- **THEN** 列表默认显示 2 个项目会话，未绑定会话收在单独分组且不超过一行摘要

#### Scenario: 打开未绑定会话

- **WHEN** 用户打开一个未绑定会话
- **THEN** 会话头部显示「未绑定」标记，发送入口在绑定前保持禁用并说明绑定后才会写入项目

#### Scenario: 绑定后写入

- **WHEN** 用户把未绑定会话绑定到当前项目
- **THEN** 之后的消息与产物写入该项目，会话出现在当前项目的会话列表

## MODIFIED Requirements

### Requirement: 产物与对话并列为两列

创意视图 MUST 把源视频、镜头切分、提示词包与生成结果呈现在对话右侧的独立栏，MUST NOT 让产物占据对话上方的横向条带。产物栏 MUST 可折叠，折叠后对话列占满剩余宽度且消息不丢失、不重排。没有产物时 MUST NOT 显示空栏或空占位。加入左栏与会话列表后，产物栏 MUST 仍紧贴对话右侧，不因列数增加移到对话上方。

#### Scenario: 有产物时对话高度不受挤压

- **WHEN** 会话有源视频、镜头切分或提示词包
- **THEN** 产物显示在对话右侧，对话的可视高度与没有产物时相同

#### Scenario: 折叠产物栏

- **WHEN** 用户折叠产物栏
- **THEN** 对话列扩展到占满剩余宽度，消息内容与滚动位置保持不变

#### Scenario: 没有产物

- **WHEN** 新会话既没有源视频也没有产物
- **THEN** 界面只显示对话列，不出现空的产物栏

### Requirement: 对话列有固定的阅读宽度

消息正文与输入框 MUST 在扣除左栏、会话列表与产物栏后的可用宽度内保持 560–640px 的最大宽度并水平居中；在此宽度内 13px 正文字号每行 MUST NOT 超过 50 个汉字。窗口加宽时 MUST 增加两侧留白，MUST NOT 继续拉宽正文。

#### Scenario: 宽屏下的正文宽度

- **WHEN** 视口宽度为 1500px，左栏展开、会话列表与产物栏均展开
- **THEN** 助手消息段落与输入框的渲染宽度都不超过 640px，并且左右留白对称

#### Scenario: 左栏折叠后不拉宽正文

- **WHEN** 用户折叠左栏，省出更多可用宽度
- **THEN** 对话正文仍不超过 640px，新增宽度变成两侧留白

#### Scenario: 窄屏不缩窄正文

- **WHEN** 视口宽度低于对话列所需宽度
- **THEN** 正文占满可用宽度，不出现因居中或最小宽度导致的横向滚动

### Requirement: 会话列表给足可辨认信息

每个会话行 MUST 显示标题、模式与最近更新时间的相对表述；标题区可用宽度 MUST 不小于 150px。改名与删除 MUST NOT 以常驻文字占位，SHOULD 收进悬停或键盘聚焦时出现的操作入口，且 MUST 可用键盘到达。会话行 MUST NOT 重复显示项目名来区分来源，项目隔离由列表范围表达。

#### Scenario: 区分未命名会话

- **WHEN** 会话列表里存在多个未命名会话
- **THEN** 每行显示各自的模式与相对更新时间，用户可据此区分

#### Scenario: 键盘操作会话

- **WHEN** 用户用 Tab 聚焦某个会话行
- **THEN** 该行的改名与删除入口可见且可聚焦

#### Scenario: 不靠项目名区分

- **WHEN** 用户查看当前项目的会话列表
- **THEN** 每行不显示项目名，列表整体已经限定在当前项目
