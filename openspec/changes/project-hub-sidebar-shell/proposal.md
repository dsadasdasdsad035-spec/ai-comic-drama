# Proposal

## Why

项目是系统里所有数据的唯一边界，但当前外壳把「项目」当成顶栏里的一个下拉：启动直接进画布，新建与管理埋在「项目 ▾」二级菜单，项目级信息（集、统计、健康度）没有归处。主导航横排在 52px 头部，与项目、集、全局工具挤在同一条带里；创意与设置各自带左栏、其他视图没有，视图切换时缺少稳定锚点；画布又最需要横向空间。

## What Changes

- 新增项目大厅作为唯一入口（`#/`）：继续创作 + 全部项目卡片（封面、标题、风格·画幅、集·镜·秒、更新时间、缺首帧/缺锚点/损坏徽标）+ 新建项目；空态只给新建项目。
- 项目工作区改为「左栏 + 头部 + 内容」三区。左栏 240px、可折叠 64px，承载项目身份、项目菜单（最近项目 / 管理项目 / 返回大厅）、视图导航（概览/创意/角色/素材/画布/设置）与底部全局工具（主题、任务中心）；头部 56px 只放面包屑、集选择器与全局工具（任务、导出、更多）。
- 新增项目概览页（最小版，一屏）：集数/镜头数/时长/缺首帧/缺锚点 + 集列表 + 三个动作；强调按钮按「无镜 → 导入分镜、缺首帧 → 去画布补帧、就绪 → 打开画布」切换。
- 从大厅打开项目默认回到该项目上次离开的视图；新项目落到概览。
- 创意视图绑定当前项目：会话按项目隔离，历史无项目会话归入「未绑定」分组；布局变成 app 左栏 / 会话列表 / 对话 / 产物四栏。
- 画布视图在可用宽度小于 1400px 时自动把左栏折叠为 64px 图标栏；用户手动切换后以手动状态为准。
- **BREAKING**：移除头部横向视图 tabs；项目选择器与项目生命周期入口从头部移到大堂与左栏；创意不再是无项目视图；头部高度由 52px 变为 56px。
- **不改动**：画布、角色、素材、设置四个视图的内部组件、数据流、生成与计费逻辑；项目删除的服务端级联与快照逻辑；构建与部署方式。

## Capabilities

### New Capabilities

- `project-hub`: 项目大厅作为全站入口的能力：最近项目、项目卡片信息与状态徽标、空态、打开/新建/管理入口、返回大厅。

### Modified Capabilities

- `workbench-shell`: 外壳契约从「最多两条横向上沿」改为「左栏 + 头部 + 视图工具条」，重写导航、语义、焦点顺序与窄宽度行为；删除全局带成分与顺序的条款。
- `project-context`: 项目上下文入口从顶栏改为大厅与左栏项目菜单，新增上次视图记忆与删除后回大厅，保留单一项目入口与切换重载契约。
- `creative-layout`: 创意视图显示项目与集上下文、会话按项目隔离、四栏宽度契约；删除「创意不显示项目/集」与「导航水平位置偏移 ≤2px」条款。
- `project-lifecycle`: 新建与管理入口从全局带移到大堂与左栏项目菜单，删除后回到大堂，其余新建校验、删除预览、强确认与级联清理不变。

## Impact

- 代码：新增 `src/shell/`（`AppShell`、`SideNav`、`ProjectHub`、`ProjectCard`、`ProjectSwitcher`、`OverviewPage`）；`src/App.tsx` 只改外壳编排；`src/theme.css` 新增 `--rail-w` / `--rail-w-collapsed` / `--header-h` 与大厅、左栏样式；`src/creative/sessionStore.ts` 会话增加项目字段。
- API：可选在 `server/db.mjs` 的 `listProjects` 增加首帧封面字段；前端在缺失时使用风格色块占位。
- 本机存储：`sb.railCollapsed`、`sb.lastView.<项目>`。
- 验收：`verify-theme.mjs`、`verify-creative-ui.mjs`、`verify-publish-ui.mjs` 依赖 `.topbar` / `.viewtabs`，需保留兼容选择器或迁移断言；新增左栏与大厅的验收脚本。
- 不在本次范围：从压缩包新建项目、⌘K 全局搜索、发布视图、项目卡片真实封面生成。
