# Spec Delta

## MODIFIED Requirements

### Requirement: 聊天页签切换不得丢失会话

聊天面板 MUST 在打开的工作台内保持会话；切换到代码页签 MUST NOT 卸载聊天状态、清空消息/工具结果/关键帧/验收清单/滚动位置，MUST NOT 取消正在运行的 agent。关闭工作台 MAY 结束运行会话并释放沙箱，但 MUST 保留该镜头的线程记录；重新打开同一项目同一镜头时 MUST 恢复此前的消息、工具卡摘要、技能激活状态和产物引用。

#### Scenario: 已完成会话切换

- **WHEN** 聊天已经产生消息、工具卡和验收清单，用户切到代码页签再切回
- **THEN** 所有消息、卡片、帧和清单仍在，内容顺序不变

#### Scenario: 运行中切换

- **WHEN** agent 正在运行，用户切到代码页签
- **THEN** agent 继续执行，不被取消；切回聊天时能看到已完成和正在进行的步骤

#### Scenario: 滚动位置

- **WHEN** 用户在聊天中滚动到较早的工具步骤后切换页签再回来
- **THEN** 聊天仍保留原来的滚动位置

#### Scenario: 关闭工作台

- **WHEN** 用户关闭工作台
- **THEN** 当前运行会话结束并释放沙箱，线程记录保留，不要求保持运行状态

#### Scenario: 重新打开同一镜头

- **WHEN** 用户重新打开该镜头的 3D 工作台
- **THEN** 聊天恢复此前的消息、工具卡摘要和技能激活状态，已保存的视频和代码仍可查看

#### Scenario: 关闭时正在运行

- **WHEN** agent 正在运行时用户关闭工作台
- **THEN** 本次运行标记为已取消并停止产生新事件，线程保留取消前的已确认内容，重新打开后可以继续发起新一轮
