# Spec Delta

## MODIFIED Requirements

### Requirement: 按能力显式路由且不做自动回退

系统 SHALL 以设置中每个能力选定的渠道与模型为准发起请求；一个渠道不支持某能力时 MUST NOT 出现在该能力的选择列表中；请求失败时 MUST 直接返回错误，不得自动改用其他渠道重试。

「生成图片」与「生成三视图」MUST 视为同一个生图能力。只要模型能生图，它就 MUST 同时出现在设定图、场景与道具设计图、角色三视图与表情总图、画布首帧等所有生图位置的可选列表里，任一方向的声明都 MUST 算数。该规则是本要求中「不支持某能力时不得出现」的**唯一例外**，MUST NOT 扩展到文本、视频、配音等其他能力。

生图的默认选择 MUST 仍分为图像与三视图两个独立默认位，用户可以分别指定不同模型；未手动选择某个位置时，该位置 MUST 继续使用它自己的默认位，MUST NOT 因为两个默认位指向不同模型而互相顶替。

用户在某处显式选中的模型 MUST 作用于这一次请求，MUST NOT 因为该模型的主声明是另一个生图能力就被替换成默认位的模型。

#### Scenario: 视频继续走标准方舟

- **WHEN** 用户生成视频或视频参考
- **THEN** 请求使用标准方舟渠道配置的视频模型与 Key

#### Scenario: Agent Plan 失败不自动重试

- **WHEN** Agent Plan 的文本或图片请求返回模型不支持或鉴权错误
- **THEN** 画布直接显示该错误，不向标准方舟渠道重新提交

#### Scenario: 文本切回标准方舟

- **WHEN** 用户把文本默认模型切换为绑定标准方舟渠道的模型
- **THEN** 后续文本请求使用标准方舟 Base URL 与 Key，不影响图片的 Agent Plan 选择

#### Scenario: 场景与道具设计图选到三视图模型

- **WHEN** 用户在场景或道具的生图下拉里选中一个主声明为三视图的模型并生成
- **THEN** 请求使用该模型生成设计图，存入设计图目录，不回落默认图像模型

#### Scenario: 三视图选到图像模型

- **WHEN** 用户在角色三视图下拉里选中一个主声明为图像的模型并生成
- **THEN** 请求使用该模型生成三视图，存入角色目录，不回落默认三视图模型

#### Scenario: 两个默认位互不影响

- **WHEN** 图像默认位与三视图默认位指向不同模型
- **THEN** 未手动选择时，两处各自使用自己的默认位，互不顶替

#### Scenario: 生图模型不出现在文本位置

- **WHEN** 用户在文本、视频或配音位置打开可选模型列表
- **THEN** 生图模型不出现，家族规则不外溢

## ADDED Requirements

### Requirement: 生图请求必须遵守模型的参考图能力

当一次生图请求带参考图，而选中的模型或渠道不支持参考图时，系统 MUST 让这次生成失败并返回可读错误，说明该模型不接受参考图并提示更换模型。系统 MUST NOT 丢弃参考图后继续生成，也 MUST NOT 回一个成功并只在附带提示里提一句。

没有参考图的请求 MUST NOT 因此被拒绝：同一个模型在不带参考图时 MUST 正常出图。

#### Scenario: 三视图选了不支持参考图的模型

- **WHEN** 角色已有参考图，用户选中的三视图模型不支持参考图
- **THEN** 生成失败，错误说明该模型不接受参考图并提示更换模型

#### Scenario: 表情总图选了不支持参考图的模型

- **WHEN** 生成表情总图时带参考图，而选中模型不支持参考图
- **THEN** 生成失败并给出同样的可读错误，不产出缺参考图的图

#### Scenario: 同一模型不带参考图

- **WHEN** 同一个不支持参考图的模型在没有参考图时被选中
- **THEN** 正常生成，不报错
