# Spec Delta

## MODIFIED Requirements

### Requirement: 每镜代码是唯一场景真相

系统 SHALL 为每个镜头保存一段 `SceneCode`，包含代码文本、运行时标识、引擎版本、ABI 版本、代码哈希、来源和更新时间。代码 MUST 是该镜头新 3D 渲染的唯一场景描述；系统 MUST NOT 从代码反向维护结构化空间清单，也 MUST NOT 让两个镜头共享同一可变代码对象。

#### Scenario: 保存后重开

- **WHEN** 用户保存一个镜头的代码并重新打开该项目
- **THEN** 该镜头恢复同一段代码、运行时标识、引擎版本、ABI 版本和代码哈希

#### Scenario: 两个镜头独立

- **WHEN** S01 和 S02 各自有代码，用户修改 S01
- **THEN** S02 的代码、预览和渲染结果不变

#### Scenario: 手改代码

- **WHEN** 用户直接修改代码文本并成功渲染
- **THEN** 代码哈希更新，来源标记为手改

#### Scenario: 引擎升级

- **WHEN** 本机 Blender 版本与代码记录的引擎版本不同
- **THEN** 该镜调度视频标为过期，重新渲染前不用于下游参考

### Requirement: 运行时提供最小 ABI

代码 MUST 按 `build(ctx)`、`pose(t, mode)`、`dispose()` 三个入口组织。`ctx` MUST 提供场景、相机、已选素材的稳定键访问、宽度、高度、画幅和镜头时长；`t` MUST 是以秒为单位的 0 到时长之间的时间；`mode` MUST 为 `clean` 或 `review`。宿主 MUST 按时间点设置帧、调用 `pose(t, mode)` 并渲染当前场景；代码 MUST 使用场景和相机对象输出最终画面。

#### Scenario: 最小场景

- **WHEN** 代码在 `build` 中向场景添加一个立方体并设置相机
- **THEN** 试运行、代理预览和定稿渲染都能看到该立方体

#### Scenario: 时间驱动运动

- **WHEN** 代码在 `pose` 中按 `t` 移动物体或相机
- **THEN** 播放代理片、拖动时间轴和定稿渲染都按同一时间函数变化

#### Scenario: 清理

- **WHEN** 编辑器关闭或代码被替换
- **THEN** 运行时调用 `dispose`，释放自定义数据块、节点组和临时贴图

### Requirement: 选中素材以稳定键注入

运行时 SHALL 把当前镜头选中的图片和视频关键帧作为素材注入一次性工作目录，每个素材 MUST 有稳定键、类型、尺寸和可读取的本地副本。代码 MUST 通过稳定键取副本路径，MUST NOT 依赖外部 URL 或网络访问；视频 MUST 以其关键帧和时长元数据进入运行时，MUST NOT 依赖视频文件逐帧播放。缺失或损坏素材 MUST 以缺失项呈现，不能导致整个代码无法运行。

#### Scenario: 角色图作为纹理

- **WHEN** 代码通过稳定键读取一个选中的角色图
- **THEN** 代码能拿到可读副本并把它用于材质或背景板

#### Scenario: 视频关键帧

- **WHEN** 用户选中一个视频
- **THEN** 代码素材中包含该视频的关键帧文件和时长元数据

#### Scenario: 缺失素材

- **WHEN** 某个选中素材已从项目中删除
- **THEN** 运行时报告该素材缺失，其他素材和代码仍可运行

### Requirement: 代码必须试运行成功后才可应用

代码在替换当前结果前 MUST 通过大小、语法、必需入口、静态越权检查和渲染试运行。试运行 MUST 至少执行 `build` 并渲染开头与结尾两个时间点；任一步失败、超时或未产生可渲染画面时 MUST 返回可读错误，MUST NOT 写入项目。

#### Scenario: 语法错误

- **WHEN** 聊天返回的代码有语法错误
- **THEN** 编辑器保留旧代码并显示错误位置和原因

#### Scenario: 缺少入口

- **WHEN** 代码没有定义 `pose`
- **THEN** 准入被拒绝，旧预览不变

#### Scenario: 首尾帧失败

- **WHEN** `build` 成功但结尾时间点渲染失败
- **THEN** 代码不被应用，旧代码继续有效

### Requirement: 预览支持播放、暂停、定位与抓帧

编辑器 SHALL 支持播放、暂停和拖动时间轴；播放 MUST 基于已渲染的代理片，拖动 MUST 在已渲染帧上定位或触发该时间点的单帧渲染，MUST NOT 伪装成实时预览。运行时 MUST 能按请求返回指定时间点的帧图片，供缩略图和错误定位使用。

#### Scenario: 拖动时间轴

- **WHEN** 用户把时间轴拖到 2.4 秒
- **THEN** 预览显示代理片 2.4 秒的帧；该帧尚未渲染时触发单帧渲染并显示进度

#### Scenario: 抓取当前帧

- **WHEN** 用户或系统请求当前帧缩略图
- **THEN** 渲染服务返回该时间点的图片

#### Scenario: 暂停

- **WHEN** 用户暂停播放
- **THEN** 画面停在当前时间，不继续推进

### Requirement: 渲染必须可取消且不产生半成品

渲染 MUST 按确定帧率逐帧推进并输出完整帧序列后编码为视频；用户取消、关闭编辑器或渲染进程崩溃时 MUST 终止作业并丢弃未完成结果。只有完整渲染成功后才可保存视频并更新镜头；失败或取消 MUST 保留旧视频。

#### Scenario: 取消渲染

- **WHEN** 用户在渲染进度中点击取消
- **THEN** 不产生新视频文件，旧调度视频仍可用

#### Scenario: 录制完成

- **WHEN** 渲染作业正常结束
- **THEN** 视频保存为本地可访问文件并写入镜头

#### Scenario: 录制中断

- **WHEN** 渲染进程在作业中崩溃
- **THEN** 不保存半成品，界面显示错误

### Requirement: 执行超时必须终止并恢复

运行时 MUST 为试运行、单帧和整段渲染设置超时；超时后系统 MUST 终止渲染进程并清理临时工作目录，MUST NOT 让界面无限等待。超时 MUST 保留上一版代码和视频，并把错误显示为可重试状态。

#### Scenario: 初始化死循环

- **WHEN** 代码在 `build` 中进入无限循环
- **THEN** 达到试运行超时后进程被终止，旧代码仍可继续使用

#### Scenario: 单帧过慢

- **WHEN** 某一帧超过单帧预算
- **THEN** 试运行失败并提示性能问题

#### Scenario: 超时后重试

- **WHEN** 用户修正代码后再次运行
- **THEN** 使用新的渲染作业执行，不继承上次崩溃状态

### Requirement: 代码与素材指纹决定过期

系统 SHALL 记录渲染指纹，至少覆盖代码哈希、运行时标识、引擎版本、ABI 版本、参与渲染的素材指纹、有效时长和画幅。任一输入变化时该镜调度视频 MUST 标为过期，并在作为 Seedance 参考视频或抽帧参考前要求重渲；MUST NOT 静默复用旧视频。过期判断 MUST 只影响当前镜头。

#### Scenario: 改代码后过期

- **WHEN** 用户修改代码但还没有重新渲染
- **THEN** 当前镜视频显示已过期

#### Scenario: 改选中素材后过期

- **WHEN** 用户替换了一个参与渲染的角色图
- **THEN** 当前镜视频显示已过期

#### Scenario: 其他镜头不变

- **WHEN** S01 的代码变化
- **THEN** S02 的过期状态不变

### Requirement: 代码资源有明确上限

系统 MUST 限制代码大小、素材数量、单张图片尺寸、渲染分辨率、帧率、采样、单作业总时长、并发作业数和产物体积；超限 MUST 返回可读错误，MUST NOT 让界面卡死或耗尽磁盘。限制值 MUST 在编辑器中可见或在错误信息中说明。

#### Scenario: 代码过大

- **WHEN** 代码超过大小上限
- **THEN** 准入被拒绝并提示上限

#### Scenario: 素材过多

- **WHEN** 用户选择的图片超过运行时上限
- **THEN** 超出部分不注入，界面明确提示

#### Scenario: 图片过大

- **WHEN** 选中图片尺寸超过上限
- **THEN** 系统缩放或拒绝并说明原因

## ADDED Requirements

### Requirement: 本地执行受静态准入与工作目录约束

代码 MUST 在本机隔离进程内执行，进程 MUST 以一次性工作目录为工作路径，并通过受支持的启动参数屏蔽用户插件与非必要缓存。准入 MUST 拒绝操作系统命令、进程创建、网络访问、动态导入和项目目录写入；渲染 MUST 只通过固定作业协议启动，MUST NOT 提供交互式控制台或任意代码求值入口。

#### Scenario: 危险导入

- **WHEN** 代码导入进程、网络或系统命令相关模块
- **THEN** 准入拒绝执行并说明违规项

#### Scenario: 写入项目目录

- **WHEN** 代码尝试写入项目目录、家目录或其他镜头输出
- **THEN** 运行阶段失败或只写入本次临时副本，原始数据不变

#### Scenario: 资源消耗

- **WHEN** 代码申请超出上限的内存、磁盘或无限循环
- **THEN** 作业在单帧或总时长预算内被终止

## REMOVED Requirements

### Requirement: 沙箱阻断网络与父页面访问

**Reason**: 运行时由浏览器 iframe 改为本机 Blender 进程，不存在父页面、同源策略或 CSP 这层边界；继续声称"沙箱隔离"会误导用户对执行权限的判断。

**Migration**: 安全约束由新增的"本地执行受静态准入与工作目录约束"承接：静态拒绝危险导入与越界路径、一次性工作目录、受支持的启动参数与进程级终止。用户需知悉该执行模型以本机用户权限运行代码，不再具备浏览器沙箱的隔离强度。
