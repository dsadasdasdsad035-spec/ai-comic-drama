# Spec Delta

## MODIFIED Requirements

### Requirement: 五个内容工作台提供清空当前对话

系统 SHALL 在剧本、角色、素材、镜头表、提示词五个内容工作台聊天，以及 **3D 调度工作台内当前镜头的 agent 聊天** 中提供清空当前对话的入口。清空 MUST 只作用于当前线程键（项目，或项目加集，或项目加镜头 id），MUST NOT 清空其他工作台、其他集、其他镜头或其他项目的线程。

#### Scenario: 剧本聊天清空

- **WHEN** 用户在某项目的剧本聊天确认清空对话
- **THEN** 该项目剧本线程的消息消失，角色、素材聊天仍保留各自消息

#### Scenario: 镜头表按集隔离

- **WHEN** 用户在第 1 集镜头表聊天确认清空
- **THEN** 第 1 集镜头表线程被清空，第 2 集镜头表线程不变

#### Scenario: 3D 按镜头隔离

- **WHEN** 用户在镜头 A 的 3D 工作台 agent 聊天确认清空
- **THEN** 镜头 A 的 scene3d 线程被清空，同一项目镜头 B 的 agent 聊天不变
