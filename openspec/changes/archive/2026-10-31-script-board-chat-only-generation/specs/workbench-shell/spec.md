# Spec Delta

## MODIFIED Requirements

### Requirement: 每个视图只有一个主强调操作

每个视图 MUST 最多用一个强调样式按钮表达当前下一步动作；全局工具 MUST 使用非强调样式。角色页与素材页的主强调操作 SHALL 随内容状态在拆解与加入画布之间切换。剧本视图上下文带 MUST NOT 将「生成分集」或「重新生成分集」作为强调或非强调动作按钮；剧本的拆集下一步在 Agent 内完成，顶栏保存在有未保存草稿时 MAY 使用强调样式。

#### Scenario: 镜头表主操作

- **WHEN** 镜头表有未推送的镜头
- **THEN** 生成到画布是唯一的强调按钮，导出与主题切换不是强调样式

#### Scenario: 角色页状态切换

- **WHEN** 角色板为空
- **THEN** 从本集拆角色是强调操作；当存在未加入画布的已生成角色设定时，全部加入画布成为强调操作

#### Scenario: 剧本页无顶栏拆集

- **WHEN** 用户打开剧本视图
- **THEN** 上下文带动作区不出现「生成分集」类按钮；有未保存草稿时「保存」可为唯一强调按钮
