# Spec Delta

## MODIFIED Requirements

### Requirement: 视图专属工具留在视图内

只对一个视图有意义的工具 MUST 呈现在该视图内部，MUST NOT 占据全局带。画布的标注、批量操作、新建素材、导入、导出、连播与分镜摘要 MUST 以画布内工具条或视图上下文带呈现。分镜表导出属于视图内工具，全局带 MUST NOT 承载任何分镜或分集内容的导出动作。

#### Scenario: 画布工具位置

- **WHEN** 用户打开画布视图
- **THEN** 标注、批量操作、新建素材、导入、导出与连播出现在画布内的浮动工具条或上下文带中

#### Scenario: 其他视图的全局带

- **WHEN** 用户打开剧本视图
- **THEN** 全局带中不出现标注、批量出图、连播或分镜导出控件
