# Spec Delta

## MODIFIED Requirements

### Requirement: 画布是分镜唯一工作台

系统 SHALL 以画布作为分镜的查看与编辑视图，MUST NOT 提供「镜头表」项目视图或等价的全集可编辑表格（含抽屉、只读表、批量字段编辑）。分镜字段的人手编辑 MUST 只在画布单镜面（Inspector、时间尺、转场面板）或 Agent 内进行。把分镜导出为文件不属于视图：系统 MAY 导出 Markdown 分镜表，但 MUST NOT 因此在应用内提供可编辑表格界面，MUST NOT 允许直接编辑导出文件并回写；回写只经既有导入预览。

#### Scenario: 顶栏没有镜头表

- **WHEN** 用户查看顶栏的项目视图导航
- **THEN** 导航中不出现「镜头表」，画布仍可打开并编辑当前集分镜

#### Scenario: 没有隐藏的表格

- **WHEN** 用户寻找批量编辑镜号、景别、台词或提示词的界面
- **THEN** 系统只提供单镜编辑面与 Agent，不提供表格或表格替代抽屉

#### Scenario: 导出不构成表格视图

- **WHEN** 用户使用画布的「导出」得到一份含分镜表的 Markdown 文件
- **THEN** 应用内不出现该表格的可编辑界面，文件改动只能经导入预览回写
