# Spec Delta

## MODIFIED Requirements

### Requirement: 来源注册与可用性

系统 SHALL 通过可插拔的来源注册表提供在线素材来源；每个来源声明支持的媒体类型、访问方式（官方 API / 页面解析 / 外链跳转）与可用状态。来源未启用、缺少凭据、被来源限流或不可达时 MUST 显示具体不可用原因，MUST NOT 隐藏该来源或静默改用其他来源。外链型来源 MUST 标注为不可检索、不可导入。新增来源 MUST NOT 改变检索与导入的对外契约。

#### Scenario: 来源可用

- **WHEN** 某个来源已启用并配置了有效凭据
- **THEN** 它出现在来源列表里，可以检索其声明的媒体类型

#### Scenario: 缺少凭据

- **WHEN** 来源已启用但没有配置凭据
- **THEN** 来源列表显示「未配置 Key」，检索入口不可用，并说明去哪里配置

#### Scenario: 无需凭据的来源

- **WHEN** 某个来源声明不需要凭据（例如页面解析型来源）
- **THEN** 它不需要填 Key 即可检索，设置页不显示「未配置 Key」

#### Scenario: 来源未启用

- **WHEN** 用户在设置页关闭某个来源
- **THEN** 该来源不出现在可选来源里，检索不会请求它

#### Scenario: 媒体类型不同

- **WHEN** 两个来源分别声明图片和音频能力
- **THEN** 选择只提供图片的来源时不显示音频筛选

#### Scenario: 外链型来源

- **WHEN** 某个来源声明为外链跳转型
- **THEN** 它出现在来源列表里并标记为「需购买后手动上传」，没有检索框与导入按钮

#### Scenario: 页面解析失败

- **WHEN** 页面解析型来源的页面结构变化导致解析不到任何条目
- **THEN** 系统报「来源结构可能已变化」，MUST NOT 显示成「没有匹配结果」

## ADDED Requirements

### Requirement: 中文关键词检索

用户输入含中文的关键词时，系统 SHALL 在服务端把关键词翻译成该来源可检索的英文关键词后再请求来源，并在结果里回传原始关键词与译词，供界面标注。翻译 MUST NOT 把关键词交给客户端处理，也 MUST NOT 改变用户已输入的内容。翻译不可用时 MUST 明确提示「未翻译，可能没有结果」，MUST NOT 用默认推荐结果冒充检索结果。缓存键 MUST 使用翻译后的关键词。

#### Scenario: 中文关键词

- **WHEN** 用户输入「中国」并提交检索
- **THEN** 系统用翻译后的英文关键词请求来源，结果区标注「已把『中国』译为 china」

#### Scenario: 已经是英文

- **WHEN** 用户输入不含中文的关键词
- **THEN** 系统不再翻译，直接按原词检索，不做任何译词标注

#### Scenario: 翻译失败

- **WHEN** 翻译服务不可用或返回空
- **THEN** 系统按原词检索并提示「未能翻译，可能没有结果」，不提示「没有匹配的素材」以外的默认推荐

#### Scenario: 术语表兜底

- **WHEN** 翻译服务不可用但关键词命中内置术语表
- **THEN** 使用术语表译词检索，并按正常情况标注译词

#### Scenario: 缓存复用

- **WHEN** 两个用户分别用「中国」与「china」检索同一来源同一页
- **THEN** 第二次检索复用第一次的缓存结果，界面仍按各自输入标注原始关键词

### Requirement: 页面解析型来源

没有公开 API 的来源 SHALL 通过按用户显式提交的关键词抓取来源页面并解析成归一化结果。检索 MUST 只在用户显式提交时发起，MUST NOT 预取下一页或批量抓取；每页条数 MUST NOT 超过来源页面单页条数。解析器 MUST 作为纯函数输入 HTML 字符串，便于用固定快照验收。条目 MUST 携带来源页面地址与许可证，导入仍走统一的令牌与下载校验。

#### Scenario: 关键词检索

- **WHEN** 用户对页面解析型来源提交关键词
- **THEN** 系统请求该关键词的搜索结果页，解析出条目并归一化返回

#### Scenario: 翻页

- **WHEN** 用户点「加载更多」
- **THEN** 系统才请求下一页，已有结果与选中状态保留

#### Scenario: 不预取

- **WHEN** 用户只浏览第一页而没有点「加载更多」
- **THEN** 系统只发过一次来源请求，不抓取后续页面或详情页

#### Scenario: 详情补充

- **WHEN** 来源列表页不含时长或高清变体
- **THEN** 系统在导入时按需读取详情页补齐，MUST NOT 为每条结果都抓详情页

#### Scenario: 零条目

- **WHEN** 来源页面正常返回但某关键词确实没有结果
- **THEN** 系统显示空状态和可调整的关键词建议，不报错

### Requirement: 外链型来源

内容需要付费购买或来源条款不允许自动抓取的来源 MUST 以外链型来源呈现。系统 MUST NOT 检索、下载或导入该来源的内容；MUST 提供按当前关键词拼好的来源搜索入口，并在界面说明该来源需要购买后手动上传。外链型来源 MUST NOT 计入检索缓存与导入令牌。

#### Scenario: 打开外链

- **WHEN** 用户在来源列表选中外链型来源并输入关键词
- **THEN** 界面给出「去来源网站搜索」按钮，点击在新标签页打开带该关键词的来源搜索页

#### Scenario: 拒绝导入

- **WHEN** 请求试图导入外链型来源的内容
- **THEN** 服务端直接拒绝，不发起任何下载

#### Scenario: 无关键词

- **WHEN** 用户还没有输入关键词
- **THEN** 外链按钮指向来源首页，且提示需要购买后手动上传

### Requirement: 来源额度保护

声明了额度上限的来源 SHALL 在客户端限制单页条数并收敛翻页深度，服务端 MUST 对每页条数做上限裁剪。额度耗尽或返回限流时 MUST 显示可读原因与重试提示，MUST NOT 伪装成空结果。

#### Scenario: 单页条数

- **WHEN** 客户端请求超过该来源允许的每页条数
- **THEN** 服务端裁剪到上限并正常返回结果

#### Scenario: 翻页深度

- **WHEN** 用户翻到该来源允许的最后一页
- **THEN** 「加载更多」消失，不再请求来源

#### Scenario: 额度耗尽

- **WHEN** 来源返回 429 或额度不足
- **THEN** 界面显示「来源限流或额度不足，请稍后重试」并保留已有结果

### Requirement: 来源选择与来源标注

结果与详情 MUST 显示当前来源名称，并在同一个界面里允许切换来源；切换来源 MUST 清空上一来源的结果、选中项与译词标注。MUST NOT 把不同来源的结果混排成一份列表。

#### Scenario: 切换来源

- **WHEN** 用户在 Pexels 搜到结果后切到 Mixkit
- **THEN** 列表清空，来源标识变为 Mixkit，不出现 Pexels 的条目

#### Scenario: 详情标注

- **WHEN** 用户选中一条结果
- **THEN** 详情区显示来源名称、作者、许可证与来源页面入口

#### Scenario: 不可用来源

- **WHEN** 用户点选一个不可用的来源
- **THEN** 界面显示该来源的不可用原因，检索入口保持禁用
