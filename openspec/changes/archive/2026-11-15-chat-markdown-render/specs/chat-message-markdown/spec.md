# Spec Delta

## Purpose

定义工作台会话消息文本的 Markdown 渲染契约，使创意会话、3D 调度会话与技能会话对同一段模型输出呈现一致、可读且安全的富文本结果。

## ADDED Requirements

### Requirement: 消息文本按 Markdown 渲染

会话中用户消息与助手消息的文本部分 SHALL 按 Markdown 渲染为富文本，至少支持标题、粗体、斜体、行内代码、无序列表、有序列表、引用块与链接；MUST NOT 把 Markdown 源符号原样展示给用户。

#### Scenario: 标题与强调

- **WHEN** 助手输出包含 `## 步骤` 与 `**重点**` 的文本
- **THEN** 用户看到具有字号层级的标题和加粗文字，且看不到 `##`、`**` 等源符号

#### Scenario: 列表

- **WHEN** 助手输出以 `- ` 或 `1. ` 开头的多行文本
- **THEN** 用户看到带项目符号或序号的列表，行首符号不显示

#### Scenario: 行内代码

- **WHEN** 助手输出包含反引号包裹的片段
- **THEN** 该片段以与正文区分的等宽样式呈现，反引号本身不显示

#### Scenario: 纯文本不受影响

- **WHEN** 助手输出不含任何 Markdown 语法的中文段落
- **THEN** 文本按原样正常显示，不出现多余的包裹或缩进

### Requirement: 围栏代码块折叠展示

以三反引号围栏包裹的代码 SHALL 在消息中以可折叠代码块呈现，MUST 显示语言标识和行数，默认收起，用户 MUST 能展开与再次收起；MUST NOT 把代码正文直接铺在消息流里。

#### Scenario: 带语言的代码块

- **WHEN** 助手输出标注了语言的围栏代码
- **THEN** 消息里出现显示该语言与行数的收起状态代码块

#### Scenario: 展开与收起

- **WHEN** 用户点击代码块的展开入口
- **THEN** 代码正文在块内滚动展示，再次点击恢复收起

#### Scenario: 未标注语言

- **WHEN** 围栏未写语言标识
- **THEN** 代码块仍可折叠展示，语言位置以可读的占位文字表示

### Requirement: 表格在窄栏内可横向滚动

Markdown 表格 SHALL 渲染为真实表格结构，并 MUST 在宽度不足时整体横向滚动，MUST NOT 撑破或撑宽消息容器。

#### Scenario: 宽表格

- **WHEN** 助手输出含 5 列以上的表格而消息面板宽度不足以完整显示
- **THEN** 表格在自身区域内可横向滚动，消息容器宽度保持不变

#### Scenario: 表头与单元格

- **WHEN** 表格正常渲染
- **THEN** 表头与单元格有清晰分隔，表头文字以加粗呈现

### Requirement: 单换行保留为换行

消息文本中的单个换行 SHALL 渲染为换行，MUST NOT 把多行文本合并为一个连续段落。

#### Scenario: 多行模型说明

- **WHEN** 助手以三行纯文本输出说明，行间只有单个换行
- **THEN** 用户看到三行独立文本，而不是一行连排

### Requirement: 渲染不执行原始 HTML 并约束链接行为

消息渲染 MUST NOT 执行文本中的原始 HTML 标签或脚本；链接 SHALL 在新窗口打开且不携带来源信息。

#### Scenario: 注入尝试

- **WHEN** 助手文本里出现 `<script>` 或 `<img onerror=...>`
- **THEN** 该内容按纯文本显示，不产生脚本执行或网络请求

#### Scenario: 外部链接

- **WHEN** 助手输出一个 http/https 链接
- **THEN** 链接以可识别样式呈现，点击后在新窗口打开，当前会话页面不被替换

### Requirement: 所有工作台会话渲染一致

所有使用 `ChatText` 的会话 SHALL 共用同一套渲染契约，同一段助手文本在任何一处 MUST 得到一致的渲染结果。当前实际挂载点为创意会话与 3D 调度会话（`SceneAgentChat`）；技能会话的 `SkillChat` 已作为未引用死代码移除，重新接入时无需改动渲染层。

#### Scenario: 同一段文本跨会话

- **WHEN** 同一段含标题、列表、代码块与表格的助手文本分别出现在创意会话与 3D 调度会话中
- **THEN** 两处的富文本结构、代码块折叠行为与表格滚动行为一致

#### Scenario: 既有轮次与状态文案

- **WHEN** 消息文本以轮次进度、已取消或失败前缀开头
- **THEN** 该前缀仍按既有语义展示，不被当作 Markdown 语法渲染
