# Proposal

## Why

素材卡的「图片来源」现在是原生下拉框，只能看到文件名或路径。真实项目里已有 69 张项目图片、8 个视频和 3 条素材记录；用户在选择前看不到缩略图，经常选错，视频选完还可能因为素材类型没切换而按图片渲染。需要把“选来源”改成能看见素材本身的选择过程。

## What Changes

- 素材卡 Inspector 的来源下拉改为 **缩略图选择器**：分类页签（项目素材 / 生成图片 / 视频 / 手填 URL）、搜索、按时间倒序。
- 每个条目展示缩略图、标题或可读名称、类型徽标、尺寸/时长/大小；文件路径只作为次要信息或 tooltip，不再作为主标签。
- 图片和视频都支持选择前预览：图片显示缩略图，视频显示首帧/播放标记；hover、键盘聚焦或选中时才播放，避免同时播放多条视频。
- 选择器内提供较大的详情预览和「使用这张」确认；取消不修改素材卡。
- 选择后自动修正素材类型：视频 → `video`，场景/道具素材沿用其 `kind`，普通图片保留当前场景/道具类型或回落 `image`。
- 过滤空 URL 的占位素材；按 URL 去重，优先保留带标题的项目素材记录。
- 标题为空或仍是「新素材」时自动填可读标题；用户改过的标题不覆盖。
- 损坏图片/视频显示明确错误并禁用确认，不把坏 URL 写进卡片。
- 不修改项目数据模型或服务端 API；复用现有 `listMedia` 的 `assets/images/videos`，尺寸/时长在浏览器加载后读取。

不包含：服务端生成视频封面、素材文件夹管理、多选批量绑定、拖拽排序、素材卡数据结构重构。

## Capabilities

### New Capabilities

- `asset-media-picker`: 素材卡选择图片来源时的分类、缩略图预览、视频预览、确认选择、类型修正与空/坏数据保护。

### Modified Capabilities

无。

## Impact

- 代码：`src/Inspector.tsx`（AssetPanel 接入选择器）、新增 `src/MediaPicker.tsx` / `src/mediaPick.ts`、`src/theme.css`（选择器、网格、预览态）、`src/api.ts`（如需要补充媒体项类型）。
- 数据：无 SQLite/接口变更；继续使用 `/api/media?name=<project>` 返回的 `assets` / `images` / `videos`。
- 验证：新增 Playwright 脚本覆盖分类、缩略图、搜索、图片/视频预览、选择后类型、空 URL、去重、取消、损坏 URL、键盘与窄屏；现有项目隔离/素材发布回归。
- 兼容性：现有素材卡数据不变；没有图片的卡仍显示「未设置图片」；外部 URL 和数据 URL 仍可手填并预览。
