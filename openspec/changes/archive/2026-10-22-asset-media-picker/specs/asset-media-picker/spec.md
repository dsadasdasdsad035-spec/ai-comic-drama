# Spec Delta

## Purpose

让素材卡在选择图片来源时先看到素材本身：按项目素材、生成图片和视频分类浏览缩略图，预览图片或视频后再确认，并自动修正素材类型与可读标题。

## ADDED Requirements

### Requirement: 来源选择器以缩略图为主

素材卡 Inspector 的来源选择 MUST 提供可视化选择器；每个条目 MUST 展示缩略图或视频首帧、可读标题/名称和类型徽标。文件路径 MUST NOT 作为唯一条目标签，只能作为次要信息或悬停提示。

#### Scenario: 打开选择器

- **WHEN** 用户点击素材卡的「选择素材」
- **THEN** 打开选择器，至少显示当前项目的图片缩略图、标题/名称和类型

#### Scenario: 没有素材

- **WHEN** 当前项目没有任何可用素材
- **THEN** 选择器显示明确空状态，并保留「手填地址」入口

### Requirement: 按来源分类并支持搜索

选择器 SHALL 提供项目素材、生成图片、视频和手填地址分类，并显示各类数量；SHALL 支持按标题、文件名或类型搜索。默认按时间倒序，空分类 MUST 显示空状态。

#### Scenario: 切换分类

- **WHEN** 用户切换「项目素材 / 生成图片 / 视频」
- **THEN** 只显示该分类的素材，数量与内容一致

#### Scenario: 搜索素材

- **WHEN** 用户在搜索框输入文件名或标题片段
- **THEN** 列表只保留匹配项；没有匹配时显示空状态

#### Scenario: 新素材排在前面

- **WHEN** 同一分类有多个素材
- **THEN** 默认按最近修改时间从新到旧排列

### Requirement: 图片选择前可预览

图片条目 SHALL 显示缩略图；用户点选后在选择器内展示较大的详情预览。图片加载失败 MUST 显示明确错误并禁用「使用这张」，MUST NOT 把坏地址写回素材卡。

#### Scenario: 预览图片

- **WHEN** 用户点选一张图片
- **THEN** 选择器详情区显示这张图的大图预览和尺寸/大小等信息

#### Scenario: 图片损坏

- **WHEN** 图片无法加载
- **THEN** 条目或详情区显示加载失败，确认按钮不可用

### Requirement: 视频选择前可预览

视频条目 SHALL 显示首帧或可识别占位、时长和播放标记；hover、键盘聚焦或点选时才播放，同一时间 MUST 最多播放一条视频。选中后详情区 MUST 提供带控制条的视频预览。

#### Scenario: 悬停预览视频

- **WHEN** 用户 hover 或键盘聚焦一个视频条目
- **THEN** 该视频开始静音预览，移开后停止，其他视频不被同时播放

#### Scenario: 选中视频

- **WHEN** 用户点选一个视频
- **THEN** 详情区显示可播放/暂停的视频预览和时长

#### Scenario: 视频损坏

- **WHEN** 视频无法加载或解码
- **THEN** 显示明确错误并禁用确认，不写坏地址

### Requirement: 确认与取消语义

点选条目 MUST 只更新选择器的预览，MUST NOT 立即修改素材卡；用户点击「使用这张」或双击条目后才提交。取消、Esc 或关闭选择器 MUST 保持原素材卡不变，并把焦点返回触发按钮。

#### Scenario: 确认选择

- **WHEN** 用户点选素材后点击「使用这张」
- **THEN** 素材卡的来源、预览和必要类型/标题更新，选择器关闭

#### Scenario: 取消选择

- **WHEN** 用户选择另一个素材后点击取消或按 Esc
- **THEN** 素材卡保持原来的 URL、类型和标题

#### Scenario: 键盘操作

- **WHEN** 用户用 Tab/方向键移动并用 Enter 确认
- **THEN** 选择器可完成选择和关闭，焦点不会丢到页面外

### Requirement: 选择后自动修正素材类型

选择视频时素材类型 MUST 变为 `video`；选择场景/道具素材时 MUST 沿用其类型；选择普通图片时 MUST 保留当前场景/道具类型，否则回落 `image`。类型修正 MUST 与 URL 同时生效，避免视频仍按图片渲染。

#### Scenario: 选择视频

- **WHEN** 用户确认一个视频
- **THEN** 素材卡类型变为视频，卡片和 Inspector 都用视频预览

#### Scenario: 选择场景素材

- **WHEN** 用户确认一个项目场景素材
- **THEN** 素材卡类型变为场景

#### Scenario: 选择普通图片

- **WHEN** 当前卡是场景卡，用户确认一张普通图片
- **THEN** 类型仍为场景；当前卡不是场景/道具时回落为图片

### Requirement: 自动标题不覆盖手改

用户确认素材时，若素材卡标题为空或是默认「新素材」，系统 SHALL 填入可读标题；若用户已改过标题，MUST 保留用户标题。

#### Scenario: 默认标题

- **WHEN** 标题仍是「新素材」，用户选择一张素材
- **THEN** 标题自动替换为素材标题或可读的生成名

#### Scenario: 已手改标题

- **WHEN** 用户已经把标题改成自定义名称，再更换来源
- **THEN** 自定义标题保持不变

### Requirement: 过滤空条目并去重

选择器 MUST 隐藏 URL 为空的占位素材；同一 URL 出现多次时 MUST 只显示一条，并优先保留带标题/类型的项目素材记录。当前 URL 不在素材库时 SHALL 作为「当前来源」显示并可预览。

#### Scenario: 空 URL 素材

- **WHEN** 项目素材里存在没有图片地址的「新素材」
- **THEN** 它不出现在选择器可选列表中

#### Scenario: 重复 URL

- **WHEN** 同一张图既在项目素材又在生成图片列表里
- **THEN** 选择器只显示一条，优先显示带标题/类型的项目素材

#### Scenario: 当前外部地址

- **WHEN** 素材卡当前 URL 不在素材库中
- **THEN** 选择器提供「当前来源」条目并尝试预览，用户仍可保留它

### Requirement: 所有素材类型都有预览

项目素材、生成图片、视频、外部 URL 和数据 URL MUST 都走同一套预览；场景/道具/普通图/视频 MUST NOT 出现只有路径没有预览的类型。资源加载应避免一次性解码全部列表。

#### Scenario: 四类素材

- **WHEN** 用户依次查看场景、道具、普通图和视频
- **THEN** 每类都有缩略图或首帧和详情预览

#### Scenario: 外部地址

- **WHEN** 用户手填一个图片或视频地址
- **THEN** 选择器预览该地址；无法识别类型时按 URL 扩展名或用户选择处理

### Requirement: 窄屏与无障碍

选择器 SHALL 在窄屏下可用，标签和预览不被裁切；MUST 提供可访问的名称、选中状态、可见焦点和足够大的点击目标。窄屏时布局 SHOULD 改为全屏或单列，而不是压缩到不可读。

#### Scenario: 手机宽度

- **WHEN** 视口缩到 390px
- **THEN** 选择器内容可滚动、确认/取消可操作，缩略图和标题不重叠

#### Scenario: 屏幕阅读器

- **WHEN** 用户使用键盘或辅助技术浏览条目
- **THEN** 条目有可读标签和选中状态，焦点顺序与视觉顺序一致

### Requirement: 浏览不修改素材卡

打开选择器、切换分类、搜索、hover 或点选预览 MUST NOT 修改素材卡数据；只有确认动作才写入 URL、类型和自动标题。

#### Scenario: 只浏览后取消

- **WHEN** 用户浏览多个素材但没有确认
- **THEN** 素材卡 URL、类型和标题保持不变
