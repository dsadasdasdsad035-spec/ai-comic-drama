# Spec Delta

## MODIFIED Requirements

### Requirement: 集上下文覆盖画布与其余项目视图

系统 SHALL 在画布、剧本、角色、素材、发布提供集切换，并在选择器中显示集号、集标题与镜数。切换到某集后，该视图 MUST 展示该集的内容。分镜结构、首帧与视频提示词的查看与编辑随画布视图的集切换一起更新，不再提供单独的「提示词」视图与「镜头表」视图。项目级的自定义白模条目（素材 → 镜头语言）MUST NOT 随集切换而过滤。

#### Scenario: 角色页切集

- **WHEN** 用户在角色页从 E01 切换到 E02
- **THEN** 角色页的镜头上下文与聊天上下文都指向 E02

#### Scenario: 3D 视图切集

- **WHEN** 项目从 E01 切换到 E02
- **THEN** 系统不提供 3D 调度视图；自定义白模条目为项目级，不随集过滤，也不因切集丢失

#### Scenario: 发布页切集

- **WHEN** 用户在发布页从 E01 切换到 E02
- **THEN** 待发布列表与预检只使用 E02 的成片和配置，E01 的发布配置保持不变

#### Scenario: 画布切集含提示词

- **WHEN** 用户在画布从 E01 切换到 E02
- **THEN** 画布显示 E02 的镜头卡片，单镜 Inspector 展示该集对应镜的 `keyframe_prompt` / `video_prompt`

#### Scenario: 没有集的视图

- **WHEN** 项目还没有任何集或镜头
- **THEN** 集选择器显示未选状态，且不伪造集号

## REMOVED Requirements

### Requirement: 3D 调度视图的镜选择器可键盘操作

**Reason**: 顶栏「3D 调度」视图已删除，不存在该视图的镜选择器。

**Migration**: 白模工作台按条目打开，不再需要镜号选择器；画布的键盘语义不变。
