# Spec Delta

## MODIFIED Requirements

### Requirement: 角色聊天可选择参考图

角色工作台聊天打开时，附件条 MUST 为空，MUST NOT 预填项目图片、角色卡参考图或任何默认图。用户 MUST 能上传本地图片，或从当前项目已有图片中选择，将其加入本次对话。已加入的图片 MUST 在发送前可见，并 MUST 能单张移除或全部清空；移除与清空 MUST 立即从后续发送内容中消失。聊天附件 MUST NOT 写入任何角色的参考图列表，角色卡上的参考图也 MUST NOT 自动进入聊天附件。

#### Scenario: 从已有参考图选择

- **WHEN** 角色卡已有参考图，用户打开聊天后从当前项目已有图片中选中一张
- **THEN** 只有这张被选中的图出现在附件条，并可单张移除或全部清空；角色卡上的参考图不会在打开时预先出现

#### Scenario: 聊天里上传新图

- **WHEN** 用户在聊天里上传一张本地图片
- **THEN** 该图出现在附件条并可单张移除，不写入任何角色的参考图列表

#### Scenario: 参考图上限

- **WHEN** 本次对话的附件数量已达到上限，用户尝试再加入一张
- **THEN** 系统拒绝并说明上限，已有附件不受影响

#### Scenario: 切换角色不串图

- **WHEN** 用户已在聊天里添加一张图片，然后点开另一张角色卡
- **THEN** 附件条仍是用户添加的那张图，不换成另一张角色卡上的参考图

#### Scenario: 打开时没有预填图

- **WHEN** 项目里已有图片，且角色卡上已有参考图，用户打开角色聊天且尚未添加附件
- **THEN** 附件条为空，这些图片都不出现

#### Scenario: 清空后不再发送

- **WHEN** 用户清空附件后再发送消息
- **THEN** 附件条为空，该消息不包含清空前的图片

#### Scenario: 取消选择不改变附件

- **WHEN** 用户打开素材选择后取消
- **THEN** 附件条与取消前一致
