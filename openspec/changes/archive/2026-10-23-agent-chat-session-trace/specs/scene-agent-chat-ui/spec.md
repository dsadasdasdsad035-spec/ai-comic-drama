# Spec Delta

## ADDED Requirements

### Requirement: 聊天页签切换不得丢失会话

聊天面板 MUST 在打开的工作台内保持会话；切换到代码页签 MUST NOT 卸载聊天状态、清空消息/工具结果/关键帧/验收清单/滚动位置，MUST NOT 取消正在运行的 agent。关闭工作台仍可结束会话并释放沙箱。

#### Scenario: 已完成会话切换

- **WHEN** 聊天已经产生消息、工具卡和验收清单，用户切到代码页签再切回
- **THEN** 所有消息、卡片、帧和清单仍在，内容顺序不变

#### Scenario: 运行中切换

- **WHEN** agent 正在运行，用户切到代码页签
- **THEN** agent 继续执行，不被取消；切回聊天时能看到已完成和正在进行的步骤

#### Scenario: 滚动位置

- **WHEN** 用户在聊天中滚动到较早的工具步骤后切换页签再回来
- **THEN** 聊天仍保留原来的滚动位置

#### Scenario: 关闭工作台

- **WHEN** 用户关闭工作台
- **THEN** 当前会话可以结束并释放沙箱，不要求跨关闭持久化

### Requirement: 聊天必须显示模型轮次

每次模型调用 SHALL 在聊天中产生可见的轮次状态；模型返回面向用户的简短说明时 SHALL 显示说明，没有说明时 MUST 仍显示该轮已运行/完成，不能只显示工具卡。

#### Scenario: 模型有简短说明

- **WHEN** 模型在调用工具前返回一句准备说明
- **THEN** 聊天在该轮工具卡之前显示这句说明

#### Scenario: 模型只返回工具调用

- **WHEN** 模型的 content 为空但发起了工具调用
- **THEN** 聊天显示该轮模型已运行，并继续显示工具卡，不产生空白步骤

#### Scenario: 模型轮次失败

- **WHEN** 某一轮模型调用失败
- **THEN** 该轮显示失败状态和错误摘要，之前的轮次保留

## MODIFIED Requirements

### Requirement: 聊天不得展示隐藏推理

聊天 MUST NOT 渲染模型 chain-of-thought、内部系统提示或隐藏推理 token。模型面向用户的简短说明 SHALL 可以作为普通文本显示；工具调用、参数摘要、工具结果、关键帧和清单 MUST 继续按结构化卡片展示。

#### Scenario: 模型推理

- **WHEN** 模型返回内部推理或 chain-of-thought
- **THEN** 聊天不把它作为消息或工具卡片显示

#### Scenario: 模型说明

- **WHEN** 模型返回面向用户的简短准备说明
- **THEN** 聊天把它作为普通文本显示，并保留它和工具卡片的执行顺序

#### Scenario: 工具参数

- **WHEN** 参数包含大段代码或图片
- **THEN** 只显示摘要或缩略图，不直接铺满消息流
