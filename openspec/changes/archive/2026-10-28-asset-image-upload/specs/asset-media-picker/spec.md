# Spec Delta

## ADDED Requirements

### Requirement: 素材卡与选择器支持本地上传

素材卡的来源选择器与画布素材卡 MUST 提供「本地上传」入口，选择本地图片后落成项目媒体文件并把站内地址写回素材卡。上传结果 MUST 与项目素材、生成图片、在线素材走同一套预览与确认语义，MUST NOT 成为只能手填地址的特例。

#### Scenario: 从素材卡上传
- **WHEN** 用户在素材卡的来源区上传一张图片
- **THEN** 图片保存为项目媒体文件，素材卡显示该图并按图片类型渲染

#### Scenario: 从选择器上传
- **WHEN** 用户打开选择器并上传一张图片
- **THEN** 上传的图片出现在选择器条目中，可点选预览后确认使用

#### Scenario: 上传后立即可用
- **WHEN** 上传成功且用户确认
- **THEN** 素材卡的地址、预览与类型同时更新，不需要刷新页面

#### Scenario: 上传图参与镜头参考
- **WHEN** 用户把上传得到的素材卡连线到分镜
- **THEN** 出图时该图作为参考图提交，与生成图或在线素材无差别

### Requirement: 上传拒绝不修改素材卡

类型或大小校验不通过、读取失败或保存失败时，系统 MUST 保持素材卡原有的地址、类型与标题，MUST 显示具体原因，MUST NOT 写入临时 dataURL。

#### Scenario: 格式不支持
- **WHEN** 用户上传一个非 png/jpeg/webp 文件
- **THEN** 系统说明支持的格式，素材卡保持不变

#### Scenario: 保存失败
- **WHEN** 上传文件已读取但保存请求失败
- **THEN** 素材卡保持原地址，并显示失败原因

#### Scenario: 取消选择
- **WHEN** 用户打开文件选择框后取消
- **THEN** 素材卡与选择器状态都不改变
