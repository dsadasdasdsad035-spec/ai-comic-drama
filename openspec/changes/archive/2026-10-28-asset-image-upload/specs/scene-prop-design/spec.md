# Spec Delta

## ADDED Requirements

### Requirement: 设定卡支持上传本地图片

系统 SHALL 允许用户为场景/道具设定卡上传本地图片作为当前图，且该上传 MUST NOT 依赖英文生图锚点——没有锚点的卡也可以先有图。上传成功后该图 MUST 作为当前图并进入候选列表，MUST 与其他候选图一样可被选择、发布到画布和参与镜头参考。

#### Scenario: 上传成为当前图
- **WHEN** 用户对一张没有图的场景卡上传一张图片
- **THEN** 该图成为当前图，卡片显示这张图并可「加入画布」

#### Scenario: 没有英文锚点也能上传
- **WHEN** 设定卡的英文锚点为空，用户点上传
- **THEN** 上传照常进行，不提示先补锚点

#### Scenario: 上传图进入候选
- **WHEN** 设定卡已有两张生成候选，用户再上传一张
- **THEN** 候选列表包含这三张，用户可切换当前图，重新打开项目后选择保持不变

#### Scenario: 已有生成图时替换
- **WHEN** 设定卡已有生成图，用户上传一张新图
- **THEN** 当前图变为上传图，原生成图仍留在候选中可切回

### Requirement: 上传前校验并解释拒绝原因

系统 MUST 在上传前检查文件类型与大小，类型限于 png / jpeg / webp，单文件上限与既有参考图上限一致。校验不通过时 MUST 显示具体原因并保持设定卡现状，MUST NOT 发起保存请求。

#### Scenario: 不支持的格式
- **WHEN** 用户选择一个 HEIC 或 GIF 文件
- **THEN** 系统说明只支持 png / jpeg / webp，不发起上传

#### Scenario: 超过大小上限
- **WHEN** 用户选择的图片超过 30MB
- **THEN** 系统说明超出上限并给出当前文件大小，不改动设定卡

#### Scenario: 未选择项目
- **WHEN** 用户在没有项目时上传
- **THEN** 系统提示先在顶栏选择项目，不发起上传

### Requirement: 上传失败不写回设定卡

上传过程中 MUST NOT 先把图片地址写进设定卡再回滚。保存失败或读取失败时 MUST 保持设定卡原有的当前图与候选，MUST NOT 留下指向不存在文件的地址。

#### Scenario: 保存请求失败
- **WHEN** 图片已读取但保存到项目媒体目录失败
- **THEN** 设定卡的当前图与候选保持不变，并显示失败原因

#### Scenario: 取消读取
- **WHEN** 用户选择文件后读取被中断
- **THEN** 设定卡保持原状，不出现空图占位
