# Spec Delta

## MODIFIED Requirements

### Requirement: 创意视图往返不重建宿主文档

操作员首次进入创意视图后，离开并再次返回 MUST NOT 重新加载宿主外壳文档。离开创意视图时宿主文档 MUST 保持存活，会话列表、消息流滚动位置、输入区未发送草稿与实时连接 MUST 保持原样。未激活期间宿主文档 MUST 以揭示后的可视尺寸完成渲染，揭示时 MUST NOT 因尺寸变化触发重新布局或补渲染。未激活期间容器 MUST NOT 参与内容区排版、MUST NOT 接收指针事件、MUST NOT 出现在辅助技术的可访问树中。应用 SHALL 在操作员此前进入过创意、或对创意入口产生指针悬停或焦点意图时预先载入外壳；首访且无意图时 MUST 按需加载，MUST NOT 在首屏阶段预先加载宿主外壳产物。

#### Scenario: 往返后状态保留

- **WHEN** 操作员在创意视图滚动消息流、输入一段草稿，切到工作台再切回创意
- **THEN** 宿主外壳未重新加载，滚动位置与草稿都保留

#### Scenario: 揭示不产生补渲染

- **WHEN** 操作员从其它视图切回创意视图且此前已进入过
- **THEN** 首行会话在揭示后的第一帧内可见，不出现骨架、空白或列表补渲染

#### Scenario: 未激活时不干扰其它视图

- **WHEN** 操作员停留在画布视图，创意视图处于未激活的常驻状态
- **THEN** 画布的排版与点击命中不受影响，内容区尺寸与未挂载时一致

#### Scenario: 启动阶段不加载宿主外壳

- **WHEN** 全新会话启动应用，操作员未进入创意视图，也未对创意入口产生指针或焦点意图
- **THEN** 不请求宿主外壳文档，也不加载其前端产物

#### Scenario: 有意图或回访时预先载入

- **WHEN** 操作员此前进入过创意视图，或对创意入口产生了指针悬停或焦点意图
- **THEN** 应用在宿主就绪后预先载入外壳文档，点击「创意」时直接呈现已有内容

#### Scenario: 实时连接不重建

- **WHEN** 操作员离开创意视图一段时间后返回
- **THEN** 实时连接未重建，视图直接呈现最新会话状态，不出现重连提示

#### Scenario: 会话切换与视图切换互不干扰

- **WHEN** 操作员在创意视图内切换会话后立刻切到其它视图再返回
- **THEN** 仍停留在离开前的那个会话，消息流内容与离开前一致
