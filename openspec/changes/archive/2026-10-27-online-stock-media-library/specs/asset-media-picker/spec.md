# Spec Delta

## MODIFIED Requirements

### Requirement: 来源选择器以缩略图为主

素材卡 Inspector 的来源选择 MUST 提供可视化选择器；每个条目 MUST 展示缩略图、视频首帧或音频标识、可读标题/名称和类型徽标。文件路径 MUST NOT 作为唯一条目标签，只能作为次要信息或悬停提示。

#### Scenario: 打开选择器

- **WHEN** 用户点击素材卡的「选择素材」
- **THEN** 打开选择器，至少显示当前项目的图片缩略图、标题/名称和类型

#### Scenario: 没有素材

- **WHEN** 当前项目没有任何可用素材
- **THEN** 选择器显示明确空状态，并保留「手填地址」入口

#### Scenario: 音频条目

- **WHEN** 素材库或在线结果里出现音频
- **THEN** 条目显示音频标识与标题，不显示破图占位

### Requirement: 按来源分类并支持搜索

选择器 SHALL 提供项目素材、生成图片、视频、在线素材和手填地址分类，并显示各类数量；在线素材的数量 MAY 显示当前检索结果数而不是来源总数。选择器 SHALL 支持按标题、文件名或类型搜索本地分类；在线分类的搜索 MUST 由显式提交触发并走在线素材检索。本地分类默认按时间倒序，空分类 MUST 显示空状态。

#### Scenario: 切换分类

- **WHEN** 用户切换「项目素材 / 生成图片 / 视频」
- **THEN** 只显示该分类的素材，数量与内容一致

#### Scenario: 搜索素材

- **WHEN** 用户在搜索框输入文件名或标题片段
- **THEN** 列表只保留匹配项；没有匹配时显示空状态

#### Scenario: 新素材排在前面

- **WHEN** 同一本地分类有多个素材
- **THEN** 默认按最近修改时间从新到旧排列

#### Scenario: 在线素材分类

- **WHEN** 用户切到「在线素材」
- **THEN** 选择器显示在线检索界面，未输入关键词时给出检索提示而不是空白列表

#### Scenario: 在线搜索不随键入

- **WHEN** 用户在线素材页签里逐字输入但未提交
- **THEN** 不发起来源请求

### Requirement: 选择后自动修正素材类型

选择视频时素材类型 MUST 变为 `video`；选择音频时 MUST 变为 `audio`；选择场景/道具素材时 MUST 沿用其类型；选择普通图片时 MUST 保留当前场景/道具类型，否则回落 `image`。类型修正 MUST 与 URL 同时生效，避免视频或音频仍按图片渲染。

#### Scenario: 选择视频

- **WHEN** 用户确认一个视频
- **THEN** 素材卡类型变为视频，卡片和 Inspector 都用视频预览

#### Scenario: 选择音频

- **WHEN** 用户确认一条音频
- **THEN** 素材卡类型变为音频，卡片和 Inspector 都用音频预览

#### Scenario: 选择场景素材

- **WHEN** 用户确认一个项目场景素材
- **THEN** 素材卡类型变为场景

#### Scenario: 选择普通图片

- **WHEN** 当前卡是场景卡，用户确认一张普通图片
- **THEN** 类型仍为场景；当前卡不是场景/道具时回落为图片

### Requirement: 所有素材类型都有预览

项目素材、生成图片、视频、音频、在线检索结果、外部 URL 和数据 URL MUST 都走同一套预览；场景/道具/普通图/视频/音频 MUST NOT 出现只有路径没有预览的类型。资源加载应避免一次性解码全部列表。

#### Scenario: 四类素材

- **WHEN** 用户依次查看场景、道具、普通图和视频
- **THEN** 每类都有缩略图或首帧和详情预览

#### Scenario: 音频素材

- **WHEN** 用户点选一条音频素材或在线音频结果
- **THEN** 详情区提供可播放/暂停的音频预览和时长

#### Scenario: 外部地址

- **WHEN** 用户手填一个图片、视频或音频地址
- **THEN** 选择器预览该地址；无法识别类型时按 URL 扩展名或用户选择处理

#### Scenario: 在线结果

- **WHEN** 用户在在线素材页签浏览结果
- **THEN** 结果缩略图、详情预览和授权信息与本地条目使用同一套交互，不出现只有文字链接的条目
