# Proposal

## Why

创意视图是唯一「聊天即主界面」的视图，但它的空间分配还是按「对话框 + 一条产物横带」做的：产物卡挂在消息视口上方、最多吃掉 42% 高度，有源视频和提示词包时聊天只剩一半；消息正文没有阅读宽度上限，1500px 视口下 13px 文字一行约 91 个汉字；进入创意视图时全局导航还会因为移除项目与集选择器整体左移 376px。

另外有两个直接可见的缺陷：空态正文在两套主题下都解析成背景色（对比度 1.06–1.09:1，等于看不见），因为 `--muted` 在聊天 token 作用域里被重定义为表面色；策划模式没有源视频，底部仍常驻一整行灰掉的摄取控件。

这些问题都不涉及数据与流程，改的是「东西放在哪、占多宽」。上沿刚统一为两段式，创意页如果继续用横带堆叠，收益会在这一页丢掉一半，所以现在一起收口。

## What Changes

- **产物改为右侧栏**：源视频、镜头、提示词包、生成结果从消息上方横带搬进对话右侧的独立栏（320px，可折叠，折叠状态记本机）；窄屏变为覆盖式抽屉。
- **对话列有自己的阅读宽度**：消息与输入最大宽度 640px 居中，不再拉满整个主列。
- **媒体摄取条按模式出现**：策划模式整条不渲染；反推/复刻模式显示链接、摄取、上传、切分、抽帧，无源视频时切分与抽帧保持不可用。
- **示例只出现一次**：删除空态里不可点击的静态示例列表，保留输入框上方可点击、只填入不发送的示例。
- **会话行改成两行**：标题 + 「模式 · 相对时间」；改名/删除不再常驻占位，改为悬停或键盘聚焦时出现的更多菜单。
- **导航位置稳定**：创意视图继续不显示项目与集选择器，但保留它们的占位几何，进入/离开创意时导航不位移。
- **修复正文颜色**：创意聊天区内的文字颜色不再使用聊天作用域里被重定义为表面色的 token；空态说明与提示在两套主题下达到 4.5:1。
- **头部与底部去重**：模型显示短名、次要信息一行溢出省略；底部媒体条不再重复模式标签。
- **BREAKING（内部结构）**：`.creative-cards` 不再是消息视口上方的横带，`verify-creative-*.mjs` 中依赖该位置与空态静态示例的断言需要同步更新。

## Capabilities

### New Capabilities

- `creative-layout`: 创意视图的空间与密度契约。覆盖三列骨架（会话 / 对话 / 产物）、对话阅读宽度、产物栏的折叠与窄屏形态、媒体摄取条的按模式显隐、示例与模式标签的唯一性、会话列表的信息密度、创意视图下全局导航的位置稳定，以及创意正文在两套主题下的可读对比。

### Modified Capabilities

无。`creative-chat`（聊天优先的交互与工具）尚未归档进主规格，本次不动它，避免与 `creative-chat-studio` 的待合并增量冲突；`workbench-shell` 的导航要求也不改，导航位移作为创意视图自身的约束由 `creative-layout` 承担。

## Impact

- 组件：`src/creative/CreativeStudio.tsx`（三列骨架与产物栏挂载点）、`CreativeMessageParts.tsx`（产物区宿主）、`CreativeComposerBar.tsx`（模式化显隐）、`CreativeEmpty.tsx`（颜色与示例）、`CreativeHeader.tsx`（短名与去重）、`CreativeSessionList.tsx`（两行与更多菜单）、`CapabilityTray.tsx`（入口位置）、`App.tsx`（创意视图保留选择器占位几何）。
- 样式：`src/theme.css` 中的 `.creative-*` 规则、新增产物栏与阅读宽度规则、`.topbar` 占位规则；聊天作用域内文字色改用 `--text` / `--text-2` / `--muted-foreground`。
- 交互与无障碍：产物栏折叠按钮与窄屏抽屉的可达名称、Esc 关闭与焦点归还；会话行更多菜单的键盘操作。
- 校验脚本：`verify-creative-ui.mjs`（产物宿主位置、示例计数、窄屏形态）、`verify-creative-e2e.mjs`（空态上传入口）、`verify-creative-reverse.mjs` 与 `verify-creative-export.mjs`（产物卡所在区域）。
- 不改动：会话数据模型、创意 API、技能与工具集、成本确认、晋升项目、模型路由；其余七个视图的布局与上沿结构。
