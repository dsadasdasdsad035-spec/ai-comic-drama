# Spec Delta

## MODIFIED Requirements

### Requirement: 提供夜间与日间两套主题

系统 SHALL 提供 Night 与 Day 两套主题；Night MUST 保持当前 Cinema Dark 的视觉与布局，Day MUST 使用暖纸底与深色文字而非简单反色。全局带、集选择器、视图上下文带、画布、分镜卡、Inspector、时间线、菜单、Toast 与创意视图的宿主外壳 MUST 从同一套语义主题取值。

#### Scenario: 夜间保持现状

- **WHEN** 用户处于夜间主题
- **THEN** 主要表面、文字、强调色和布局与当前深色工作台一致

#### Scenario: 日间覆盖全界面

- **WHEN** 用户切到日间主题
- **THEN** 全局带、集选择器、上下文带、画布、卡片、Inspector、时间线和浮层都变为浅色表面，不残留深色区块

#### Scenario: 日间覆盖创意外壳

- **WHEN** 用户在日间主题下打开创意视图
- **THEN** 会话列表、消息气泡、输入区与工具卡片都使用日间表面与文字配色，不出现整块深色区域

### Requirement: 日间文字与强调色达到可读对比

日间主题 SHALL 保证正文、次级文字、弱化文字和强调色在其实际背景上达到 WCAG AA 的 4.5:1；强调色 MUST 使用适合浅底的颜色，MUST NOT 直接沿用夜间的高亮青色。focus ring 在两种主题下都 MUST 可见。该约束同样适用于创意视图的宿主外壳内部。

#### Scenario: 日间正文与次级文字

- **WHEN** 日间主题渲染正文、标签或时间码
- **THEN** 这些文字与所在面板/画布的对比度不低于 4.5:1

#### Scenario: 日间强调色

- **WHEN** 日间主题渲染选中态、主按钮或链接
- **THEN** 强调色与背景的对比度不低于 4.5:1，且不依赖低对比高亮色

#### Scenario: 键盘聚焦

- **WHEN** 用户用 Tab 聚焦主题开关或其他主要控件
- **THEN** 当前主题下都能看到清晰的 focus ring

#### Scenario: 创意外壳内的对比度

- **WHEN** 日间主题下渲染创意会话的消息正文、时间戳与工具卡片标签
- **THEN** 这些文字与所在背景的对比度不低于 4.5:1

### Requirement: 首屏主题跟随系统并可记忆

系统 SHALL 在用户没有保存过偏好时跟随 `prefers-color-scheme`；系统没有可用信号时 MUST 回落夜间。用户手动切换后 MUST 记住选择，并在刷新、重新打开应用后继续使用；本地存储不可用时 MUST 回落到系统/夜间且不阻断页面。创意视图的宿主外壳 MUST 使用同一份已保存偏好启动。

#### Scenario: 首次打开跟随系统

- **WHEN** 用户从未选择过主题，系统偏好为浅色
- **THEN** 首次打开显示日间主题；系统偏好为深色时显示夜间

#### Scenario: 手动选择被记住

- **WHEN** 用户切到日间后刷新页面
- **THEN** 页面仍以日间主题启动

#### Scenario: 存储不可用

- **WHEN** 浏览器禁止或清空本地存储
- **THEN** 页面仍能按系统偏好或夜间正常显示，切换在当前会话内有效

#### Scenario: 创意视图继承主题

- **WHEN** 用户已保存日间主题并进入创意视图
- **THEN** 外壳首帧即为日间配色，不先闪出夜间再切换
