# Spec Delta

## MODIFIED Requirements

### Requirement: 所有聊天共用同一个执行运行时

应用内除创意会话外的所有聊天 SHALL 由同一个有状态工具调用运行时驱动，包括 3D 调度、五个工作台聊天与发布助手。这些聊天 MUST NOT 自带第二套模型循环或第二套工具执行路径。运行时的模型调用 MUST 继续经过服务端代理。创意会话由独立的宿主运行时驱动，不在此条约束之内。

#### Scenario: 统一运行时

- **WHEN** 任一工作台聊天发起一轮对话
- **THEN** 它走同一个运行时，并产生同形状的步骤、文本与工具事件

#### Scenario: 不存在第二套循环

- **WHEN** 检查工作台聊天实现
- **THEN** 不存在按技能、按工作台或按界面分叉的模型循环

#### Scenario: 线程记录兼容

- **WHEN** 用户打开切换前保存的工作台聊天线程
- **THEN** 历史消息、工具卡片与草稿回执仍按原样恢复

#### Scenario: 创意会话不受该约束

- **WHEN** 检查创意会话实现
- **THEN** 它由宿主运行时驱动，且工作台运行时的工具与事件契约不被其修改

## ADDED Requirements

### Requirement: 创意会话运行时边界

创意会话 SHALL 由宿主运行时独立驱动，工作台运行时 MUST NOT 为创意会话保留第二套适配分支。宿主运行时 MUST 继续遵守原生工具调用与代理出口两项约束：MUST NOT 把模型文本解析为工具调用，MUST NOT 让模型调用绕过应用代理。

#### Scenario: 创意会话走宿主运行时

- **WHEN** 用户在创意会话发送一条消息
- **THEN** 该轮由宿主运行时执行，模型调用经应用代理出口

#### Scenario: 创意不污染工作台运行时

- **WHEN** 创意会话的工具或事件形状发生变化
- **THEN** 工作台聊天的事件形状与工具契约保持不变

#### Scenario: 工作台运行时不承载创意

- **WHEN** 检查工作台运行时的注册表
- **THEN** 其中不含仅为创意会话存在的技能、工具或分支
