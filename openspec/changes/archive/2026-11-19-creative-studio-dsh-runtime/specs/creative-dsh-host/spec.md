# Spec Delta

## Purpose

定义创意工作室把 dsh（DeepSeek Harness）作为会话宿主嵌入本应用时的外部契约：挂载路径与鉴权、宿主进程生命周期、会话与媒体存放、模型调用出口、主题与导航一致性，以及运行时基线。

## ADDED Requirements

### Requirement: 创意视图在应用路径下挂载 dsh 外壳

应用 SHALL 在 `/studio/` 下提供创意会话界面，其内容由 dsh Web 外壳渲染。该路径 MUST 与应用其它视图同源可访问，MUST NOT 需要操作员单独打开另一个端口或另行登录。直接访问 `/studio/` 或其子路径 MUST 返回完整可用的外壳页面，MUST NOT 返回目录列表或空白页。

#### Scenario: 从应用内进入创意

- **WHEN** 操作员在应用中切到创意视图
- **THEN** 浏览器在 `/studio/` 下加载 dsh 外壳，会话列表与输入区可用

#### Scenario: 直接打开深链接

- **WHEN** 操作员在一个新标签页打开某个创意会话的 `/studio/` 深链接
- **THEN** 页面加载后直接定位到该会话，不出现 404 或空白

#### Scenario: 子路径资源

- **WHEN** 外壳加载脚本、样式或图标等子路径资源
- **THEN** 这些请求同样落在 `/studio/` 前缀下并成功返回，不出现跨前缀 404

### Requirement: 创意入口沿用现有访问控制

`/studio/` MUST 继承应用现有的访问控制，未通过认证的请求 MUST 被拒绝且 MUST NOT 触达宿主进程。宿主自身的引导令牌 MUST 由服务端在服务端侧换取，MUST NOT 以明文形式出现在页面源码、URL 查询串或前端日志中。

#### Scenario: 未登录访问

- **WHEN** 未通过现有认证的客户端请求 `/studio/`
- **THEN** 请求被拒绝，壳页面与宿主接口都不返回内容

#### Scenario: 引导令牌不外泄

- **WHEN** 已认证客户端打开创意视图
- **THEN** 页面源码与地址栏中都不含宿主引导令牌明文

### Requirement: 宿主不可用时创意入口给出可读错误

宿主进程未就绪、启动失败或崩溃时，创意入口 MUST 显示可读中文说明与重试入口，MUST NOT 显示空白页、无限加载或原始堆栈。宿主故障 MUST NOT 阻塞应用其它视图，MUST NOT 影响工作台与画布的既有功能。

#### Scenario: 宿主启动失败

- **WHEN** 宿主进程启动失败
- **THEN** 创意入口显示失败原因摘要与重试按钮，其它视图仍可正常打开

#### Scenario: 宿主崩溃后重试

- **WHEN** 宿主进程在会话中途崩溃，操作员点击重试
- **THEN** 宿主重新启动，已落盘会话可重新打开

### Requirement: 会话与媒体落在受控目录

创意会话 SHALL 持久化在宿主会话目录，应用重启后 MUST 能按会话标识恢复。创意媒体 MUST 继续存放在会话对应的媒体目录，宿主与工具 MUST 通过该目录读写，MUST NOT 把媒体二进制写入会话记录。

#### Scenario: 重启后恢复会话

- **WHEN** 应用重启后操作员打开此前使用过的创意会话
- **THEN** 该会话的消息历史可读，且媒体引用仍能解析到本地文件

#### Scenario: 会话记录不含二进制

- **WHEN** 检查某会话的持久化记录
- **THEN** 记录中只有文本与媒体引用路径，不含图片或视频的二进制内容

### Requirement: 创意模型调用必须经过应用代理与账本

宿主发起的每一次文本模型调用 MUST 经应用现有代理出口，MUST 使用应用解析出的当前模型与渠道，MUST 继续受预扣与结算约束。系统 MUST NOT 允许宿主直连上游渠道，MUST NOT 出现绕过账本的模型调用路径。代理不可用或余额不足时 MUST 以可读错误结束该轮。

#### Scenario: 正常一轮对话

- **WHEN** 操作员在创意会话发送一条消息
- **THEN** 该轮模型调用出现在应用账本中，并按既有规则预扣与结算

#### Scenario: 余额不足

- **WHEN** 账本余额不足以支撑该轮调用
- **THEN** 该轮以可读的余额不足说明结束，不产生上游扣费

#### Scenario: 代理不可用

- **WHEN** 应用代理进程不可用
- **THEN** 该轮以可读错误结束，界面提示可重试

### Requirement: 外壳与应用主题和导航保持一致

创意外壳 MUST 跟随应用当前主题，在夜间与日间两套主题下都 MUST 呈现对应表面与文字配色。进入与离开创意视图 MUST NOT 改变应用全局导航按钮的水平位置，偏移 MUST NOT 超过 2px。

#### Scenario: 日间主题下的外壳

- **WHEN** 应用处于日间主题且操作员打开创意视图
- **THEN** 外壳使用浅色表面与深色文字，不残留整块深色区域

#### Scenario: 往返后导航稳定

- **WHEN** 操作员从镜头表切到创意再切回镜头表
- **THEN** 全局导航按钮的水平位置与离开前相差不超过 2px

### Requirement: 运行时基线满足宿主最低版本

应用运行环境 MUST 满足宿主声明的最低 Node 版本，服务端打包目标与桌面端内置运行时 MUST 与该基线一致。应用启动时 MUST 校验运行时版本，不满足时 MUST 以可读错误阻止启动并指明所需版本。

#### Scenario: 版本达标

- **WHEN** 应用在满足最低版本要求的运行时上启动
- **THEN** 启动自检通过，创意入口可用

#### Scenario: 版本过低

- **WHEN** 运行时不满足最低版本要求
- **THEN** 启动以可读错误终止，错误指明当前版本与所需最低版本
