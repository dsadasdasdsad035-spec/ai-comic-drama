# Spec Delta

## ADDED Requirements

### Requirement: 创意视图只呈现宿主对话外壳

创意视图 SHALL 只呈现宿主的对话外壳，包括会话列表、消息流、输入区与工具结果卡片。视图 MUST NOT 保留创意专属的产物栏、能力托盘、媒体摄取行、模式切换器、示例卡片或模型下拉。查看产物 MUST 通过工具结果卡片中的媒体引用或工作台视图完成。

#### Scenario: 打开有产物的会话

- **WHEN** 操作员打开一个已生成图片、视频或提示词包的创意会话
- **THEN** 界面只有宿主外壳，产物可从对应工具卡片打开，界面不出现独立的产物栏

#### Scenario: 没有产物

- **WHEN** 新会话尚无任何产物
- **THEN** 界面只显示会话列表、消息流与输入区，不出现空的产物区或占位

#### Scenario: 模式与示例

- **WHEN** 操作员在创意视图中查看界面
- **THEN** 不出现模式切换器与固定示例列表，界面不使用「策划/反推/复刻」模式标签

## REMOVED Requirements

### Requirement: 产物与对话并列为两列

**Reason**: 创意外壳由宿主渲染，不再维护创意专属的三列布局与可折叠产物栏。

**Migration**: 产物改由工具结果卡片中的媒体引用呈现；需要在画布或镜头表继续编辑时，到对应工作台视图操作。

### Requirement: 对话列有固定的阅读宽度

**Reason**: 对话列宽度由宿主外壳的排版决定，应用不再单独约束创意对话列的像素宽度。

**Migration**: 阅读宽度与排版随宿主外壳统一；需要整体样式对齐时在宿主主题层调整，不在应用侧另设宽度规则。

### Requirement: 媒体摄取控件按模式出现

**Reason**: 模式切换器与媒体摄取行随创意专属界面一并移除，源视频的链接输入、上传、切分与抽帧改由创意工具承担。

**Migration**: 在对话中调用对应的源视频与切分抽帧工具完成摄取；参数与结果仍按工具契约校验。

### Requirement: 示例与模式标签各只出现一次

**Reason**: 宿主外壳没有创意示例卡片与模式标签，该去重约束失去对象。

**Migration**: 空态由宿主外壳的默认空态承担，不再提供可点击填入的创意示例。

### Requirement: 会话列表给足可辨认信息

**Reason**: 会话列表由宿主外壳渲染，其信息密度与操作入口由宿主决定，应用不再单独约束标题宽度与悬停入口。

**Migration**: 会话标题与更新时间沿用宿主会话列表；需要重命名或删除时使用宿主提供的会话操作。

### Requirement: 会话头部与底部保持一行

**Reason**: 创意会话头部不再显示模型短名与创意专属次要信息，该布局约束失去对象。

**Migration**: 模型信息在宿主设置中查看，输入区高度由宿主外壳决定。
