# Spec Delta

## ADDED Requirements

### Requirement: 模型生成期间必须显示增量反馈

聊天 SHALL 在模型生成期间持续显示可观察的增量反馈：至少包含已接收字符数；启用文本流时 MUST 增量显示面向用户的说明文字。反馈 MUST 随生成推进更新，MUST NOT 只等整轮结束后一次性出现。未启用文本流时 MUST NOT 把原始 JSON、转义片段或 reasoning 增量当作聊天文本显示。

#### Scenario: 长输出进度

- **WHEN** 一次模型调用持续超过 3 秒
- **THEN** 聊天显示已接收字符数并持续更新，而不是只显示“模型调用中…”

#### Scenario: 文本增量

- **WHEN** 文本流启用且模型开始返回面向用户的说明文字
- **THEN** 文字按增量追加到同一条助手消息，结束时与完整说明一致

#### Scenario: 原始片段不外露

- **WHEN** 工具参数或 reasoning 以增量形式到达
- **THEN** 聊天不把这些片段作为助手说明显示

### Requirement: 重试与取消必须清理未完成的流

模型调用失败后重试时，聊天 MUST 丢弃失败那一轮已显示的半截文本；用户取消时 MUST 停止继续追加，并保留取消前已确认的内容。半截内容 MUST NOT 被当成完整结果、写入项目或参与验收。

#### Scenario: 修复重试

- **WHEN** 一轮模型输出中途失败并进入修复重试
- **THEN** 聊天移除该轮的半截文字，只保留重试后的新内容

#### Scenario: 用户取消

- **WHEN** 用户在文本流进行中取消
- **THEN** 文本停止追加，消息标记为已取消，旧代码和旧视频不被修改
