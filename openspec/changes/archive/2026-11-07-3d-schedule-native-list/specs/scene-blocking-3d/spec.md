# Spec Delta

## ADDED Requirements

### Requirement: 3D 调度列表只展示调度域字段

3D 调度视图的镜头列表 MUST 为每镜展示调度状态（未渲染 / 生效 / 仅审阅 / 已过期）、打开 3D 工作台的入口，以及有则展示的预演视频查看入口。列表 MUST 展示与该镜 3D 调度直接相关的摘要：当前代码哈希短码（无代码时标明无代码）与 `motion_note` 运镜说明（空时标明缺失）。列表 MUST NOT 将镜号、出场角色、场次或画布同步状态作为可见列展示。系统 MAY 在行 hover 提示或无障碍属性中暴露镜号以便辨认，但 MUST NOT 恢复为表头列。每行 MUST 携带可稳定定位该镜头的机器可读标识（与项目镜头 id 一致）。

#### Scenario: 列表无剧本制表列

- **WHEN** 用户在 3D 调度视图浏览当前集镜头列表
- **THEN** 表头不出现镜号、出场、场次列
- **AND** 每行仍显示调度状态与「打开」

#### Scenario: 代码与运镜摘要

- **WHEN** 某镜已保存 `sceneCode` 且存在 `motion_note`
- **THEN** 列表该行显示代码哈希短码与运镜文本摘要

#### Scenario: 无代码镜头

- **WHEN** 某镜没有 `sceneCode`
- **THEN** 列表标明无代码，并仍提供「打开」

#### Scenario: 稳定定位

- **WHEN** 自动化或脚本需要选中指定镜头行
- **THEN** 可通过该行与镜头 id 绑定的 DOM 属性定位，而不依赖镜号单元格文本

#### Scenario: 镜号在工作台顶栏

- **WHEN** 用户从列表打开某镜 3D 工作台
- **THEN** 工作台顶栏仍显示该镜镜号与集号
