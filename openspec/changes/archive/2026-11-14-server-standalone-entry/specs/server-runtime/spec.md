# Spec Delta

## Purpose

为应用提供一个可独立启动的 HTTP 运行时：同一个进程同时托管前端静态产物与全部 `/api/*` 接口，并能把数据、媒体写入位置从代码目录迁到可配置目录，使桌面端与容器都能在只读安装包之外运行。

## ADDED Requirements

### Requirement: 独立进程启动与端口上报

系统 SHALL 提供一个无需 Vite dev server 即可启动的 HTTP 入口。绑定端口 MUST 可由环境变量指定，值为 `0` 时 MUST 由操作系统分配；绑定成功后 MUST 在标准输出打印含实际端口与监听地址的一行握手信息，供上层进程解析。

#### Scenario: 默认端口启动
- **WHEN** 未设置端口环境变量启动入口
- **THEN** 进程在 127.0.0.1 上以默认端口开始监听，并在标准输出打印包含该端口与地址的握手行

#### Scenario: 系统分配端口
- **WHEN** 端口环境变量设为 `0`
- **THEN** 进程绑定到系统分配的随机可用端口，标准输出打印的端口等于实际监听端口

#### Scenario: 端口被占用
- **WHEN** 指定端口已被其它进程占用
- **THEN** 进程以非零状态退出，并在标准错误输出指明端口与失败原因，MUST NOT 静默继续

### Requirement: 仅绑定回环地址

系统 SHALL 默认只监听回环地址。未经显式配置，接口与静态资源 MUST NOT 在局域网或公网可达。

#### Scenario: 默认监听范围
- **WHEN** 以默认配置启动
- **THEN** 仅 `127.0.0.1` 可访问，其它网卡地址连接被拒绝

### Requirement: 静态产物托管与 SPA 回退

系统 SHALL 从构建产物目录提供前端静态文件，并对未知的非接口路径回退到入口 HTML，使前端路由刷新可用。命中真实文件的路径 MUST 返回文件本身而非入口 HTML。

#### Scenario: 前端深链刷新
- **WHEN** 请求一个在构建产物中不存在的非 `/api/` 路径
- **THEN** 返回入口 HTML 且状态码为 200

#### Scenario: 静态资源直出
- **WHEN** 请求构建产物中存在的资源路径
- **THEN** 返回该文件内容，并带有与该扩展名匹配的 Content-Type

#### Scenario: 未知接口不回退
- **WHEN** 请求未实现的 `/api/` 路径
- **THEN** 返回 JSON 形式的 404 或明确的未实现错误，MUST NOT 返回入口 HTML

### Requirement: 媒体根可配置

系统 SHALL 从环境变量解析媒体根目录，用于生成产物、视频、配音、导出包与发布包的读写。URL 前缀 MUST 保持 `/generated/`、`/videos/`、`/voices/`、`/exports/`、`/publish-packages/` 不变，使前端与既有验收脚本无需改动。未配置媒体根时 MUST 回退到仓库内 `public/`，保持现有开发行为。

#### Scenario: 自定义媒体根读写一致
- **WHEN** 媒体根指向代码目录之外的路径，且接口在其中写入一个生成产物
- **THEN** 文件落在该路径下，且通过对应 URL 前缀可下载到同一文件

#### Scenario: 未配置时保持旧行为
- **WHEN** 未设置媒体根环境变量
- **THEN** 读写仍落在 `public/` 下的同名子目录

#### Scenario: 路径穿越被拒绝
- **WHEN** 请求的媒体路径包含 `..` 或解析后落在媒体根之外
- **THEN** 请求被拒绝并返回错误状态，MUST NOT 返回媒体根之外的文件

### Requirement: 健康检查

系统 SHALL 提供健康检查接口，在服务可接受请求后返回成功状态与版本信息。桌面外壳与容器编排 MUST 能以该接口判断服务是否就绪。

#### Scenario: 服务就绪
- **WHEN** 进程已开始监听并请求健康检查接口
- **THEN** 返回成功状态与运行版本信息

### Requirement: 优雅退出

系统 SHALL 在收到终止信号后停止接受新连接、结束进行中的请求并释放资源，然后以零状态退出。等待超时后 MUST 强制退出，避免进程悬挂。

#### Scenario: 收到终止信号
- **WHEN** 进程收到 SIGTERM 或 SIGINT
- **THEN** 停止监听并在进行中请求结束后退出，退出码为 0

### Requirement: 开发与独立运行共用同一实现

系统 SHALL 由同一份接口实现同时服务开发模式与独立运行模式。开发模式下 MUST 保持现有默认地址与端口，使既有验收脚本无需修改即可运行。

#### Scenario: 开发模式行为不变
- **WHEN** 以开发模式启动
- **THEN** 前端页面与 `/api/*` 接口仍在 `127.0.0.1:5273` 可用，既有验收脚本按原地址访问成功

#### Scenario: 两种模式路由一致
- **WHEN** 同一请求分别发往开发模式与独立运行模式
- **THEN** 两者返回相同状态码与相同业务负载，差异仅限开发模式额外的模块热更新能力
