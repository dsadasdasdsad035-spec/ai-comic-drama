# Proposal

## Why

当前 3D 调度是「结构化 ShotScene/ShotBlocking + 受限 patch 聊天」：用户能改机位、墙、固定物，但改不了材质、贴图、自定义几何和任意运镜；角色图、场景图、道具图、分镜生成图和视频只能做参考板，不能成为 Three.js 场景里的贴图或背景板。编辑器又围绕 SVG 平面和属性面板设计，参考内容不可选、聊天只收文本，无法支撑“围绕选中素材直接生成 3D”的工作方式。

纯 Three.js 代码可以解除这些限制：每个镜头一段代码，聊天直接改写代码，选中的角色/场景/道具/分镜图可以作为纹理或背景板，视频以关键帧参与。代价是放弃结构化空间校验、穿墙检查、空间连续性和由几何自动推导的运镜文案；这些必须如实标注，不能伪装成仍然存在。

## What Changes

- **BREAKING** 新镜头以每镜 `SceneCode` 为唯一场景真相：一段可执行的 Three.js 代码，替代 `ShotScene`/`ShotBlocking` 作为新编辑入口。旧结构化数据保留为 legacy 只读渲染，不再提供结构化拖拽编辑。
- 增加最小运行时 ABI：`init(ctx)`、`renderAt(t, mode)`、`dispose()`；运行时提供 Three.js、canvas、camera、scene、renderer、时长/画幅和已选素材，代码决定场景内容与镜头运动。
- 增加沙箱执行：独立 iframe、无同源权限、CSP 禁止网络与外部脚本、素材通过 `postMessage` 传入、初始化/单帧/总渲染超时、代码大小和素材数量上限；代码错误不写入项目。
- 重做 3D 调度工作台布局：顶部镜头信息与保存/渲染；左侧可选参考内容；中间大预览和时间轴；右侧聊天/代码双页签。移除 SVG 平面与“本镜空间/镜头走位”模式。
- 增加每镜参考内容选择器，可选择角色图、项目素材图、场景、道具、当前分镜图/候选图、项目生成图片、视频，以及逐句台词、prompt、videoPrompt、cast、景别/运镜/秒数、画面标注。默认带入本镜相关项，可搜索、预览、勾选、移除，并按镜头持久化。
- 选中内容同时进入两条链路：作为代码可直接使用的图片/关键帧素材，以及作为图片/视频理解 brief 进入代码生成和聊天；聊天不再直接调用视频理解模型，视频统一以关键帧进入聊天。
- 聊天可直接生成/改写 Three.js 代码，返回完整代码与一句说明；代码先在沙箱试运行，成功才进入草稿/撤销栈，保存后才落库。代码页签允许人工修改并重新运行。
- 增加代码来源与媒体理解可见性：显示“AI 生成/手改/legacy/兜底”、用了哪些选中素材、图片/视频 brief 是否真的参与、代码哈希与渲染过期状态。
- 渲染指纹改为 `codeHash + 素材指纹 + 时长 + 画幅 + ABI 版本`；代码、选中素材、时长或画幅变化后旧 `scheduleVideo` 标为过期，仍阻止静默复用为 Seedance 参考。
- 旧 `shotScene`/`shotBlocking`/`sceneLayouts` 与旧 `scheduleVideo` 保持可读、可播放；旧结构化镜头显示只读 legacy 预览，并提供显式的“AI 生成代码版本”，不自动覆盖旧数据。
- 设置增加“3D 代码”文本环节；视频理解作为可选能力，配置了支持视频输入的模型时用于首次代码生成，未配置或失败时回退关键帧 + 图像理解，聊天始终只用关键帧。
- 明确移除：拖拽角色/墙体/固定物、数值精修、碰撞/穿墙校验、相邻镜结构差异提示、自动从几何推导运镜文案。`motionNote` 改为代码生成或用户编辑的说明，不再声称由代码自动推导。

## Capabilities

### New Capabilities

- `scene-code-runtime`: 每镜 Three.js 代码的最小 ABI、沙箱执行、素材注入、试运行/录制、超时与错误回滚、代码与素材指纹。
- `shot-3d-context`: 3D 调度可选择的角色/素材/场景/道具/图片/视频/文本上下文，预览与持久化，以及图片和视频关键帧的媒体理解 brief。

### Modified Capabilities

- `scene-blocking-3d`: 3D 调度从结构化场景/走位改为代码优先工作台；保留 legacy 兼容、渲染时长/画幅、过期拦截和下游参考通路，移除结构化编辑与自动几何推导。

## Impact

- 代码：新增 `sceneCode` 类型、代码生成/聊天编排、沙箱 iframe 运行时、素材传输与指纹、媒体 brief；重写 `SceneScheduleEditor` 为代码工作台并拆分参考内容选择器、代码聊天、代码预览；`shot3dJob`/`shotChat`/`schedule3d` 的结构化链路保留为 legacy，不再作为新编辑器主路径。
- 数据：镜头新增 `sceneCode`、`sceneCodeMeta`、`shot3DContext`（snake_case `scene_code` / `scene_code_meta` / `shot_3d_context`）；继续复用 SQLite `shots.extra`，无需新建表。旧 `shotScene`/`shotBlocking`/`visualBrief` 保留只读兼容。
- API/服务端：沿用 `/api/text`、`/api/vision`、`/api/frames`、`/api/save-video`、`/api/media`；新增沙箱页面/构建入口与必要的 CSP/静态资源头；如启用原生视频理解，增加受控的视频输入路由，不把 Key 或临时 URL 写入项目。
- 模型：新增 `sceneCode` 文本环节；`vision` 继续处理图片/视频关键帧；`videoVision` 为可选视频理解能力。当前标准方舟 Key/视频理解模型缺失时，必须回退关键帧并明确标注，不阻塞代码工作台。
- 安全：沙箱无同源、无网络、无父页面 DOM/存储访问；代码大小、素材数量、图片尺寸、执行时长均设上限；项目只保存代码文本、选择和指纹摘要，不保存临时 blob/dataURL 或模型原始响应。
- 依赖：继续使用现有 Three.js、MediaRecorder、ffmpeg；不新增云渲染、对象存储或外部代码执行服务。
- 验证：新增沙箱安全/超时/错误回滚、代码全文替换、素材选择与持久化、媒体 brief、legacy 兼容、代码指纹过期、渲染时长/画幅、窄屏布局回归；保留现有 Seedance 视频参考与抽帧回归。
- 文档：README 更新代码 ABI、参考内容选择、聊天改代码、legacy 状态和模型前置条件。
- 不包含：自动把旧 ShotScene 无损转成语义等价的代码、结构化碰撞/连续性校验、视频纹理逐帧确定性播放、云渲染队列、实时协作、任意网络资源或第三方 Three.js 插件。
