# Spec Delta

## ADDED Requirements

### Requirement: 删除项目后的全局上下文回退

项目被删除后，系统 SHALL 立即更新全局项目列表；若删除的是当前项目，MUST 把全局上下文切换到剩余项目之一或「未选项目」，并 MUST 清除该项目的浏览器画布状态。回退后的视图 MUST NOT 显示已删除项目的镜头、角色、成片或发布记录，也 MUST NOT 把旧项目数据写入新选中的项目。

#### Scenario: 删除当前项目

- **WHEN** 用户删除当前正在使用的项目
- **THEN** 顶栏项目选择器切到剩余项目或「未选项目」，各项目视图重新加载回退后的上下文

#### Scenario: 删除非当前项目

- **WHEN** 用户删除一个不是当前项目的项目
- **THEN** 当前项目与各视图内容保持不变，只有项目列表少一项

#### Scenario: 画布状态被清除

- **WHEN** 删除项目后用同名重新创建并打开画布
- **THEN** 画布不恢复被删除项目的节点与连线

#### Scenario: 删除最后一个项目

- **WHEN** 系统中只剩一个项目且被删除
- **THEN** 顶栏显示「未选项目」，项目视图进入空状态，系统不自动创建新项目

#### Scenario: 删除后不再写入旧项目

- **WHEN** 用户删除项目后在回退后的上下文里保存数据
- **THEN** 写入只发往回退后的项目，不触发针对已删除项目的请求
