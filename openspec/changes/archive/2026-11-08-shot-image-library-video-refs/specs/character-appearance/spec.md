# Spec Delta

## MODIFIED Requirements

### Requirement: 参考图不进入分镜参考预算

分镜出图的参考图集合 MUST 只由镜头连线、镜上静帧预览（`refImage`）、角色三视图与表情单格、手工参考组成。角色参考图 MUST NOT 被自动加入；MUST NOT 占用每镜的参考图上限。视频出片附件 MUST NOT 包含角色参考图，且 MUST NOT 因镜上静帧预览 alone 而增加视频参考项。

#### Scenario: 有参考图但不影响出图
- **WHEN** 一个角色有三张参考图，其所在分镜出图
- **THEN** 该镜的参考图集合不含这三张，数量与上限计算与没有参考图时一致

#### Scenario: 出片附件清单
- **WHEN** 用户打开某镜的出片提示词面板
- **THEN** 附件清单不出现角色参考图，也不把镜上静帧预览标为已附加视频参考；仍只列连线解析出的三视图或表情单格
