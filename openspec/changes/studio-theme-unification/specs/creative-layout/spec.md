# Spec Delta

## ADDED Requirements

### Requirement: 创意视图沿用应用的设计尺度

创意外壳内可交互控件（按钮、输入框、选择器、卡片、气泡与列表项）的圆角与描边粗细 MUST 落在应用自身控件的取值体系内，MUST NOT 呈现明显更圆或更钝的另一套形状。分层面板与大面积容器的圆角 MUST NOT 大到与「应用内的容器都是方正的」这一观感冲突。

同一控件类型在外壳内 MUST 共享同一圆角取值；相邻层级（如卡片与其内部小按钮）MUST 保持可辨认的圆角差，MUST NOT 压到相同值导致层级糊成一片。

#### Scenario: 输入区的形状

- **WHEN** 操作员查看创意视图的输入区与发送按钮
- **THEN** 两者圆角与应用同类控件一致，输入区不呈现接近胶囊形的超大圆角

#### Scenario: 卡片与内部控件

- **WHEN** 一条工具结果卡片内含按钮或标签
- **THEN** 卡片与内部控件的圆角可分辨，两者不同值且都落应用的取值体系内

#### Scenario: 两套主题下尺度一致

- **WHEN** 在夜间与日间主题下分别打开创意视图
- **THEN** 同一控件的圆角相同，尺度不随主题变化

### Requirement: 创意视图不冒充宿主产品的品牌标识

创意外壳 MUST NOT 向操作员呈现宿主产品的名称、图标或版本信息作为产品身份。标签页标题 MUST 使用应用名称；侧栏的宿主版本徽标与首页空态的大幅宿主吉祥物 MUST NOT 出现在创意视图内。

外壳中的应用内标识 MUST NOT 由应用自造素材替换宿主图标——宿主侧栏图标 MUST 保留原样，降噪只做减法。

#### Scenario: 标签页标题

- **WHEN** 应用运行在桌面端且当前视图为创意会话
- **THEN** 窗口标题显示应用名称，不显示宿主产品名

#### Scenario: 版本徽标与吉祥物

- **WHEN** 操作员打开创意视图并观察侧栏与首页空态
- **THEN** 侧栏不显示宿主版本徽标，首页空态不显示宿主吉祥物

#### Scenario: 侧栏图标

- **WHEN** 操作员查看创意视图侧栏顶部的应用内图标
- **THEN** 该位置显示宿主原有图标，不出现应用自造的替代图形

#### Scenario: 降噪不损伤布局

- **WHEN** 版本徽标与首页吉祥物被隐藏后
- **THEN** 侧栏项间距、首页输入区位置与已保存会话的列表布局不出现塌陷或跳动
