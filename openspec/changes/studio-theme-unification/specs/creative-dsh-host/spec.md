# Spec Delta

## ADDED Requirements

### Requirement: 宿主调色板镜像应用语义 token

创意外壳的调色板变量 MUST 写在宿主文档中真正生效的声明层（`body` 及其内联样式）上，MUST NOT 只写在文档根节点——宿主把两套调色板直接声明在 `body` 上，根节点的自定义属性会被继承覆盖而不生效。

外壳的表面、描边、文字三层、主色、交互态、区域专用表面与滚动条 MUST 取自应用当前主题的语义 token，MUST NOT 保留宿主默认的中性灰。外壳内正文与辅助文字的色相 MUST 与应用同层级文字一致。

#### Scenario: 夜间主题下的调色板

- **WHEN** 应用处于夜间主题且操作员打开创意视图
- **THEN** 外壳底色、侧栏底、分层面与描边分别等于应用夜间主题的对应语义 token 值，不出现与外壳不一致的中性灰黑

#### Scenario: 日间主题下的调色板

- **WHEN** 应用处于日间主题且操作员打开创意视图
- **THEN** 外壳底色、侧栏底、分层面与描边分别等于应用日间主题的对应语义 token 值，不出现纯白底或残留深色块

#### Scenario: 文字三层跟随应用

- **WHEN** 读取外壳内主要文字、次要文字与弱化文字的实际颜色
- **THEN** 三者分别等于应用当前主题的正文色、次级色与弱化色，而不是宿主的默认文字色阶

#### Scenario: 宿主新增调色板变量时不阻断渲染

- **WHEN** 宿主版本引入了应用尚未映射的调色板变量
- **THEN** 外壳仍完整渲染且可交互，只有该变量对应的局部区域沿用宿主默认色，不出现透明背景或不可读文字

### Requirement: 应用是创意外壳明暗的唯一决定者

应用当前主题 MUST 是创意外壳明暗的唯一来源。宿主侧的明暗状态改写 MUST NOT 改变外壳配色：当宿主移除或重设明暗标记、或改写调色板变量时，应用 MUST 在一个可测的短时限内把调色板重新写回应用当前主题。

宿主设置页中与外观决定权冲突的开关 MUST NOT 影响外壳配色；该开关被隐藏时，隐藏行为 MUST NOT 影响设置页其余行、MUST NOT 影响配色，隐藏未命中时 MUST 退化为一个无效开关而不是布局错乱或脚本报错。

外壳在加载遮罩撤除之前 MUST 已经是目标主题的底色，MUST NOT 出现先按宿主默认主题绘制、再被改写的一帧。

#### Scenario: 宿主去掉暗色标记后被重新贴回

- **WHEN** 外壳在夜间主题下运行，宿主侧把明暗标记移除
- **THEN** 在时限内暗色标记与夜间调色板被重新写回，界面不残留浅色表面

#### Scenario: 在宿主设置页切换外观

- **WHEN** 夜间主题下操作员进入宿主设置页把外观改为浅色
- **THEN** 创意外壳保持夜间配色，应用切到日间后外壳随之变浅

#### Scenario: 首帧不闪错主题

- **WHEN** 应用处于日间主题、宿主自身偏好为深色，操作员首次打开创意视图
- **THEN** 加载遮罩撤除时外壳已经是日间底色，不出现深色外壳再翻转的可见过程

#### Scenario: 隐藏设置行未命中

- **WHEN** 宿主文案或结构变化导致外观设置行未被隐藏
- **THEN** 设置页其余行正常显示与操作，该行切换不改变外壳配色，控制台不出现脚本异常
