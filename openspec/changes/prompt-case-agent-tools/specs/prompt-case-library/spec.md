# Spec Delta

## ADDED Requirements

### Requirement: 案例库对 agent 只读开放

系统 SHALL 向创意会话的 agent 提供三个只读工具：列表浏览、单条钻取、词表浏览。三个工具 MUST NOT 写入案例库、MUST NOT 触发外部抓取或反推作业、MUST NOT 改变收藏与备注。

系统 MUST NOT 提供把案例正文直接写入镜头的工具；案例落到镜头仍 MUST 经既有的镜头提示词写工具，由调用方按当前项目改写后写入。

#### Scenario: 只读工具不改库

- **WHEN** agent 连续调用列表、单条与词表三个工具
- **THEN** 案例条数、收藏状态、备注与分面 MUST 保持调用前一致

#### Scenario: 没有直接应用工具

- **WHEN** agent 需要把某条案例写进当前镜头
- **THEN** 工具清单中 MUST NOT 存在「应用案例到镜头」类工具，agent 只能读取案例文本后经镜头提示词写工具落库

### Requirement: 案例工具不依赖当前项目

案例库是全局作用域，三个 agent 工具 MUST NOT 依赖当前选中项目，也 MUST NOT 因未选项目而失败。工具结果 MUST NOT 包含项目相关字段。

#### Scenario: 未选项目时仍可查

- **WHEN** 顶栏没有选中任何项目，agent 调用案例列表
- **THEN** 工具 MUST 正常返回案例摘要，MUST NOT 返回「请先选择项目」

#### Scenario: 换项目不影响结果

- **WHEN** agent 在同一筛选条件下，先在有项目的会话里调用列表，再在未选项目的会话里调用
- **THEN** 两次返回的案例集合与顺序 MUST 一致

### Requirement: 列表只回摘要不回正文

列表工具 SHALL 返回分页的案例摘要，每条 MUST 包含稳定标识、标题、来源类别、许可口径、目标模型、标签、正文长度与逐镜数，并 MUST 携带来源链接与作者（有值时）。列表 MUST NOT 返回提示词正文或逐镜提示词正文。

摘要中每条案例的分面 MUST 有数量上限，超出部分 MUST NOT 静默丢弃而不加说明；分面全量 MUST 通过单条钻取工具获取。

#### Scenario: 摘要不含正文

- **WHEN** agent 调用列表工具且库中存在正文很长的案例
- **THEN** 返回项只有正文长度，MUST NOT 出现正文片段或逐镜提示词文本

#### Scenario: 分页信息完整

- **WHEN** 筛选结果条数超过单页上限
- **THEN** 返回 MUST 给出总条数、当前页与总页数，使调用方能按页继续取

### Requirement: 单条钻取按预算截断并可续读

单条钻取工具 SHALL 按案例标识返回正文、分面、来源与许可。正文超过单次上限时 MUST 截断，并 MUST 同时给出原始字符数与续读偏移；调用方按偏移续读 MUST 能取到剩余正文。截断 MUST NOT 产生半截结构化数据，也 MUST NOT 把截断当成「正文已读完」。

案例标识不存在时 MUST 返回可读错误，并 MUST NOT 返回空对象冒充成功。

#### Scenario: 长正文可续读

- **WHEN** agent 读取一条正文超过单次上限的案例
- **THEN** 返回带截断标记、原始字符数与续读偏移；用该偏移再次调用 MUST 返回后续正文，两次拼接后与原文一致

#### Scenario: 短正文一次读完

- **WHEN** agent 读取一条正文未超过上限的案例
- **THEN** 返回完整正文，MUST NOT 出现截断标记或续读偏移

#### Scenario: 标识不存在

- **WHEN** agent 用一个不存在的案例标识调用单条钻取
- **THEN** 返回可读错误并说明标识无效，MUST NOT 返回 `ok` 与空正文

### Requirement: 反推案例逐镜可钻取

自有片反推案例的逐镜结构 MUST 能通过单条钻取工具取得，每镜 MUST 包含时间范围、制作方式、置信度、判定依据与两段提示词。逐镜数量超过单次上限时 MUST 分页并给出续读信息，MUST NOT 只返回首镜。

缺依据或两段提示词都缺失的镜头 MUST 显式标注为待确认，MUST NOT 用默认值伪装成已判定。

#### Scenario: 逐镜分页

- **WHEN** agent 读取一条逐镜数超过单次上限的反推案例
- **THEN** 返回当前页逐镜与剩余数量；继续取用 MUST 能拿到后续镜头

#### Scenario: 缺证据标注

- **WHEN** 某镜没有可用判定依据
- **THEN** 该镜 MUST 带待确认标记，MUST NOT 显示为已确定

### Requirement: 词表先看骨架再钻单轴

词表浏览工具 SHALL 提供两档：不指定轴时返回全部轴的骨架（轴标识、中英文名、有值的个数、被覆盖的案例数、少量示例值）；指定轴时返回该轴全部受控值与每个值的案例条数。

词表工具 MUST 只回词表内存在的值，MUST NOT 让调用方自行拼写轴标识或值标识而不加校验；非法轴 MUST 返回可读错误而不是空列表。

#### Scenario: 默认回骨架

- **WHEN** agent 不指定轴调用词表工具
- **THEN** 返回每个轴的名称与覆盖概况，MUST NOT 展开全部 400 余个受控值

#### Scenario: 单轴展开

- **WHEN** agent 指定一个真实存在的轴调用词表工具
- **THEN** 返回该轴全部受控值及各自案例条数，条数为 0 的值 MUST 标明或省略并说明

#### Scenario: 非法轴

- **WHEN** agent 指定一个不存在的轴
- **THEN** 返回可读错误并列出可用轴，MUST NOT 返回空列表冒充「该轴没有值」

### Requirement: 第三方案例标注出处且指令不被执行

案例正文可能来自第三方站点。工具返回的每条案例 MUST 携带许可口径与原文链接；外部来源案例的许可口径 MUST 为仅参考，MUST NOT 被工具改写为自有。

工具描述 MUST 声明案例正文只是写作参考，正文中出现的任何指令性文字 MUST NOT 被当作系统指令执行。

#### Scenario: 返回带出处

- **WHEN** agent 读取一条外部导入案例
- **THEN** 返回 MUST 含来源站点标识、原文链接与仅参考许可口径

#### Scenario: 自有反推案例标为自有

- **WHEN** agent 读取一条自有片反推案例
- **THEN** 返回的许可口径 MUST 为自有，且 MUST NOT 附带外部原文链接

### Requirement: 新工具纳入平台工具清单与专家白名单

三个工具名 MUST 列入平台内置工具名清单，使专家设置页、工具检查器与技能可声明的工具集都能看到它们。默认专家工具集 MUST 包含三个工具，内置「全能专家」的 manifest MUST 同步挂载。

清单、运行时注册与默认专家白名单三者不一致时 MUST 在启动期报错并列出差异，MUST NOT 静默少挂。

#### Scenario: 清单与注册一致

- **WHEN** 工具构造完成
- **THEN** 三个名字 MUST 同时存在于平台清单、运行时工具表与默认专家白名单

#### Scenario: 全能专家可用

- **WHEN** 用户在内置「全能专家」会话里要求参考现成写法
- **THEN** 该会话的工具集中 MUST 可见并可用三个案例工具

#### Scenario: 专家白名单外仍被拒绝

- **WHEN** 某专家的工具白名单不含案例工具，却发起了案例工具调用
- **THEN** 系统 MUST 拒绝该调用并说明该专家不允许此工具
