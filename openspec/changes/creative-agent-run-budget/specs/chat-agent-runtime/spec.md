# Spec Delta

## MODIFIED Requirements

### Requirement: 运行上限与取消必须由运行时统一实现

每次聊天运行 SHALL 受总时长上限约束；超时 MUST 终止上游请求与进行中的工具。用户取消 MUST 立即停止产生新事件，MUST NOT 继续执行后续工具。运行时 MUST 自身响应取消信号，MUST NOT 依赖底层只中止当前请求就假定循环已停止。运行时 MUST NOT 设置默认的工具轮次预算；循环 MUST 只在模型不再返回工具调用、用户取消、总时长到点或底层错误时结束。如调用方显式提供内部安全阀，其触发 MAY 以可读错误结束；该错误 MUST NOT 作为默认产品行为或用户可配置设置。

#### Scenario: 运行超时

- **WHEN** 运行超过总时长上限
- **THEN** 上游请求与进行中的工具被终止，运行以超时错误结束

#### Scenario: 用户取消

- **WHEN** 用户在模型流或工具执行中取消
- **THEN** 后续工具不再执行，不再产生新的文本或工具事件

#### Scenario: 底层只中止当前请求

- **WHEN** 底层中止能力只覆盖当前模型流
- **THEN** 运行时自身保证循环退出，不继续调度下一轮

#### Scenario: 长工具序列不被步数截断

- **WHEN** 一次运行连续产生超过 16 轮工具调用且尚未达到总时长
- **THEN** 运行继续执行，不出现「工具循环达到 N 步上限」错误

## ADDED Requirements

### Requirement: 聊天总时长必须来自共享 Agent 运行上限设置

每次聊天运行的总时长 MUST 来自设置页「Agent 运行上限」，并 MUST 对 3D 与创意等所有聊天面生效。未配置时 MUST 使用默认值 300 秒。设置变更 MUST 从下一轮运行生效，MUST NOT 改变进行中的运行。

#### Scenario: 创意会话按设置运行

- **WHEN** 设置页 Agent 运行上限为 600 秒且用户在创意会话发送消息
- **THEN** 本轮运行最多持续 600 秒，而不是固定的 180 秒

#### Scenario: 未配置时使用默认值

- **WHEN** 设置为空或缺少总时长字段
- **THEN** 聊天运行使用 300 秒

#### Scenario: 配置变更不追溯

- **WHEN** 用户在一轮运行进行中修改总时长并保存
- **THEN** 当前运行仍按开始时的时长结束，新值从下一轮生效
