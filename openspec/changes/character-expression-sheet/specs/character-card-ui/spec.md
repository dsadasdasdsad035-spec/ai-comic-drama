# Spec Delta

## Purpose

重排角色卡的信息层级，让角色外观、表情总图、音色和参考预算在一张可扫描的卡里可见，同时把低频编辑与详细设置收进渐进披露。

## ADDED Requirements

### Requirement: 主图优先与页签

角色卡 MUST 把一张主图放在卡片视觉最前，主图区提供“三视图 / 表情总图 / 音色”三个页签；音色样本和音色选择 MUST NOT 排在主图之前。默认页签 MUST 优先显示已有三视图，其次已有表情总图，最后显示三视图空状态。

#### Scenario: 有三视图

- **WHEN** 角色有已选中的三视图
- **THEN** 卡片默认显示三视图页签，姓名和状态在主图旁可见

#### Scenario: 只有表情总图

- **WHEN** 角色没有三视图但有表情总图
- **THEN** 卡片默认显示表情总图页签，并明确提示三视图缺失

#### Scenario: 两个都没有

- **WHEN** 角色既没有三视图也没有表情总图
- **THEN** 卡片显示带内联生成按钮的三视图空状态，不显示空白大图区

### Requirement: 摘要行与状态

角色卡 MUST 在首屏显示姓名、定位、年龄、当前状态、音色名称和表情完成度；状态 MUST 区分就绪、生成中、缺图、失效和错误。完整身份字段和试音稿 MUST NOT 直接铺在卡片首屏。

#### Scenario: 就绪角色

- **WHEN** 角色有三视图、有效音色和表情总图
- **THEN** 摘要行显示“就绪”、音色名称和“表情 8/8”

#### Scenario: 失效角色

- **WHEN** `lookEn` 改动导致表情总图失效
- **THEN** 摘要行显示“表情需重生成”，不只靠缩略图颜色表达

### Requirement: 单一主操作

每张角色卡 MUST 只有一个视觉主操作，并按当前状态切换为“生成三视图”“生成表情总图”或“重生成”；编辑、删除、上传、试听、注入镜头等动作 MUST 收进次级操作或更多菜单。主操作 MUST 在 330px 卡宽、900px 视口高度下无需滚动即可看到。

#### Scenario: 空角色

- **WHEN** 角色没有三视图
- **THEN** 主操作是“生成三视图”，其他动作不与之同权

#### Scenario: 总图失效

- **WHEN** 角色有三视图但表情总图失效
- **THEN** 主操作是“重生成表情总图”，成本仍可见

### Requirement: 渐进披露编辑抽屉

点击“编辑”MUST 打开侧边抽屉或对话框编辑姓名、定位、年龄、外观锚点和试音稿；MUST NOT 在卡片正文内展开整块表单。抽屉 MUST 提供明确的保存和取消，取消 MUST 丢弃本次未保存改动；角色卡正文只在保存后更新。

#### Scenario: 编辑后保存

- **WHEN** 用户打开编辑抽屉修改 `lookEn` 并保存
- **THEN** 抽屉关闭，卡片摘要和表情失效状态更新

#### Scenario: 取消编辑

- **WHEN** 用户修改字段后点取消
- **THEN** 角色数据和卡片显示保持编辑前状态

### Requirement: 表情格交互

表情总图上的八个格子 MUST 有可读标签和至少 44×44 CSS 像素的可点击区域；选中格 MUST 同时有边框、标签和状态文字，不能只靠颜色区分。点击格子 MUST 只预览该格和显示情绪名称，MUST NOT 静默改写当前镜头的 `performance`；失效格 MUST 有可见的“需重生成”标记。

#### Scenario: 预览格子

- **WHEN** 用户点击表情总图里的 angry 格
- **THEN** 卡片放大或高亮该格并显示“愤怒”，镜头表演数据不变

#### Scenario: 键盘操作

- **WHEN** 用户用键盘在八个格子间移动并选择
- **THEN** 焦点可见，回车只触发预览，不修改镜头

### Requirement: 成本与参考预算

角色卡 MUST 显示一次表情总图生成的图片数量和估算成本；当角色被某镜使用且系统能确定该镜参考预算时，MUST 显示该角色的参考占用，例如“本镜 2/4 · 表情关/仅说话角色”。没有选中镜头时 MUST 显示“未选中镜头”，不得伪造预算。

#### Scenario: 显示生成成本

- **WHEN** 用户查看未生成的总图入口
- **THEN** 按钮旁显示“1 张 · ¥0.22”这类一次生成成本

#### Scenario: 显示参考占用

- **WHEN** 用户选中一个使用该角色的镜头
- **THEN** 卡片显示本镜参考槽位占用和表情参考是否开启

### Requirement: 空状态与错误状态

空状态 MUST 在主图区直接提供下一步动作，MUST NOT 使用“点下方按钮”但按钮在折叠线以下的文案。缺图、文件缺失、生成失败和失效 MUST 各自显示可执行的恢复动作或明确原因，MUST NOT 只显示一个通用错误色块。

#### Scenario: 没有三视图

- **WHEN** 角色没有三视图
- **THEN** 空状态内直接出现“生成三视图”按钮和当前成本

#### Scenario: 文件缺失

- **WHEN** 三视图或总图文件已不在项目媒体目录
- **THEN** 卡片显示“文件缺失”和重新生成/清除引用动作，不把它当作无图

### Requirement: 响应式与可访问性

角色卡 MUST 在 330px 宽度下不出现横向滚动；页签、主操作、表情格和编辑抽屉 MUST 可用键盘操作，并提供可见焦点和可访问名称。窗口变窄或右侧聊天面板展开时，主图和主操作 MUST 保持可见，不得被音色或表情详情挤出首屏。

#### Scenario: 窄卡宽度

- **WHEN** 卡片宽度为 330px
- **THEN** 摘要、页签和主操作正常换行，无横向滚动

#### Scenario: 聊天面板展开

- **WHEN** 右侧聊天面板展开导致内容区变窄
- **THEN** 主图和主操作仍可见，详细设置进入抽屉
