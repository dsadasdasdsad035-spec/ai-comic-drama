# Proposal

## Why

当前角色表情是“每个情绪生成一张、一次生成 2 张候选”，8 个情绪最多产生 16 张图，既增加生成费用，也让角色卡被表情区撑得过长。更关键的是，表情图不在画布素材层，用户看不见、不能连线；视频出片又只有 4 张参考图，表情会自动排在身份和场景之前，双人镜头很容易把身份/场景挤掉。

角色卡本身也把音色样本放在三视图之前，主操作经常落在折叠线以下，表情 chip 只有 22px，成本、失效状态和参考槽位都不可见。现在需要把表情收敛成“一张总图”，同时重排角色卡的信息层级和参考预算。

## What Changes

- **一张表情总图**：每个角色只保留一张 4×2 表情总图，固定 8 个情绪格（neutral / happy / sad / angry / fearful / disgusted / surprised / calm）；默认一次只生成 1 张，不再默认生成 2 张候选。
- **用身份图生成总图**：总图请求把角色三视图作为身份参考，而不是只靠 `lookEn` 文本重画；总图记录身份指纹，`lookEn` 变化时标 stale，但保留旧图。
- **总图作为一张画布素材**：角色卡提供“发布表情总图到画布”，画布上只出现一张 `expression-sheet` 素材卡；卡上显示 8 格缩略图和角色名。
- **分镜只用裁剪单格**：总图本身 MUST NOT 直接作为生成参考；分镜按 `performance[].emotion` 选择对应格子，裁剪成单张参考图后再发送。没有表演、没有对应格或总图失效时回退文字表演并说明原因。
- **视频表情参考改为显式可选**：视频出片默认不自动加入表情图，首帧/关键帧承担表情；用户可在镜头里显式开启“带说话角色表情参考”，且只在 4 张预算有富余时加入。提交前显示槽位分配和被省略项，不再只在提交后弹 Toast。
- **角色卡 UI/UX 重排**：主图优先（三视图 / 表情总图 / 音色三个页签）、摘要行（姓名/定位/年龄/状态/音色/表情完成度）、单一状态化主按钮、编辑抽屉、成本与参考预算 chip、空状态内联 CTA；表情格提供足够大的可点击区域和选中态。
- **旧数据只读兼容**：已有 `expressions[emotion]` 单图继续可读、可作为回退；不再新增逐情绪生成入口。不批量迁移、不删除旧图。

## Capabilities

### New Capabilities

- `character-expression-sheet`: 一张表情总图的生成、格子映射、裁剪缓存、画布素材发布、分镜按情绪取单格，以及成本和失效状态。
- `character-card-ui`: 角色卡的视觉层级、页签、摘要、主操作、编辑抽屉、成本/参考预算展示和空状态。

### Modified Capabilities

- `shot-video-prompt`: 视频参考预算从“按解析顺序截前 4 张”改为“先保当前画面、身份和场景，表情默认关闭、显式开启且只带说话角色”；提交前必须展示实际槽位和省略项。

## Impact

- 角色数据：`CharacterSheet` / `ProjectChar` 新增 `expressionSheet`；保留 `expressions` 作为旧数据回退。
- 生成链路：`CharacterBoard` 改为总图生成；新增格子裁剪与缓存；`src/shotReferences.ts` 优先解析总图单格。
- 画布：新增 `expression-sheet` 素材类型/节点元数据，复用现有素材卡连线和项目持久化；不新增第二套画布状态。
- 出片：`src/videoPrompt.ts`、`src/App.tsx`、`src/Inspector.tsx` 增加表情开关和参考预算预览；`shot-video-prompt` 的“N/4、省略项”要求扩展为分配策略。
- UI：`src/CharacterBoard.tsx`、`src/theme.css`；角色卡改为页签 + 摘要 + 抽屉，不再纵向堆叠所有模块。
- 兼容：依赖 `shot-performance-direction` 的 performance/表情语义；旧逐情绪图保留只读回退。归档顺序需先处理 `shot-performance-direction`，避免同一角色表情语义在主 specs 中重复。
- 测试与文档：新增总图/裁剪/画布/预算纯函数和 UI 用例，更新 README 与证据。
