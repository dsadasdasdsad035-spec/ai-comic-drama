# Spec Delta

## MODIFIED Requirements

### Requirement: 清空前取消进行中的运行

若本轮模型调用或内置动作仍在运行，系统 MUST 先取消它们，再清空线程。取消产生的半截轨迹 MUST NOT 被写回已清空的线程。

#### Scenario: 运行中清空

- **WHEN** 用户在助手正在生成时确认清空
- **THEN** 生成停止，线程变为空态，之后重开也不出现该轮半截文本

#### Scenario: 内置动作运行中清空

- **WHEN** 用户在其他工作台内置动作仍在运行，或镜头表 Agent 分镜产镜仍在运行时确认清空
- **THEN** 动作或请求被取消且不写入半份草稿，聊天为空
