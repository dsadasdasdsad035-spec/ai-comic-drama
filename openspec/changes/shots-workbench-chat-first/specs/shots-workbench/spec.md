# Spec Delta

## Purpose

定义镜头表工作台「左草稿、右聊天」的布局：左侧承载可编辑镜头列表与显式保存，产镜与结构性改镜仅经 Agent 聊天与分镜技能工具链。

## ADDED Requirements

### Requirement: 镜头表不提供页内梗概与拆镜条

镜头表工作台 MUST NOT 在主内容区上方渲染本集梗概输入框或「拆镜」按钮；MUST NOT 依赖页内 `brief` 字段作为产镜前置条件。

#### Scenario: 打开镜头表

- **WHEN** 用户进入镜头表视图且项目已加载
- **THEN** 主内容区直接展示当前集镜头列表或空态，不出现 `.wb-gen` 类梗概/拆镜条

#### Scenario: 切集不填充页内梗概

- **WHEN** 用户在全局带切换集号
- **THEN** 左侧镜头列表切换为该集数据，不出现仅用于拆镜的页内文本框

### Requirement: 左侧镜头草稿可编辑并显式保存

镜头表主区域 SHALL 展示当前集镜头行，并 MUST 支持编辑镜号、时长、景别、运镜、描述、台词、表演及相关手改保护；增删插镜、导入、清理孤儿、推画布等既有手工能力 MUST 保留。保存 MUST 沿用显式保存语义，写入 `project.shots` 前 MUST NOT 静默落库。

#### Scenario: 手改字段

- **WHEN** 用户修改某镜描述并保存
- **THEN** 该字段写入项目并参与手改保护，与变更前合并规则一致

#### Scenario: 聊天写入后左侧同步

- **WHEN** Agent 通过提交工具写入镜头草稿且用户尚未保存
- **THEN** 左侧列表展示合并后的草稿，并标记未保存状态

### Requirement: 产镜入口仅在 Agent

系统 SHALL 在镜头表视图移除顶栏与页内的「拆镜」入口。从零拆镜与按指令改镜 MUST 通过 Agent 聊天完成：模型可读本集/镜头表并调用提交工具返回 `shots-v1`；MUST 沿用现有技能契约、草稿合并与任务台账。镜头表聊天 MUST NOT 再提供与已删顶栏绑定的内置「拆镜」一键动作。

#### Scenario: 顶栏与页内无拆镜

- **WHEN** 用户查看镜头表上下文带与主内容区
- **THEN** 不出现「拆镜」按钮或本集梗概拆镜条

#### Scenario: 对话产镜

- **WHEN** 用户在 Agent 输入拆镜指令且模型提交合法镜头 JSON
- **THEN** 草稿合并进左侧列表，回执标明新增/更新计数与显式保存提示

#### Scenario: 无内置拆镜动作

- **WHEN** 用户打开镜头表 Agent 的内置动作列表
- **THEN** 不包含「拆镜」项（与已移除的顶栏按钮对应）

### Requirement: Agent 为默认产镜输入面

镜头表视图 SHALL 在首次进入（无用户记忆的开合状态时）默认展开 Agent 面板；用户 MUST 仍可通过 Agent 按钮收起。窄屏下 Agent  MAY 以抽屉呈现，但 MUST 可达且可输入。

#### Scenario: 宽屏默认展开

- **WHEN** 用户首次在宽屏打开镜头表且本地未记忆聊天开合
- **THEN** Agent 面板处于展开状态

#### Scenario: 空态指向聊天

- **WHEN** 当前集尚无镜头
- **THEN** 空态文案指引用户在 Agent 中描述如何拆镜，不提及页内梗概或顶栏拆镜

### Requirement: 剧本跳转打开镜头表 Agent

剧本分集列表中的「拆这一集」类入口 SHALL 切换到镜头表视图、选中对应集，并 MUST 使 Agent 面板处于可输入状态（展开或聚焦抽屉）。

#### Scenario: 从剧本跳转

- **WHEN** 用户在剧本页点击某集的拆镜跳转
- **THEN** 进入镜头表且集号一致，Agent 可立即输入，不要求用户先点拆镜按钮
