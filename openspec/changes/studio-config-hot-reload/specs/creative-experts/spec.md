## ADDED Requirements

### Requirement: 专家变更判据覆盖 persona 与白名单内容

系统判断专家是否需要重新同步时 MUST 依据专家内容本身，MUST NOT 只依据工具或技能的数量。判据 MUST 至少覆盖 `soul` 全文、显示名、说明、工具白名单内容与技能白名单内容。任一字段内容变化 MUST 触发重新同步，使后续会话使用更新后的 persona 与白名单；内容未变化时 MUST NOT 触发宿主重启。

#### Scenario: 修改 persona

- **WHEN** 操作员修改某专家 `soul.md` 的内容，白名单数量不变
- **THEN** 触发重新同步，后续会话的 system 为修改后的 persona

#### Scenario: 同数量替换工具

- **WHEN** 操作员把某专家的一个工具替换为另一个工具，工具数量不变
- **THEN** 触发重新同步，后续会话可用的工具为新白名单

#### Scenario: 同数量替换技能

- **WHEN** 操作员把某专家的一个技能替换为另一个技能，技能数量不变
- **THEN** 触发重新同步，后续会话可读取的技能为新白名单

#### Scenario: 内容未变化

- **WHEN** 操作员保存专家，内容与上一次完全一致
- **THEN** 不触发宿主重启

### Requirement: 技能集合变更后专家预设自动重建

技能安装、上传、卸载或技能覆盖重置后，系统 MUST 自动重建受影响专家的预设配置与技能根，MUST NOT 要求操作员再次保存专家设置。重建 MUST 保持既有白名单语义：白名单内的技能可见，白名单外不可见；通配白名单 MUST 覆盖重建时已存在的全部技能。

#### Scenario: 上传后直接使用

- **WHEN** 操作员上传技能后直接进入创意会话并使用该专家
- **THEN** 该技能已按白名单可见，无需再次保存专家设置

#### Scenario: 通配白名单覆盖新增技能

- **WHEN** 专家使用通配白名单，操作员新增一个技能
- **THEN** 该技能立即可用于该专家

#### Scenario: 卸载后从全部专家移除

- **WHEN** 操作员卸载某技能
- **THEN** 该技能不再出现在任何专家的技能根中

#### Scenario: 重建不打断进行中的会话

- **WHEN** 操作员在创意会话进行中上传技能并保存
- **THEN** 进行中的会话不受影响，重建结果在后续会话生效
