# Spec Delta

## ADDED Requirements

### Requirement: 剧本写回按集号合并且保留未提交的集

系统 SHALL 提供写回分集剧本的 Agent 工具，接受分集契约（`script-v1`）形状的载荷。写回 MUST 按集号合并：本次出现的集更新或新增，未出现的集 MUST 保持原样，MUST NOT 被删除。

顶层梗概一同写回时 MUST 与分集在同一次提交内生效。写回 MUST 是原子的：任一条目校验不通过时 MUST 整体不生效，MUST NOT 留下部分写入的集。

#### Scenario: 只改第 2 集

- **WHEN** agent 提交只包含第 2 集的分集载荷
- **THEN** 第 2 集被更新或新增，其余集的标题、场次与目标时长保持原值

#### Scenario: 校验失败整体不生效

- **WHEN** 提交的某一集缺少场次的必要叙事字段
- **THEN** 工具返回可读失败，项目里没有任何一集被改动

#### Scenario: 首次写回分集

- **WHEN** 项目还没有任何分集，agent 提交两集
- **THEN** 两集按集号顺序写入项目，回执报告新增集数

### Requirement: 剧本写回回执与实际落库一致

写回成功时 MUST 返回新增与更新的集数，且这些计数 MUST 与项目落库后的实际集数变化一致。落库失败时 MUST 返回失败，MUST NOT 报告成功计数。

#### Scenario: 落库被服务端拒绝

- **WHEN** 服务端拒绝一次分集写回
- **THEN** 调用方收到失败结果，后续读取看不到本次提交的内容
