# Spec Delta

## ADDED Requirements

### Requirement: Agent 出图走同一静帧产线并写回镜头

系统 SHALL 提供分镜静帧生成的 Agent 工具，复用与界面一致的静帧产线：生成结果 MUST 保存进当前项目媒体目录并返回站内项目媒体地址，MUST 写入该镜的首帧字段，并 MAY 追加到候选列表。

该工具 MUST 只对工位类型为生图的镜头开放；工位类型为出片的镜头调用时 MUST 返回可读错误，MUST NOT 静默改写其工位类型。生成前 MUST 取得成本确认，未确认 MUST NOT 发起请求。

生成成功 MUST NOT 自动创建画布素材卡，MUST NOT 自动向该镜的参考连线追加节点标识。

#### Scenario: 生图镜成功出图

- **WHEN** agent 对一个工位为生图的镜头完成成本确认后调用出图
- **THEN** 该镜首帧指向新的站内媒体地址，候选列表包含本次结果

#### Scenario: 出片镜调用出图

- **WHEN** agent 对工位为出片的镜头调用出图工具
- **THEN** 工具返回可读错误，该镜工位与首帧保持不变

#### Scenario: 用户拒绝成本确认

- **WHEN** 用户在成本确认中选择取消
- **THEN** 不发起生成请求，镜头字段保持原样

### Requirement: Agent 配音写回该镜声音引用

系统 SHALL 提供分镜配音生成的 Agent 工具，复用与界面一致的配音产线。生成成功 MUST 把音频地址与配音元数据写入该镜，MUST NOT 只把结果留在工具回执里。

生成前 MUST 取得成本确认；未确认或生成失败时 MUST 返回失败，镜头的声音引用保持不变。

#### Scenario: 配音成功

- **WHEN** agent 对某镜完成确认后生成配音
- **THEN** 该镜声音引用与配音元数据指向新产物，重开项目后仍可播放

#### Scenario: 配音失败

- **WHEN** 配音渠道返回失败
- **THEN** 工具返回可读失败，该镜原声音引用不被清空
