# Spec Delta

## Purpose

让平台内置 Agent 工具的「声明」与「可用」始终一致：清单里有的名字运行时一定拿得到，读到的项目上下文足以支撑生成，破坏性写入缺确认时一律拒绝，长耗时生成不占用对话轮次。

## ADDED Requirements

### Requirement: 平台工具名清单与运行时注册一致

平台内置工具的名字清单 SHALL 是运行时实际注册工具集的子集，且两者 MUST 在工具集构造完成时校验。存在清单有、注册无的名字时，系统 MUST 以可读错误中止工具集构造，MUST NOT 静默跳过该名字。

默认专家平台工具白名单 MUST 是平台工具名清单的子集。白名单里出现未注册的名字时 MUST 同样在构造期失败。

场景专属工具集（3D 作业、创意会话产物）不参与该校验，其名字由各自场景绑定。

#### Scenario: 幽灵工具导致构造失败

- **WHEN** 某个名字出现在默认专家白名单里，但平台工具集没有注册它
- **THEN** 工具集构造失败并指出该名字，而不是给出一个少一个工具的工具集

#### Scenario: 新增工具未同步分组

- **WHEN** 新工具已注册进平台工具集，但未加入名字清单
- **THEN** 构造失败并指出缺少哪一个名字

### Requirement: 项目元信息对 Agent 可读

读取剧本与项目设定的只读工具 SHALL 返回当前项目的标题、梗概、画风与画幅，除原著正文外 MUST 一并给出这四项。工具描述 MUST 与实际返回字段一致。未选项目时 MUST 返回可读错误而不是空字符串集合。

#### Scenario: 生成提示词前读取项目设定

- **WHEN** agent 在已选项目的会话里读取项目设定
- **THEN** 响应包含项目标题、梗概、画风与画幅，且与项目文件中的当前值一致

#### Scenario: 画风为空

- **WHEN** 项目画风尚未填写
- **THEN** 响应把画风表示为空值，MUST NOT 用任何默认画风替代

### Requirement: 破坏性工具缺少确认时拒绝执行

创建项目、修改项目元信息、删除镜头这三类工具 SHALL 在执行前取得用户确认。运行环境未提供确认通道时，工具 MUST 返回可读失败，MUST NOT 直接落库。

确认结果 MUST 覆盖该次调用的全部破坏性动作；用户取消时工具 MUST NOT 落库，且 MUST 返回取消原因。

#### Scenario: 无确认通道

- **WHEN** 在没有确认通道的会话里调用删除镜头
- **THEN** 工具返回失败并说明需要确认，项目里的镜头保持不变

#### Scenario: 用户取消确认

- **WHEN** 用户在一次创建项目的确认卡上选择取消
- **THEN** 不创建项目，全局项目列表与当前选中的项目都不变

### Requirement: 技能声明的平台工具缺失在装载期可见

当技能清单声明了属于平台工具范围、但运行时未注册的工具名时，系统 SHALL 在装载阶段给出可读提示，并在检查器的工具列表里如实反映实际可用集合。MUST NOT 让被跳过的名字继续出现在「可用工具」展示中。

#### Scenario: 技能声明了未实现工具

- **WHEN** 某个技能清单声明了一个平台工具范围内但未注册的名字
- **THEN** 装载结果带有该名字的缺失提示，检查器不把它列为可用

#### Scenario: 全部声明都可用

- **WHEN** 技能声明的名字都在平台工具集里存在
- **THEN** 不产生缺失提示，绑定结果包含全部声明工具

### Requirement: 视频生成工具只提交任务不阻塞对话

面向分镜的视频生成工具 SHALL 在提交生成任务后立即返回任务标识，MUST NOT 在工具调用内等待成片完成，MUST NOT 在等待期间占用对话轮次的总时长预算。

工具 MUST 返回可读的回执，说明任务已提交、结果由任务中心接续落库。任务提交失败时 MUST 返回失败，MUST NOT 返回一个不存在的任务标识。

#### Scenario: 提交成功立即返回

- **WHEN** agent 对某镜提交视频生成
- **THEN** 工具在任务受理后即返回任务标识，该轮对话可以继续下一步

#### Scenario: 提交被渠道拒绝

- **WHEN** 视频渠道拒绝受理
- **THEN** 工具返回可读失败，镜头不写入任何成片引用
