# Spec Delta

## ADDED Requirements

### Requirement: 镜头写回覆盖业务字段并保护产线产物

Agent 写回已有镜头时 SHALL 能修改业务字段：选角、表演、台词表演、参考连线、参考补充、转场配置、工位类型、运动说明、视频提示词手改稿与模板渲染正文。这些字段 MUST 在命中已有镜头时真正写入，MUST NOT 被静默丢弃。

写回 MUST NOT 修改产线产物字段：首帧图、成片、配音引用、配音元数据、口型配置、视频元数据与生成态。这些字段只能由生成动作或画布单镜面写入。写回 MUST NOT 清空本次未提交的字段。

被标记为人改的字段 MUST 在写回后保持人改值。写回回执报告的更新镜数 MUST 与实际生效的镜头数一致。

#### Scenario: 写回选角与表演

- **WHEN** agent 对已有镜头提交新的选角、表演与参考连线
- **THEN** 该镜的对应字段被更新，画布重开后仍然存在

#### Scenario: 写回不含成片字段

- **WHEN** agent 提交的镜头载荷带有首帧路径或成片路径
- **THEN** 这些产线产物字段保持原值，不被覆盖也不被清空

#### Scenario: 手改字段受保护

- **WHEN** 某镜的时长已被用户标记为人改，agent 写回时提交了另一个时长
- **THEN** 该镜时长保持人改值，其余未被标记的字段照常更新

#### Scenario: 未提交字段不被清空

- **WHEN** agent 只提交镜头的视频提示词
- **THEN** 该镜的选角、表演与参考连线保持原值

### Requirement: 删除镜头经独立工具并强确认

系统 SHALL 提供独立的删除镜头工具，按当前集镜号删除。删除 MUST 在落库前取得用户确认，MUST NOT 与写回工具合并成一个动作。

删除 MUST 只影响本次列出的镜号；不存在的镜号 MUST 在回执中被指出，MUST NOT 让整次删除失败。删除回执 MUST 报告实际删除的镜数。

#### Scenario: 删除两镜

- **WHEN** agent 在确认后提交删除第 3 与第 4 镜
- **THEN** 这两镜从项目与画布中移除，其余镜头保持原样

#### Scenario: 混入不存在的镜号

- **WHEN** 提交的镜号里有一个在该集不存在
- **THEN** 存在的镜号被删除，回执列出不存在的那个镜号

#### Scenario: 未确认

- **WHEN** 没有取得用户确认
- **THEN** 工具返回失败，没有任何镜头被删除
