# Proposal

## Why

画布连线上原本叠了三样东西：线身、中点胶囊、胶囊里的接缝摘要（`叠化 0.5s` / `生成 1.2s`）。这条摘要既不是可点按的控件，也读不出稳定的语义——同一个位置显示的可能是关系名（硬切/闪回），也可能是效果摘要，字号比线条本身还抢眼，遮住了连线的走向。连线本该只是一条线。

触发方式也不顺手：右击是画布上唯一需要记的隐形约定，而画布其它地方都是单击出详情（点卡片开 Inspector、点参考线选中）。同一块画布两套手势，用户每次都要先判断「这条线该点还是该右击」。

本次把两件事一起收掉：**连线上不再有任何标签**，关系改由线条颜色与虚实表达；**单击连线弹出关系菜单**，与画布其它单击行为一致。

## What Changes

- **移除连线中点标签**（`edge-chip`）：不再渲染任何浮层文字、胶囊、状态点。关系由线条颜色与虚线样式表达，与改造前一致。
- 连线关系菜单改为**单击线身触发**，在鼠标落点弹出；菜单内容不变：`硬切 / 转场 / 闪回 / 分支` 单选（当前值打点）、「转场设置…」、「删除连线」。
- **BREAKING**：分镜连线不再响应右击（只抑制浏览器原生菜单，不弹自定义菜单）。单击只打开菜单，MUST NOT 选中连线、MUST NOT 直接改 `relation`、MUST NOT 打开转场面板。
- 分镜连线保持 `selectable: false`：「正在编辑的转场边」高亮仍由 `data.active` 派生，与单击无关。
- 原本挂在胶囊上的状态信息（未出片 / 需重生成 / 未参与成片）改由**线条自身**承担：未参与成片降低不透明度并保留关系虚线，需重生成改为警示色描边。文字说明只在菜单头部出现。
- 角色/素材参考连线（`ref-` 前缀）不受影响，仍以单击选中、不弹菜单。

明确不做：

- 不改 `relation` 四种标签的语义：闪回、分支仍只是叙事标注，不参与成片。
- 不改接缝的数据结构与持久化（仍是源镜的 `transition_out`）。
- 不给连线加悬停浮层或 tooltip 替代原胶囊；悬停只做线条提亮。
- 不为触屏单独设计手势。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `canvas-shots-workbench`：「接缝只在画布编辑」的入口从「选中连线」改为「单击连线的菜单」；新增连线关系单选菜单、菜单删除连线，以及「画布连线不显示接缝标签」的要求，并明确单击连线本身不改变任何数据。

## Impact

- 画布交互：`src/ShotEdge.tsx`（删除 `EdgeChip` / `EdgeLabelRenderer` / 缩放订阅，状态改为线条样式）、`src/App.tsx`（`onEdgeClick` 打开菜单、`onEdgeContextMenu` 只拦原生菜单、边加 `className` 供样式与回归脚本识别）、`src/ctx.ts`（`openEdgeMenu` 语义改为单击开菜单）。
- 样式：`src/theme.css` 删除 `.edge-chip*` 规则，补分镜边的 `cursor: pointer` 与悬停提亮、状态着色。
- 回归脚本：`verify-edge-menu.mjs` 改为单击路径并断言「画布上不存在 `.edge-chip`」；`verify-transitions-ui.mjs` 里读胶囊文本的断言改为读边的 `data-relation` / `data-state` 与菜单头部文案。
- 文档：`README.md`「分镜转场（接缝）」首段与操作路径。
- 无服务端、数据模型与依赖变更；不改成片合成。
