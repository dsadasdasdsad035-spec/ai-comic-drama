# Proposal

## Why

画布连线的交互挤在命中面积很小的边中点标签上：单击 chip 循环 `硬切 → 转场 → 闪回 → 分支`，落点不可预期，想直接改成「闪回」必须先绕两圈；转场详情还要再点一个几乎贴在一起的 `⋯` 小按钮。一次误点就会改掉连线关系，且没有任何回退提示。右键菜单能把「选什么关系」变成一次显式的单选，同时把转场设置与删除收进同一处，单击不再改动数据。

## What Changes

- 分镜连线改为**右击弹出菜单**（线身与中点标签都可触发），菜单内以单选列出 `硬切 / 转场 / 闪回 / 分支`，当前值高亮，点选即写入。
- 连线中点的 chip **退化为只读标签**：保留接缝摘要与状态点（pending / stale / inactive），移除单击循环与 `⋯` 按钮；`title` 提示「右击连线设置」。
- **BREAKING**：单击分镜连线不再选中、不再打开转场面板。转场面板改由菜单项「转场设置…」进入；首次进入时若关系不是转场，先落到默认转场（沿用现有「默认叠化 0.5 秒」）。
- 菜单内提供「删除连线」；删除已生成关键帧/视频的转场时沿用现有二次确认。
- 角色/素材参考连线（`ref-` 前缀）不受影响，仍以单击选中。

明确不做：

- 不改 `relation` 四种标签的语义：闪回、分支仍只是叙事标注，不参与成片。
- 不改接缝的数据结构与持久化（仍是源镜的 `transition_out`）。
- 不为触屏单独设计长按手势；本次只覆盖桌面右键。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `canvas-shots-workbench`: 「接缝只在画布编辑」的入口从「选中连线」改为「右击连线的菜单」；新增连线关系与删除连线的右键菜单交互要求，并明确单击连线不改变任何数据。

## Impact

- 画布交互：`src/ShotEdge.tsx`（chip 只读、标签也挂右键）、`src/App.tsx`（`onEdgeClick` 移除分镜边分支、新增边菜单状态与 `onEdgeContextMenu`、`edgesSelectable` 关闭）、`src/ctx.ts`（暴露打开边菜单）。
- 新组件：`src/EdgeContextMenu.tsx`，复用 `NodeContextMenu` 的 `.ctx-menu` 视觉与贴边翻面逻辑。
- 样式：`src/theme.css` 补无缩略图的单选行样式。
- 回归脚本：`verify-transitions-ui.mjs` 里「点 chip 循环」「点 `⋯` 开面板」的断言改为右键路径；`verify-ctxmenu.mjs` 增补边菜单用例。
- 无服务端、数据模型与依赖变更；不改成片合成。
