# Spec Delta

## MODIFIED Requirements

### Requirement: 接缝只在画布编辑

相邻镜之间的接缝 MUST 只通过画布连线的单击菜单与转场面板编辑，读写同一 `transition_out` 字段。系统 MUST NOT 提供表格式接缝行作为编辑入口。

#### Scenario: 通过连线改接缝

- **WHEN** 用户单击两镜之间的连线并选择「转场设置」后修改过渡效果
- **THEN** 画面按当前 `transition_out` 载入转场面板，改动即时写回同一字段，序列摘要与面板显示一致

#### Scenario: 非转场连线进入转场设置

- **WHEN** 用户单击一条硬切连线并选择「转场设置」
- **THEN** 关系先落到转场并写入默认叠化 0.5 秒，再打开转场面板

#### Scenario: 没有表格接缝行

- **WHEN** 用户寻找接缝列表
- **THEN** 系统不提供表格式接缝行，入口为画布连线与转场面板

## ADDED Requirements

### Requirement: 连线关系由单击菜单单选

分镜连线的 `relation`（硬切 / 转场 / 闪回 / 分支）MUST 只通过单击连线弹出的菜单修改。菜单 MUST 以单选形式列出四种关系并标记当前值，MUST 在鼠标落点弹出。单击连线 MUST NOT 选中连线、MUST NOT 直接改变 `relation`、MUST NOT 打开转场面板；改变关系 MUST 只来自菜单里的一次点选。

#### Scenario: 单击线身弹出菜单

- **WHEN** 用户单击一条硬切连线的线身
- **THEN** 在鼠标位置弹出关系菜单，当前值标记为硬切，连线关系与镜头数据均不变

#### Scenario: 菜单选择关系

- **WHEN** 用户在菜单里选择「闪回」
- **THEN** 该连线关系变为闪回，边样式按闪回绘制，两镜的镜头数据不因此改变，菜单保持打开

#### Scenario: 右击连线不弹菜单

- **WHEN** 用户右击一条分镜连线
- **THEN** 不弹出关系菜单，也不弹出浏览器原生右键菜单

#### Scenario: 改为硬切保留接缝配置

- **WHEN** 用户在菜单中把一条转场连线改为硬切
- **THEN** 连线关系立即变为硬切，源镜上已配置的 `transition_out` MUST NOT 被删除

#### Scenario: 参考连线不受影响

- **WHEN** 用户单击一条角色/素材参考连线
- **THEN** 该参考连线按原有方式选中，MUST NOT 弹出连线菜单

### Requirement: 画布连线不显示接缝标签

画布上的分镜连线 MUST 只以线条呈现：MUST NOT 在中点渲染胶囊、关系名、接缝摘要或状态文字。关系 MUST 由线条颜色与虚实表达。

#### Scenario: 连线中点无浮层

- **WHEN** 用户查看画布上任一条分镜连线
- **THEN** 中点没有任何标签或胶囊元素，画面上不存在 `.edge-chip`

#### Scenario: 状态不占用文字

- **WHEN** 一条转场连线未参与成片，或边界变化后需要重生成
- **THEN** 连线用线条样式（低不透明度 / 警示色）表达该状态，MUST NOT 在连线上添加文字，状态文字只在单击菜单的头部出现

### Requirement: 连线可通过单击菜单删除

单击分镜连线的菜单 MUST 提供删除连线。删除已生成关键帧或视频的转场连线前 MUST 二次确认，并说明会清除已生成配置。

#### Scenario: 删除硬切连线

- **WHEN** 用户单击一条硬切连线并在菜单选择「删除连线」
- **THEN** 该连线从画布移除，两镜的镜头数据不变

#### Scenario: 删除已生成的转场连线

- **WHEN** 用户单击一条已生成视频的转场连线并在菜单选择「删除连线」
- **THEN** 系统先二次确认，确认后才移除连线并清除源镜的 `transition_out`
