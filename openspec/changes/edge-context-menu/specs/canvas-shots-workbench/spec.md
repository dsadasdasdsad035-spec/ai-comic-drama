# Spec Delta

## MODIFIED Requirements

### Requirement: 接缝只在画布编辑

相邻镜之间的接缝 MUST 只通过画布连线的右键菜单与转场面板编辑，读写同一 `transition_out` 字段。系统 MUST NOT 提供表格式接缝行作为编辑入口。

#### Scenario: 通过连线改接缝

- **WHEN** 用户右击两镜之间的连线并选择「转场设置」后修改过渡效果
- **THEN** 画面按当前 `transition_out` 载入转场面板，改动即时写回同一字段，序列摘要与面板显示一致

#### Scenario: 非转场连线进入转场设置

- **WHEN** 用户右击一条硬切连线并选择「转场设置」
- **THEN** 关系先落到转场并写入默认叠化 0.5 秒，再打开转场面板

#### Scenario: 没有表格接缝行

- **WHEN** 用户寻找接缝列表
- **THEN** 系统不提供表格式接缝行，入口为画布连线与转场面板

## ADDED Requirements

### Requirement: 连线关系由右键菜单单选

分镜连线的 `relation`（硬切 / 转场 / 闪回 / 分支）MUST 只通过右击连线的菜单修改。菜单 MUST 以单选形式列出四种关系并标记当前值，MUST 对线身与中点标签都可触发。单击连线 MUST NOT 选中连线、MUST NOT 改变 `relation`、MUST NOT 打开转场面板。中点标签 MUST 为只读展示，保留接缝摘要与状态标记。

#### Scenario: 右击线身改关系

- **WHEN** 用户右击一条硬切连线的线身并在菜单选择「闪回」
- **THEN** 该连线关系变为闪回，边样式按闪回绘制，两镜的镜头数据不因此改变

#### Scenario: 右击中点标签同样开菜单

- **WHEN** 用户右击连线中点的关系标签
- **THEN** 弹出与右击线身相同的菜单

#### Scenario: 单击连线不改变任何数据

- **WHEN** 用户单击一条分镜连线的线身或中点标签
- **THEN** 关系不变、转场面板不打开，该连线保持只读展示

#### Scenario: 改为硬切保留接缝配置

- **WHEN** 用户在菜单中把一条转场连线改为硬切
- **THEN** 连线关系立即变为硬切，源镜上已配置的 `transition_out` MUST NOT 被删除

#### Scenario: 参考连线不受影响

- **WHEN** 用户单击一条角色/素材参考连线
- **THEN** 该参考连线按原有方式选中，MUST NOT 弹出连线菜单

### Requirement: 连线可通过右键菜单删除

右击分镜连线的菜单 MUST 提供删除连线。删除已生成关键帧或视频的转场连线前 MUST 二次确认，并说明会清除已生成配置。

#### Scenario: 删除硬切连线

- **WHEN** 用户右击一条硬切连线并选择「删除连线」
- **THEN** 该连线从画布移除，两镜的镜头数据不变

#### Scenario: 删除已生成的转场连线

- **WHEN** 用户右击一条已生成视频的转场连线并选择「删除连线」
- **THEN** 系统先二次确认，确认后才移除连线并清除源镜的 `transition_out`
