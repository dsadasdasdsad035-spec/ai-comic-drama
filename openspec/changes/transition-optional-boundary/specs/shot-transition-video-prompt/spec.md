# Spec Delta

## MODIFIED Requirements

### Requirement: 结构锚点可见且可校正

系统 SHALL 在生成转场模式下展示首帧与尾帧两个槽位，两者均为**可选**，MUST NOT 作为生成的前置条件。首帧 MUST 来自上一镜成片的最后一帧，尾帧 MUST 来自下一镜成片的第一帧；用户 MUST 能通过「抽取两镜成片帧」一次填好两帧，也能单独清除某一侧。生成时系统 MUST 按实际可用输入选择提交模式，MUST NOT 因缺任一侧就阻止生成。

#### Scenario: 首次打开两槽为空

- **WHEN** 用户首次打开一条生成转场的「选择出片参考 → 首尾帧」，且此前未抽取过边界
- **THEN** 首帧与尾帧两个槽位均显示未选择，面板只提供「抽取两镜成片帧」与打开上/下镜入口

#### Scenario: 抽取一次即填好两帧

- **WHEN** 上镜与下镜都有成片，用户点「抽取两镜成片帧」
- **THEN** 首帧填为上镜成片尾帧、尾帧填为下镜成片首帧，两槽同时可预览

#### Scenario: 边界齐全可生成

- **WHEN** 首帧与尾帧均已就绪，且当前模型支持尾帧
- **THEN** 提交首尾帧，生成按钮可用

#### Scenario: 缺尾帧阻止

- **WHEN** 首帧或尾帧未抽取，且没有任何其他可用输入、模型也不支持文生视频
- **THEN** 面板显示 blocking，文案要求补参考或换支持文生视频的模型

#### Scenario: 旧项目保留已选

- **WHEN** 打开一个已保存过 `generated.boundary` 的旧项目转场
- **THEN** 两槽显示已保存的选择，用户可清除或重新抽取

## ADDED Requirements

### Requirement: 输入模式降级链

转场生成 MUST 按以下优先级选择提交模式，命中即停：首尾帧齐全 → 首尾直变；仅首帧 → 单首帧出片；无帧但有参考图 → reference_image；无帧但有参考视频 → reference_video；以上皆无且模型支持文生视频 → 纯文本。模式 MUST 在出片提示词面板的摘要中可见。

#### Scenario: 两帧齐全

- **WHEN** 首帧与尾帧都已选且模型支持尾帧
- **THEN** 模式为首尾直变，提交首帧与尾帧

#### Scenario: 缺帧也允许生成

- **WHEN** 首帧或尾帧未抽取，但存在可用输入（单侧帧、连线参考图/参考视频，或模型支持纯文本）
- **THEN** 生成按钮可用，系统按降级链选择提交模式

#### Scenario: 只有首帧

- **WHEN** 只选了首帧
- **THEN** 模式为单首帧，生成后裁到目标时长，不提交尾帧

#### Scenario: 无帧有参考图

- **WHEN** 两槽都为空，且两镜连线解析出参考图
- **THEN** 模式为参考图，提交 reference_image 列表

#### Scenario: 纯文本

- **WHEN** 两槽为空、没有参考图/视频，且当前模型声明支持文生视频
- **THEN** 模式为纯文本，请求只带提示词

### Requirement: 纯文本模式的能力门禁

系统 MUST 只在模型声明 `textToVideo` 能力时允许纯文本转场生成。模型未声明该能力且没有其他可用输入时 MUST blocking，文案 MUST 说明可以补参考或换支持文生视频的模型，MUST NOT 静默失败。

#### Scenario: 支持文生视频

- **WHEN** 无帧无参考且模型声明了 `textToVideo`
- **THEN** 不出现 blocking，可以生成

#### Scenario: 不支持文生视频

- **WHEN** 无帧无参考且模型未声明 `textToVideo`
- **THEN** 出现 blocking，提示补参考或换模型

### Requirement: 请求时长按实际提交的帧决定

生成请求时长 MUST 依据实际提交的锚点计算：提交尾帧时保留整段不裁剪；只提交首帧或纯文本时按目标时长加余量生成并裁到目标时长。MUST NOT 仅依据模型是否支持尾帧决定裁剪。

#### Scenario: 只有首帧时裁剪

- **WHEN** 只提交首帧或纯文本
- **THEN** 返回 `trimTo` 等于目标时长，成片按该值裁剪

#### Scenario: 首尾帧齐全不裁剪

- **WHEN** 同时提交首帧与尾帧
- **THEN** 不返回 `trimTo`，保留模型生成的完整时长

### Requirement: 参考图与尾帧的互斥按实际提交判断

尾帧与 reference_image 的互斥 MUST 依据本次是否真的提交了尾帧判断，而不是依据模型能力或锚点策略。未提交尾帧时参考图 MUST 正常提交。

#### Scenario: 未提交尾帧时参考图可用

- **WHEN** 只选了首帧或没有帧，且存在参考图
- **THEN** 参考图进入本次请求，不被标记为省略

#### Scenario: 提交尾帧时参考图省略

- **WHEN** 首尾帧同时提交且模型禁止尾帧与参考图混用
- **THEN** 参考图列在清单中但标注本次未提交及原因
