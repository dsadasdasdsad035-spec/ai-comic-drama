# Proposal

## Why

现在拆镜和提示词链路只把“长相、动作姿态、运镜”写进提示词，表演没有结构化数据：情绪只存在于剧本场次的自由文本里，逐角色动作只有一段 `desc`，台词只有 `speaker/text`，TTS 只有音色和语速，视频请求不带台词音频，也没有口型验收。结果是角色长相能保持一致，但“这场戏怎么演”无法稳定传递，口型和配音情绪对不上，角色表情还被 `lookEn` 里的固定表情锁死。

外部已有 MIT 许可的短剧/媒体技能验证了可复用的做法：身份与表演分离、逐角色表演弧、对白与口型预算、口型 QA。这个变更把这些做法落成本项目的结构化数据和工作台能力，而不是把外部技能当运行时依赖。

## What Changes

- 新增镜头表演数据：每个镜头按角色记录情绪、强度、可见动作、视线和说话状态；台词行可携带情绪、语速、音量与重音等表演参数；镜头记录口型模式。
- 拆镜技能输出表演信息：除 `cast` 外，为每个真正承担画面变化的角色给出可见表演，不再用一段整体 `desc` 代替多人动作；台词保留说话人与逐句表演。
- 提示词技能消费表演数据：首帧提示词写表情、姿态和说话状态；视频提示词写说话中的面部/嘴部动作，并在对话镜头优先保证嘴部可见；提示词阶段显式接收 `cast`，不再只靠描述猜谁在画面里。
- 工作台可查看和编辑表演：镜头表、Inspector 和聊天草稿共用同一份表演数据；手工修改的表演字段在重新拆镜/重新生成提示词时保留，不被静默覆盖。
- 新增可选的角色表情参考：在身份锚点之外，为角色生成/上传中性、喜、怒、哀、惧、惊等表情参考图；表情只改变表情，不改变身份锚点。每个镜头可以选择一张表情参考，首帧生成时作为参考；没有表情图时退回文字表演。
- 新增台词表演与 TTS 情绪：逐句/逐角色记录情绪和表演要求，按当前 TTS 引擎映射到原生参数；音色身份保持不变，情绪不写入角色身份。引擎不支持情绪参数时显式降级，不把情绪标签读进台词。
- 新增口型模式与验收：`off` / `prompt` / `provider` 三档；`prompt` 只写嘴部与说话约束，`provider` 在用户手动确认后把已接受视频和台词音频交给可配置的外部口型服务；生成后用静音段/发声段抽帧检查“静音闭嘴、说话嘴动”，失败只标记待修，不覆盖已接受视频。
- 参考外部 MIT 技能（drama-skills、generative-media-skills、cartoon-studio 的口型 QA）作为规则来源；不复制其运行时、不自动安装、不把它们变成项目依赖。
- 更新文档、验收脚本和证据；真实 Seedance 2.0+ 或外部口型调用仍按人工确认规则执行。

明确不做：

- 不自动批量调用外部口型服务，不自动提交真实 Seedance 2.0+ 任务。
- 不把表情图做成新的角色身份，也不要求固定六格/九格表情表；没有表情图时文字表演仍然可用。
- 不改变现有 `voice-synthesis` 的渠道协议和默认模型；只增加可选的表演参数。
- 不引入新的默认图像/视频渠道，也不改变现有项目的保存语义。
- 不把外部技能正文整段复制进项目；只吸收规则并注明来源。

## Capabilities

### New Capabilities

- `shot-performance`: 镜头级表演数据、拆镜/提示词技能契约、工作台编辑与保存语义、首帧/视频提示词中的表情与说话状态。
- `voice-performance`: 台词表演参数、音色身份与表演分离、各 TTS 引擎的情绪/语速/音量映射与不支持时的降级。
- `character-expression`: 角色表情参考图的数据、生成/选择、身份与表情分离、按镜头作为首帧参考。
- `video-lip-sync`: 口型模式、外部口型服务边界、手动确认与成本、静音/发声抽帧验收、失败标记与不覆盖已接受视频。

### Modified Capabilities

无。现有 `voice-synthesis` 的渠道协议与默认路由保持不变；新增的表演参数由 `voice-performance` 拥有。现有 `character-extraction` 的外观锚点与合并规则保持不变；表情参考是新增的可选资产，不改身份。

## Impact

- 数据：`ShotData` / `ProjectShot` 新增表演与口型字段；`CharacterSheet` / `ProjectChar` 新增可选表情参考；`src/shotSync.ts` 的签名、回写与读取要覆盖新字段；旧项目按空表演读取，不做批量迁移。
- 技能与契约：`skills/shotlist`、`skills/prompt`、`skills/character` 的正文与输入；`shots-v1`、`prompts-v1`、`characters-v1` 的输出契约增加可选表演字段，保持旧输出兼容。
- 工作台：`src/ShotTable.tsx`、`src/Inspector.tsx`、`src/PromptTable.tsx`、`src/CharacterBoard.tsx` 增加查看/编辑与参考选择；聊天草稿与一次性生成共用同一套合并规则。
- 配音：`src/App.tsx` 的 `generateVoiceOne`、`src/api.ts` 的 `VoiceLine`、`vite.config.ts` 的 TTS 分发、`server/volc-tts.mjs` 与 `server/apimart.mjs` 增加可选表演参数；MiniMax/ ElevenLabs 等按能力映射。
- 口型：`src/api.ts` 的视频选项、视频路由、可配置的外部口型适配器与验收脚本；默认关闭，真实调用需要手动确认和成本预览。
- 测试与文档：新增表演、配音情绪、表情参考、口型验收的纯函数/UI/导出测试；`README.md`、`DEPLOY-CHECKLIST.md` 和 `openspec/changes/shot-performance-direction/evidence/` 记录操作与真实产物。
- 成本与兼容：旧项目、旧技能输出、无表演参数的任务保持原行为；表情图按图像生成计费；外部口型按次计费且默认不自动执行。
