# Proposal

## Why

创意视图由 dsh 宿主前端提供，宿主会把 DeepSeek Harness 的品牌图形（侧栏鲸鱼标记、折叠轨道的鲸鱼、空白首页的像素鲸水印）当作产品身份呈现出来。操作员看到的是「另一个软件」而不是分镜画布，与既有「宿主品牌不出现在外壳上」的定位不符。现有注入样式只盖住了版本徽标、产品名与首页行内鲸鱼，侧栏与空白首页仍有三处可见。

## What Changes

- 创意视图注入样式追加三类隐藏规则：侧栏展开态的鲸鱼标记、侧栏折叠轨道的鲸鱼、空白首页的像素鲸画布水印。
- 侧栏展开态品牌按钮失去图形后不再保留不可见的点击区：该按钮原本是「新会话」的快捷入口，隐藏后只留 `pointer-events: none`，功能由下方独立的「新会话」按钮承担。
- 折叠轨道失去静止鲸鱼后，展开按钮的面板图标改为常驻，避免触屏端出现一个无图形的按钮。
- 侧栏品牌行的行高、右侧折叠按钮与整体版式保持不变。
- 不修改 dsh 子模块源码：仍以注入样式处理，宿主升级后语义类名漂移时静默退化。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `creative-layout`: 新增「创意视图不呈现宿主品牌图形」的要求，覆盖展开侧栏、折叠侧栏与空白首页三个场景；现有「只呈现宿主对话外壳」的要求扩展到品牌图层。

## Impact

- `src/creative/StudioFrame.tsx`：`studioStyleText()` 的品牌降噪规则。
- `tests/studio-shell.mjs`：降噪样式的选择器断言。
- `openspec/specs/creative-layout/spec.md`：需求条目。
- 不涉及服务端、工具桥、主题 token 或 dsh 子模块代码。
