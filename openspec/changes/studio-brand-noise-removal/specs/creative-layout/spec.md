# Spec Delta

## ADDED Requirements

### Requirement: 创意视图不显示宿主品牌图形

创意视图 MUST NOT 显示宿主的产品品牌图形，包括侧栏展开态的品牌标记、侧栏折叠轨道的品牌图标、空白会话首页的品牌水印、行内图形与标题旁的「预览版」标签。隐藏 MUST 只做减法：MUST NOT 引入应用自己的图形或文案替代，MUST NOT 改变侧栏行高、折叠按钮位置与消息区版式。宿主类名漂移导致隐藏失效时 MUST 静默退化，MUST NOT 阻断加载或报错。

#### Scenario: 展开侧栏

- **WHEN** 操作员展开宿主侧栏并查看顶部
- **THEN** 顶部不出现宿主品牌标记，该位置也不再回应用户点击（不保留不可见的新会话点击区），行高与右侧折叠按钮位置与改动前一致

#### Scenario: 折叠侧栏

- **WHEN** 侧栏处于折叠态
- **THEN** 顶部只显示展开按钮的面板图标，标记可见可点，不出现宿主品牌图标；悬停不再把静止品牌图换成面板图标

#### Scenario: 空白会话首页

- **WHEN** 操作员打开尚无消息的创意会话
- **THEN** 首页不出现品牌水印与行内品牌图形，标题、说明与输入区的位置不因此偏移；标题旁不出现「预览版」标签

#### Scenario: 降噪不伪造品牌

- **WHEN** 检查创意视图注入的降噪样式
- **THEN** 样式只包含隐藏规则，不含背景图、外部图片引用或替代文本

### Requirement: 创意视图不显示宿主的预览版说明

创意视图 MUST NOT 呈现宿主自己的「预览版说明」首次运行公告。实现 MUST 在宿主 profile 里把该公告预置为已确认（`ui-settings-general.welcomeNoticeVersion`），让公告不渲染；MUST NOT 通过隐藏 DOM 或模拟点击绕过——公告挂载时会把 `#root` 置为 inert，只藏不关会让会话区继续不可交互。宿主提升公告版本时必须同步确认值，不让公告静默重现。

#### Scenario: 首次进入创意会话

- **WHEN** 操作员首次打开创意会话（宿主 profile 里没有确认记录）
- **THEN** 不出现遮罩弹窗，侧栏、消息区与输入框立即可交互，页面文本里没有「预览版说明」

#### Scenario: 宿主升版公告

- **WHEN** 宿主把公告版本 bump 成新值
- **THEN** 用例失败并指出要同步 `server/studio-profile.mjs` 的确认值，而不是让公告在用户侧重新出现
