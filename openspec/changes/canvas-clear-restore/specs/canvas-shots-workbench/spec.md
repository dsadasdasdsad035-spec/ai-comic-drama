# Spec Delta

## MODIFIED Requirements

### Requirement: 画布增删插为正式镜头

画布 SHALL 提供新增镜头、在某镜之后插入与删除镜头。新增与插入 MUST 生成带集内唯一镜号的正式镜头并写入项目，MUST NOT 只建无业务 ID 的临时卡。新增与插入 MUST 在创建时让用户选定镜头的 `prodKind`（生图或出片），并把选定值写入该镜头。删除 MUST 先确认，确认后移除该项目镜头、画布节点与其连线，并清除指向它的 `transition_out`。画布上有两类删除动作：「删除选中」移除所选卡片（可能含素材卡），「清空本集」移除当前集全部镜头；两者 MUST 在确认文案里写明各自的镜数与集号，MUST NOT 用同一句话描述。

#### Scenario: 新增镜头

- **WHEN** 用户在画布新增镜头并选择生产类型
- **THEN** 项目出现新镜头且含对应 `prodKind`，画布出现对应卡片并接在序列中

#### Scenario: 在中间插入

- **WHEN** 用户从某一镜插入新镜并选择生产类型
- **THEN** 新镜紧跟在所选镜之后，镜号在集内唯一，且 `prodKind` 与选择一致

#### Scenario: 删除带转场的镜头

- **WHEN** 用户删除一镜且上一镜配置了指向它的转场
- **THEN** 该镜从项目与画布移除，上一镜的 `transition_out` 被清除

#### Scenario: 镜号冲突

- **WHEN** 新增或改动的镜号与集内已有镜号重复
- **THEN** 写入被阻止并指出冲突的镜号

#### Scenario: 两个删除动作的措辞按范围区分

- **WHEN** 用户分别触发「删除选中」与「清空本集」
- **THEN** 删除选中的确认写所选卡片数与其中镜头数，清空本集的确认写当前集号与全镜数，两者措辞不混用

## ADDED Requirements

### Requirement: 清空画布删除本集镜头

「清空画布」MUST 删除当前集全部镜头，MUST 通过显式的镜头删除通道（按镜头 id 点名删除）写入项目，MUST NOT 用整表替换的方式删数据。删除范围 MUST 限定当前集：其他集的镜头、角色卡、素材、设定卡 MUST 保持不变，画布上的素材卡 MUST 保留。删除后 MUST 清除所有指向被删镜头的 `transition_out`，包括其他集里指向本集的边界转场。

删除完成后，画布 MUST 为空且只保留素材卡；`read_shots` 与 Markdown 导出 MUST NOT 再返回该集镜头；集目录里该集的镜数 MUST 为 0。该结果 MUST 只依赖项目数据：刷新页面、重启服务、换浏览器或换设备后，该集仍 MUST 为空。

#### Scenario: 清空删除本集镜头

- **WHEN** 用户确认清空当前集
- **THEN** 该集镜头从项目与画布移除，素材卡保留

#### Scenario: 其他集与关联数据不变

- **WHEN** 用户清空某一集，而项目里还有其他集、角色卡与设定卡
- **THEN** 其他集的镜头数量与内容、角色卡、素材、设定卡均保持不变

#### Scenario: 读工具与导出一致

- **WHEN** 清空后调用 `read_shots` 或导出该集 Markdown
- **THEN** 该集不再返回任何镜头，导出内容里不含该集镜头

#### Scenario: 结果不依赖浏览器

- **WHEN** 清空后刷新页面、重启服务或更换浏览器
- **THEN** 该集仍为空，卡片 MUST NOT 自动恢复

#### Scenario: 边界转场被清理

- **WHEN** 用户清空一集，而其他集有镜头配置了指向本集镜头的转场
- **THEN** 那些 `transition_out` 被清除，不留指向已删镜头的悬空转场

### Requirement: 清空画布需二次确认与服务端快照

清空画布 MUST 使用需要用户手打当前集号（例如 `E01`）的确认交互，输入不匹配时确认动作 MUST 不可用。确认内容 MUST 写明：将被删除的镜数、素材卡会保留、其他集不受影响、该动作不可撤销。

服务端在执行删除前 MUST 先把将被删除的镜头写入快照；快照写入失败时 MUST 拒绝删除并且不修改任何镜头。快照 MUST 落在不随项目删除而清理的位置，并 MUST 能从文件名区分这是镜头级快照。

#### Scenario: 输入不匹配不删除

- **WHEN** 用户在确认框里输入与当前集号不符的文本
- **THEN** 确认动作不可用，镜头不被删除

#### Scenario: 确认后落快照再删除

- **WHEN** 用户输入正确集号并确认
- **THEN** 服务端先写入镜头快照，成功后才删除，响应返回删除后的镜头列表

#### Scenario: 快照失败则拒绝删除

- **WHEN** 快照写入失败
- **THEN** 删除被拒绝，项目镜头保持原样，并返回可读的错误

### Requirement: 清空后的空状态

当前集在项目里没有镜头时，画布 MUST 显示空状态说明该集还没有镜头，并 MUST 提供导入分镜表与新建镜头两个入口。其他集的可用镜头计数 MUST 取自项目镜头，MUST NOT 依赖画布上现存的节点。

空状态 MUST NOT 提供重建或恢复已删镜头的入口；不得以「项目里还有 N 镜可重建」这类在真删语义下不成立的说明描述当前集。

#### Scenario: 清空后显示本集无镜头

- **WHEN** 用户清空当前集
- **THEN** 画布显示该集还没有镜头的说明，并给出导入分镜表与新建镜头入口

#### Scenario: 其他集计数仍可见

- **WHEN** 当前集没有镜头，而其他集在项目里有镜头
- **THEN** 空状态仍列出其他集的集号与镜数，可据此切集

#### Scenario: 切到他集能看到该集镜头

- **WHEN** 用户从空状态切到项目里有镜头的其他集
- **THEN** 该集镜头按项目数据水合到画布

#### Scenario: 不出现重建入口

- **WHEN** 用户查看空状态或画布操作菜单
- **THEN** 不存在任何以恢复已删镜头为目标的按钮或菜单项
