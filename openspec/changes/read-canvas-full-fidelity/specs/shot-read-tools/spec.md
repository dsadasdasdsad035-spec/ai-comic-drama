# Spec Delta

## Purpose

让内置 Pi agent 能无损读取画布上的分镜与其关联关系：截断按整条记录进行、可续读至全量、可单镜钻取，并能拿到与出片预览逐字一致的最终正文。

## ADDED Requirements

### Requirement: 读工具截断以整条记录为单位

读工具在响应超出长度预算时 SHALL 以整条记录为单位装填，MUST NOT 返回被切断的 JSON 文本，MUST NOT 返回缺字段的记录。超限响应 MUST 仍是合法 JSON，并 MUST 报告总数与本次实际返回的条数。

#### Scenario: 一集镜头超出预算

- **WHEN** agent 读取一集镜头，且该集全部镜头序列化后超过读取预算
- **THEN** 响应仍是合法 JSON，按整条返回前若干镜，并给出该集总数与本次返回条数

#### Scenario: 单镜字段不被省略

- **WHEN** agent 读取到某一镜
- **THEN** 该镜记录带有首帧提示词、视频提示词各形态、转场配置与参考连线字段（有值时出现），不因位置靠后而被丢弃

### Requirement: 分镜列表可续读至全量

`read_shots` SHALL 提供续读游标，使调用方能在多次调用中读完该集全部镜头。游标 MUST 由上一次响应给出，调用方 MUST NOT 需要自行推算偏移量。

#### Scenario: 连续续读覆盖全集

- **WHEN** agent 用上一次响应给出的游标连续调用
- **THEN** 最终覆盖该集全部镜头，且不重复、不遗漏

#### Scenario: 续读结束有明确信号

- **WHEN** 最后一次续读已到达该集末尾
- **THEN** 响应明确表示没有更多镜头，不再给出游标

### Requirement: 指定镜号时不受列表预算限制

`read_shots` 收到 `shotIds` 时 SHALL 返回这些镜头的完整记录，MUST NOT 因列表长度预算丢弃其中任一镜。条数上限仍 MUST 生效，超出时 MUST 明确报告未被返回的 id。

#### Scenario: 按 id 精确取多条

- **WHEN** agent 传入 20 个属于该集的 `shotId`
- **THEN** 这 20 条记录全部返回，且每条都含完整字段

#### Scenario: 超出条数上限

- **WHEN** agent 传入的 id 数量超过单次条数上限
- **THEN** 响应只返回上限内的记录，并列出未返回的 id 与总数

### Requirement: 单镜完整记录可钻取

系统 SHALL 提供只读工具，按镜号或 `shotId` 返回单镜完整记录。返回 MUST 包含该镜全部已存字段，MUST NOT 受列表预算影响。镜号在该集不存在时 MUST 返回可读错误并说明可用范围。

#### Scenario: 钻取到视频提示词各形态

- **WHEN** agent 读取某镜完整记录，且该镜有手改快照与模板渲染正文
- **THEN** 响应同时包含手改正文、模板渲染正文与渲染元数据，以及当前语义层运动提示词

#### Scenario: 镜号不存在

- **WHEN** agent 传入该集不存在的镜号
- **THEN** 返回失败状态并说明该集可用镜号范围

### Requirement: 出片正文读取与拼装一致

系统 SHALL 提供只读工具读取某镜最终会提交给视频模型的正文，并给出来源标记。手改快照、语义层运动提示词或首帧正文存在时，返回 MUST 与画布出片前预览逐字一致。正文只能由画布脚本拼装产生且画布上下文不可用时，MUST 报告无法给出正文及原因，MUST NOT 返回近似拼接结果。

#### Scenario: 手改版本优先

- **WHEN** 某镜保存了手改出片提示词
- **THEN** 读工具返回的正文与出片预览正文完全相同，来源标记为手改快照

#### Scenario: 自动正文标明来源

- **WHEN** 某镜没有手改，但有语义层运动提示词或首帧正文
- **THEN** 返回正文并标明实际来源，不使用未标记的拼接结果

#### Scenario: 缺少画布上下文时如实报告

- **WHEN** 某镜既无手改、也无模板渲染正文与语义层运动提示词，正文需由画布脚本拼装
- **THEN** 响应表示无法给出最终正文并说明需要画布上下文，不返回猜测的正文

### Requirement: 其余读工具同受无损约束

`read_episodes`、`read_episode`、`read_characters`、`read_designs`、`read_transition_recipes` SHALL 遵循同一套整条装填与截断标记规则：MUST NOT 返回半截 JSON，超限时 MUST 标明被截断并给出总数。

#### Scenario: 角色表超出预算

- **WHEN** 角色记录合计超过读取预算
- **THEN** 响应为合法 JSON，按整条返回前若干角色，并标记截断与角色总数

#### Scenario: 单集摘要超出预算

- **WHEN** `read_episode` 的一集镜头摘要超过读取预算
- **THEN** 响应为合法 JSON 并标明截断与总计，不返回残缺的镜头条目

### Requirement: 新增读工具纳入平台工具清单

系统 SHALL 把新增读工具列入平台内置工具名清单与默认专家工具白名单，专家设置页的「读项目」分组 MUST 能列出它们。

#### Scenario: 专家设置可见

- **WHEN** 用户在专家设置页查看「读项目」分组
- **THEN** 分组中出现新增的单镜钻取与出片正文读工具

#### Scenario: 内置专家包含

- **WHEN** 加载内置全能专家
- **THEN** 其工具白名单包含新增读工具
