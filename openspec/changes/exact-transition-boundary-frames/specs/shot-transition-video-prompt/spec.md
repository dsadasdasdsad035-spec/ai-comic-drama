# Spec Delta

## MODIFIED Requirements

### Requirement: 结构锚点可见且可校正

系统 SHALL 在生成转场模式下展示首帧与尾帧两个槽位，两者均为**可选**，MUST NOT 作为生成的前置条件。首帧 MUST 来自上一镜成片的**解码输出最后一帧**，尾帧 MUST 来自下一镜成片的**解码输出第 0 帧**（首帧）；两者 MUST NOT 是接近片尾或接近片头的任意一帧。用户 MUST 能通过「抽取两镜成片帧」一次填好两帧，也能单独清除某一侧。生成时系统 MUST 按实际可用输入选择提交模式，MUST NOT 因缺任一侧就阻止生成。

#### Scenario: 首次打开两槽为空

- **WHEN** 用户首次打开一条生成转场的「选择出片参考 → 首尾帧」，且此前未抽取过边界
- **THEN** 首帧与尾帧两个槽位均显示未选择，面板只提供「抽取两镜成片帧」与打开上/下镜入口

#### Scenario: 抽取一次即填好两帧

- **WHEN** 上镜与下镜都有成片，用户点「抽取两镜成片帧」
- **THEN** 首帧填为上镜成片尾帧、尾帧填为下镜成片首帧，两槽同时可预览

#### Scenario: 边界齐全可生成

- **WHEN** 首帧与尾帧均已就绪，且当前模型支持尾帧
- **THEN** 提交首尾帧，生成按钮可用

#### Scenario: 缺尾帧阻止

- **WHEN** 首帧或尾帧未抽取，且没有任何其他可用输入、模型也不支持文生视频
- **THEN** 面板显示 blocking，文案要求补参考或换支持文生视频的模型

#### Scenario: 旧项目保留已选

- **WHEN** 打开一个已保存过 `generated.boundary` 的旧项目转场
- **THEN** 两槽显示已保存的选择，用户可清除或重新抽取

### Requirement: 抽取两镜成片帧

系统 SHALL 提供单一「抽取两镜成片帧」动作：上镜成片抽尾帧写入首帧槽，下镜成片抽首帧写入尾帧槽。写入的首帧 MUST 是上镜成片解码输出的最后一帧，MUST NOT 是接近片尾的任意一帧；写入的尾帧 MUST 是下镜成片解码输出的第 0 帧。抽取 MUST 在用户触发时执行，MUST NOT 在生成前隐式执行。某一侧抽取失败时 MUST 提示原因并保留该侧原值，MUST NOT 用静帧或当前画面替代。任一侧没有成片时 MUST 明确提示先为该镜出片，且提示文案 MUST 指明缺失的是尾帧还是首帧。

#### Scenario: 抽取即写入

- **WHEN** 用户点击「抽取两镜成片帧」且两镜都有成片
- **THEN** `generated.boundary.out` 与 `in` 同时被写入，来源分别为上镜成片尾帧与下镜成片首帧

#### Scenario: 单侧失败不覆盖

- **WHEN** 上镜抽帧失败而下镜成功
- **THEN** 面板提示失败原因，首帧槽保持抽取前的值，尾帧槽更新为下镜首帧

#### Scenario: 没有成片不回退静帧

- **WHEN** 上镜只有静帧没有成片
- **THEN** 首帧不会被静帧填充，提示先为上镜出成片

#### Scenario: 尾帧是解码输出现存的最后一帧

- **WHEN** 对一段 N 帧的成片执行「抽取两镜成片帧」
- **THEN** 首帧取自第 N-1 帧（末帧），MUST NOT 取到第 N-2 或更早的帧；尾帧取自第 0 帧

#### Scenario: 抽帧结果不随帧率与关键帧间隔漂移

- **WHEN** 上镜成片分别为 24fps 与 30fps，或关键帧间隔长达全片只有一个关键帧
- **THEN** 抽出的首帧都是该片各自的末帧，不会因为帧率不同落到倒数第 2、第 3 帧

#### Scenario: 时长极短的成片也能抽到尾帧

- **WHEN** 上镜成片总时长不足一秒（如 0.6 秒）
- **THEN** 首帧槽仍写入该片末帧，不因片长不足而抽取失败或落空

## ADDED Requirements

### Requirement: 边界帧近黑提示

系统 SHALL 在「抽取两镜成片帧」后检测两个已写入边界帧的亮度，并在任一侧接近全黑时以**非阻断**方式提示该侧可能是黑场、连续性参考价值有限。近黑判定 MUST 基于抽到的帧本身，MUST NOT 基于源视频的时长或元数据。提示 MUST NOT 阻止生成，MUST NOT 清除或替换已写入的帧，也 MUST NOT 因近黑而回退静帧或改抽其他帧。

#### Scenario: 尾帧近黑提示

- **WHEN** 上镜以淡出黑场收尾，抽到的末帧接近全黑，而下镜首帧正常
- **THEN** 首帧槽仍写入该末帧并可预览，面板同时提示上镜尾帧接近黑场

#### Scenario: 首帧近黑提示

- **WHEN** 下镜以黑场淡入开头，抽到的首帧接近全黑
- **THEN** 尾帧槽仍写入该首帧并可预览，面板同时提示下镜首帧接近黑场

#### Scenario: 正常帧不提示

- **WHEN** 两侧抽到的帧都不是近黑
- **THEN** 面板不显示近黑提示，抽取结果与提示区状态与改动前一致

#### Scenario: 近黑不拦截生成

- **WHEN** 某一侧边界帧已提示近黑，且其余出片条件齐备
- **THEN** 生成按钮仍可用，提交的正是这两个已提示的帧
