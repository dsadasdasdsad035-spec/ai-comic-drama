# Proposal

## Why

选中画布分镜后，右侧 Inspector 固定 300px，把镜号、台词、表演、配音、口型、两类提示词、参考图、出图、出片提示词、3D 调度和视频生成全部纵向堆在一起，完整面板约 3–4 屏。生成画面/视频是最高频动作，却埋在底部；改完顶部字段要滚回去才能点按钮；上次新增的出片提示词面板又让视频区多出 250–350px。用户很难一眼回答「这一镜现在有什么、下一步该做什么」。

## What Changes

- 把分镜 Inspector 改成四页「镜头驾驶舱」：`画面` / `视频` / `声音` / `更多`。页面按用户意图分组，而不是按数据字段顺序堆叠。
- 顶部固定头部：缩略图、镜号/稳定 ID、媒体状态 chip（画面 / 视频 / 配音 / 提示词）、右上角 `...` 菜单（删除、复制 ID 等危险或低频操作）。
- 底部固定操作栏：随当前 tab 显示主操作（生成画面 / 生成视频 / 生成配音）、预估费用、运行中与取消状态；滚动内容在操作栏上方结束。
- 面板宽度可拖拽，范围 320–520px，默认 360px，双击复位；宽度按浏览器持久化，画布不因拖宽而破版。
- 长区块改为可折叠：镜头参数、表演、3D 调度、参考、高级默认折叠或按需展开；折叠状态持久化。
- 信息重新归位：
  - `画面`：当前画面与候选、画面提示词、画布参考、出图设置、构图标注、生成画面。
  - `视频`：当前视频、运动提示词、出片提示词面板、3D 调度、原生音频、出片设置、挂载视频、生成视频。
  - `声音`：台词/音效、表演、配音、口型。
  - `更多`：镜头 ID/场次、手工参考 URL、3D 上下文入口、孤儿状态等低频项。
- 出片提示词面板保留在 `视频` tab；选中已有画面的镜头时默认进入 `视频` tab，使面板仍然「打开就能看到」；没有画面时默认进入 `画面` tab，头部提示词 chip 可一键切到 `视频`。
- tab 面板保持挂载、仅隐藏非活动页，避免切换 tab 丢失正在编辑的提示词草稿和表单状态；只有活动页的媒体预览播放。
- 去掉重复的「配音超过镜头时长」警告（当前同一句出现两次），每个问题只在对应区块出现一次。
- 明确不做：不改生成、提示词拼装、3D 渲染、数据模型或服务端协议；不做批量 Inspector；不做移动端底部抽屉；不改变素材卡 Inspector。

## Capabilities

### New Capabilities

- `shot-inspector-layout`: 画布分镜 Inspector 的分页结构、固定头部与操作栏、可拖宽、折叠区块、状态 chip、信息归位和键盘/无障碍行为。

### Modified Capabilities

- `shot-video-prompt`: 出片提示词面板从长列表中的一个区块移到 Inspector 的「视频」tab；明确默认 tab 与提示词状态入口，保证不提交请求前仍能看到正文和附件清单。

## Impact

- 前端：`src/Inspector.tsx` 重组为 shell + 四个 tab 内容；`src/theme.css` 增加驾驶舱布局、tab、吸底操作栏、拖拽把手和折叠区样式；可能新增 `src/inspectorLayout.ts` 存放 tab/宽度/折叠持久化与状态 chip 推导的纯函数。
- 数据：不改 `ShotData` / `ProjectShot` / API；只在 `localStorage` 记录面板宽度、当前 tab 和折叠状态。
- 验证：`verify-video-prompt-preview.mjs` 需要先切到 `视频` tab 再断言面板、切到 `画面` tab 操作参考 URL；新增 `verify-shot-inspector.mjs` 覆盖 tab 切换、吸底操作、拖宽持久化、折叠状态、删除入口和草稿保留。
- 文档：README 的 Inspector 使用说明更新为四页结构；不需要部署配置变更。
- 风险：移动控件会改变肌肉记忆，需要保留原有字段和动作、提供状态 chip 跳转；非活动 tab 隐藏但挂载会增加少量 DOM，需避免隐藏媒体继续播放。
