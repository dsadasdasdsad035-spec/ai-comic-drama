# Spec Delta

## ADDED Requirements

### Requirement: Agent 新增或更新素材卡

系统 SHALL 允许 Agent 新增或更新画布素材卡，字段包含标题、类型、地址，以及可选的设定卡标识与所属角色名。同一设定标识或同一「角色 + 表情总图」MUST 视为同一张卡，重复提交 MUST 更新而不是新增。地址 MUST 能在当前项目媒体里解析；解析不到时 MUST 拒绝并说明原因，MUST NOT 写入无法访问的地址。

#### Scenario: 新增图片素材卡

- **WHEN** Agent 提交标题「会议室全景」、类型图片、项目内已存在的图片地址
- **THEN** 画布新增一张素材卡，重开项目后仍在

#### Scenario: 同一设定卡重复提交

- **WHEN** 同一设定标识的素材卡已存在，Agent 再次提交
- **THEN** 该卡被更新，画布不出现第二张同名同来源的卡

#### Scenario: 表情总图重复发布

- **WHEN** 某角色的表情总图素材卡已存在，Agent 再次提交
- **THEN** 仍只有一张该角色的表情总图卡，内容被更新

#### Scenario: 地址无法解析

- **WHEN** 提交的地址不属于当前项目媒体
- **THEN** 工具拒绝并说明原因，画布与项目素材列表都不被修改

#### Scenario: 只写一侧不生效

- **WHEN** 素材卡写入成功
- **THEN** 画布状态与项目素材列表都能看到该卡，不存在只落一侧的情况

### Requirement: Agent 建卡是显式动作

Agent MUST NOT 在生成图片、生成视频或生成表情总图后自动创建素材卡，MUST NOT 自动把生成结果发布到画布。建卡与发布 MUST 由显式调用触发。

#### Scenario: 出首帧后不建卡

- **WHEN** Agent 生成某镜首帧
- **THEN** 画布节点数量不变，不出现新素材卡

#### Scenario: 生成总图后不建卡

- **WHEN** Agent 生成某角色的表情总图
- **THEN** 该总图写入角色数据，画布不新增素材卡

#### Scenario: 用户要求发布

- **WHEN** 用户明确要求把某角色表情总图放到画布
- **THEN** 调用建卡工具后出现一张该角色的表情总图素材卡
