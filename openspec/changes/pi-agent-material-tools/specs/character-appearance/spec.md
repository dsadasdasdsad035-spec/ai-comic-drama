# Spec Delta

## ADDED Requirements

### Requirement: Agent 生成角色三视图

系统 SHALL 允许 Agent 按角色的英文外观锚点生成三视图，生成结果 MUST 写入该角色当前图并进入候选列表首位。指令涉及成本时 MUST 先取得用户确认。生成 MUST NOT 让已完成的表情总图失效。

#### Scenario: 生成三视图

- **WHEN** Agent 对某角色执行生成三视图并完成成本确认
- **THEN** 该角色当前图为新图，候选列表首位为该图

#### Scenario: 表情总图不失效

- **WHEN** 某角色已有可用的表情总图，Agent 重新生成三视图
- **THEN** 表情总图仍可用，不被标记为失效

#### Scenario: 未取得确认

- **WHEN** 用户未确认成本
- **THEN** 不提交生成请求，角色数据不变

### Requirement: Agent 生成角色表情总图

系统 SHALL 允许 Agent 生成 4 列 × 2 行八格表情总图并写回角色。八格坐标、总图结构与身份指纹 MUST 由系统按固定布局与当前外观锚点计算，MUST NOT 采用调用方提供的坐标或指纹。八格裁剪 MUST 逐格执行；单格失败 MUST 保留总图并回报失败格，MUST NOT 伪造该格的裁剪结果。

#### Scenario: 生成并裁剪

- **WHEN** Agent 为某角色生成表情总图且八格裁剪全部成功
- **THEN** 总图可用，八格各自有裁剪结果，表情可用于出图与出片

#### Scenario: 指纹由系统计算

- **WHEN** 调用方随请求提供了自定义指纹或坐标
- **THEN** 系统忽略这些值，按当前外观锚点与固定布局写入

#### Scenario: 锚点已变

- **WHEN** 角色外观锚点在生成后被修改
- **THEN** 该总图被标记为失效，不再作为参考使用

#### Scenario: 单格裁剪失败

- **WHEN** 八格中有一格裁剪失败
- **THEN** 总图被保留，失败格没有裁剪结果，结果里点名该格

### Requirement: Agent 采纳已有媒体为角色外观

系统 SHALL 允许 Agent 把当前项目里已有的图片采纳为某角色的三视图或表情总图，来源记为上传。媒体可以按项目内地址或素材卡标题指定。项目外地址与无法解析的地址 MUST 被拒绝。

#### Scenario: 采纳项目图片

- **WHEN** Agent 把某张项目内图片设为角色三视图
- **THEN** 该角色当前图变为该图片，来源记为上传

#### Scenario: 采纳素材卡图片

- **WHEN** Agent 用素材卡标题指定一张素材卡作为三视图
- **THEN** 系统按标题解析到该素材卡并采纳其图片

#### Scenario: 采纳为表情总图

- **WHEN** Agent 把一张图片设为表情总图
- **THEN** 总图按固定四列两行结构建立，八格裁剪被执行

#### Scenario: 项目外地址

- **WHEN** 提交的地址不属于当前项目
- **THEN** 工具拒绝并说明原因，角色数据不变

#### Scenario: 标题不存在

- **WHEN** 用素材卡标题指定，但当前项目没有该标题的卡
- **THEN** 工具返回错误并列出可用标题，不写入

### Requirement: Agent 写角色外观立即落库

Agent 写入角色图片类字段后 MUST 立即持久化，MUST NOT 依赖延迟写回。关闭或刷新页面后再次打开，变更 MUST 仍在。

#### Scenario: 立即持久化

- **WHEN** Agent 采纳一张图片为三视图后立即刷新页面
- **THEN** 该角色当前图仍是新图

#### Scenario: 写入失败

- **WHEN** 持久化请求失败
- **THEN** 工具返回失败并说明原因，界面提示保存失败
