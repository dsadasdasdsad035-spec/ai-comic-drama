# Spec Delta

## MODIFIED Requirements

### Requirement: 验收测试必须覆盖聊天轨迹渲染

UI 验收 SHALL 覆盖 assistant 文本、工具调用状态、代码摘要、关键帧缩略图、关键帧验收清单，以及 finish 后的 MP4 渲染进度、MP4 播放器和 MP4 帧验收卡片；mock 测试 MUST 验证这些 parts 的出现顺序和状态更新，真实模型验收 MUST 确认 MP4 与视频验收文字一致，而不只是检查关键帧。

#### Scenario: mock 轨迹

- **WHEN** 运行 mock agent 验收
- **THEN** 页面出现上下文、代码、沙箱、抓帧、关键帧验收、结束、MP4 渲染和 MP4 帧验收步骤

#### Scenario: 真实模型轨迹

- **WHEN** 使用真实模型运行山/男女/双剑/环绕场景
- **THEN** 可以看到最终 MP4、MP4 帧证据和与 MP4 对应的验收结论

#### Scenario: 取消

- **WHEN** 在 mock 运行中点击取消
- **THEN** 取消状态可见，后续步骤不出现；视频阶段取消时旧视频保持不变

## ADDED Requirements

### Requirement: finish 后视频验收必须结构化展示

finish 后聊天 SHALL 显示独立视频验收卡，包含渲染进度、MP4 播放器、从 MP4 抽取的帧及时间点、逐项结果和帧来源。卡片 MUST 明确这些帧来自最终 MP4，不是沙箱关键帧。

#### Scenario: 渲染进度

- **WHEN** finish 后开始渲染 MP4
- **THEN** 卡片依次显示渲染、抽帧和视觉验收状态，而不是等全部结束才出现

#### Scenario: 播放器与帧证据

- **WHEN** MP4 已生成
- **THEN** 聊天展示可播放的 MP4，并展示同一 MP4 的帧缩略图和时间点

#### Scenario: 视频验收通过

- **WHEN** 所有 MP4 帧验收项通过
- **THEN** 卡片显示逐项通过、帧证据和已保存状态

#### Scenario: 视频验收未通过

- **WHEN** 至少一项未通过
- **THEN** 卡片显示失败项、对应帧和原因，不显示场景完成

#### Scenario: 没有视觉模型

- **WHEN** 当前没有可用视觉模型
- **THEN** 卡片显示 MP4 预览和需人工验收，不伪装为自动通过

### Requirement: 最终完成状态必须区分代码与视频阶段

聊天 MUST 在 finish 时只显示代码阶段完成，MUST NOT 提前显示场景完成。最终完成或未完成状态 MUST 由 MP4 视频验收决定，并明确视频是否已保存。

#### Scenario: finish 时

- **WHEN** agent 调用 finish
- **THEN** 聊天显示代码阶段完成，并开始视频验收，不显示场景完成

#### Scenario: 视频通过

- **WHEN** MP4 帧验收通过且保存成功
- **THEN** 聊天显示视频验收通过和已保存

#### Scenario: 视频未通过

- **WHEN** MP4 帧验收未通过
- **THEN** 聊天显示视频验收未通过，不显示场景完成

#### Scenario: 需人工验收

- **WHEN** 无视觉模型或无法自动抽帧
- **THEN** 聊天显示需人工验收，不显示自动通过

### Requirement: 旧视频和旧验收在代码变化后必须失效

代码哈希、参考上下文、时长或画幅变化后，聊天视频卡和验收卡 SHALL 标记旧结果过期，MUST NOT 把旧 MP4 或旧 review 当作当前代码的验收结果。画布出片入口 MUST 避免在工作台存在未保存草稿时静默渲染旧代码。

#### Scenario: 代码变化

- **WHEN** 聊天提交了新代码或用户修改了草稿
- **THEN** 旧视频和旧验收标记过期，新验收必须针对新代码重新执行

#### Scenario: 未保存草稿时画布出片

- **WHEN** 工作台有未保存代码，用户从画布触发 3D 出片
- **THEN** 系统提示先保存或在编辑器渲染，不使用旧已保存代码静默出片

#### Scenario: 新视频恢复

- **WHEN** 当前代码完成新的 MP4 渲染和验收
- **THEN** 过期标记消失，聊天和节点使用新的 `codeHash`/`videoUrl`

### Requirement: 视频阶段失败和取消必须可恢复

视频渲染失败、MP4 抽帧失败、视频验收未通过或取消时，聊天 MUST 显示阶段和原因，保留代码草稿与旧视频，并提供重试、继续修复或人工采用入口；MUST NOT 清空已有聊天轨迹。

#### Scenario: 渲染失败

- **WHEN** MP4 渲染或转码失败
- **THEN** 聊天显示渲染失败原因，旧视频保持不变，代码草稿仍可继续修复

#### Scenario: 视频验收未通过

- **WHEN** MP4 帧验收存在失败项
- **THEN** 聊天显示失败项和继续修复入口，不自动重跑整轮 agent

#### Scenario: 视频阶段取消

- **WHEN** 用户取消视频阶段
- **THEN** 渲染中止，聊天进入已取消状态，旧视频和草稿保留

#### Scenario: 重试

- **WHEN** 用户选择重试或继续修复
- **THEN** 可以从当前代码重新渲染视频验收，已有轨迹和旧视频不被清空
