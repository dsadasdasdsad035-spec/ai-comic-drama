# Spec Delta

## MODIFIED Requirements

### Requirement: 音频素材的使用边界

音频素材 MUST 作为可预览、可选中的项目素材保存。连到出片镜时，它 MUST 只能作为单条音频参考提交，MUST NOT 进入该镜的图片参考或视频参考，MUST NOT 变成时间线上单独的一条音轨。界面 MUST NOT 再把音频标注为完全不参与出片。

#### Scenario: 音频卡连线到镜头

- **WHEN** 用户把已有地址的音频素材卡连到出片镜并出片
- **THEN** 该地址作为单条音频参考提交，不进入图片或视频参考

#### Scenario: 图片生成请求

- **WHEN** 图片素材卡挂着音频素材并出图
- **THEN** 出图请求的参考图不包含该音频

#### Scenario: 音频入库与预览

- **WHEN** 用户导入一条音频
- **THEN** 它出现在素材库里并可播放预览

#### Scenario: 不单独进入成片音轨

- **WHEN** 用户只把音频素材卡连到出片镜
- **THEN** 系统不因此在时间线上增加一条独立音轨
