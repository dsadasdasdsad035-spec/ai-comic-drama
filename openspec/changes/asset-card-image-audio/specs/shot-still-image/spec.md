# Spec Delta

## ADDED Requirements

### Requirement: 镜头不提供静帧主生成

系统 MUST NOT 对分镜提供静帧主生成。镜头上的静帧预览 MUST 只作为该镜的画面或出片参考，MUST NOT 因此出现生成画面主操作。

#### Scenario: 出片镜有静帧也不能出图

- **WHEN** 出片镜上留有静帧预览，用户查看该镜
- **THEN** 可以看到这张图，但没有生成画面主操作，系统也不提交静帧生成

#### Scenario: 请求镜头出图被拒绝

- **WHEN** 用户对任意镜头请求生成画面
- **THEN** 系统不发起静帧生成

## REMOVED Requirements

### Requirement: 出图产物落入项目媒体

**Reason**: 静帧主生成从镜头移到图片素材卡。项目媒体仍接收素材卡的生成结果，但不再由镜头出图写入。

**Migration**: 使用图片素材卡出图。成功后的地址写在该素材卡上，并进入项目媒体。

### Requirement: 出图不自动成为画布素材或连线

**Reason**: 出图的主体改为图片素材卡本身，不再存在「镜头出图后不得变成素材卡」这条约束。

**Migration**: 图片素材卡生成成功后写回本卡地址，不另建卡，也不自动连到出片镜。

### Requirement: 镜上预览字段保留

**Reason**: 镜头不再有静帧产线。镜上留下的静帧只是出片镜的画面，不能再次作为镜头出图的输入工位。

**Migration**: 需要迭代出图时使用图片素材卡。出片镜上的既有静帧继续可作为该镜的画面预览或出片参考。
