# Spec Delta

## Purpose

让画布上的图片素材卡和音频素材卡按提示词生成文件，并把结果当作可连线的参考，而不占用分镜镜号。

## ADDED Requirements

### Requirement: 可新建无镜号的图片与音频素材卡

系统 MUST 允许在画布上新建图片素材卡和音频素材卡。这两类卡 MUST NOT 分配镜号，MUST NOT 计入当前集镜数或总时长。

#### Scenario: 新建图片卡

- **WHEN** 用户在画布新建一张用于出图的素材卡
- **THEN** 画布出现图片素材卡，当前集镜数不变

#### Scenario: 新建音频卡

- **WHEN** 用户在画布新建一张用于生成音频的素材卡
- **THEN** 画布出现音频素材卡，且该卡没有镜号

### Requirement: 空提示词不能生成

图片或音频素材卡的提示词为空时，系统 MUST NOT 提交生成，并提示先填写提示词。

#### Scenario: 图片卡没有提示词

- **WHEN** 用户对提示词为空的图片素材卡请求出图
- **THEN** 系统不提交出图，并提示先填写提示词

#### Scenario: 音频卡没有提示词

- **WHEN** 用户对提示词为空的音频素材卡请求生成
- **THEN** 系统不提交生成，并提示先填写提示词

### Requirement: 生成结果写回本卡

图片或音频生成成功时，系统 MUST 把文件保存到当前项目媒体，并把地址写回发起生成的那张素材卡。系统 MUST NOT 为此另建一张卡，MUST NOT 分配镜号。

#### Scenario: 出图写回原卡

- **WHEN** 图片素材卡出图成功
- **THEN** 该卡地址变为项目内的图片文件，画布素材卡数量不因此增加

#### Scenario: 音频写回原卡

- **WHEN** 音频素材卡生成成功
- **THEN** 该卡地址变为项目内的音频文件，且可以播放

### Requirement: 只写提示词也能出图

未连入任何参考时，图片素材卡 MUST 只按提示词出图。

#### Scenario: 无参考出图

- **WHEN** 用户在没有参考连线的图片素材卡上填写提示词并出图
- **THEN** 系统提交该提示词，且请求不包含参考图

### Requirement: 图片卡接受参考连线

用户 MUST 能把角色、场景、道具或其他图片素材连到图片素材卡。出图时这些连线 MUST 作为参考图提交。系统 MUST NOT 把相邻镜头当作该卡的参考，也 MUST NOT 把这些连线只记在某条镜头上才生效。

#### Scenario: 连入参考图后出图

- **WHEN** 用户把一张图片素材连到图片素材卡上并出图
- **THEN** 出图请求包含这张参考图和该卡提示词

#### Scenario: 相邻镜头不自动成为参考

- **WHEN** 图片素材卡旁边有出片镜，但用户没有把画面连到这张卡
- **THEN** 出图请求不包含该出片镜的画面

### Requirement: 提示词与参考随项目保存

图片与音频素材卡的提示词 MUST 写入项目素材，并在重新打开项目后保留。图片素材卡的参考连线 MUST 同样保留。

#### Scenario: 重开后提示词还在

- **WHEN** 用户为素材卡写下提示词，保存并重新打开项目
- **THEN** 该卡仍显示原来的提示词

#### Scenario: 重开后参考连线还在

- **WHEN** 用户把参考图连到图片素材卡，保存并重新打开项目
- **THEN** 该连线仍指向这张图片素材卡

### Requirement: 音频卡只按提示词生成

音频素材卡生成 MUST 只提交该卡提示词。系统 MUST NOT 在这张卡上提供旁白与音乐两种模式。连入其他媒体 MUST NOT 改变这次音频请求的内容。

#### Scenario: 同一张卡生成语音或音乐

- **WHEN** 用户在音频素材卡上填写提示词并选择一个已接入的音频模型
- **THEN** 系统用该提示词提交生成，且界面没有旁白或音乐的模式开关

#### Scenario: 连入媒体不进入音频请求

- **WHEN** 音频素材卡上连有其他素材，用户仍用提示词生成
- **THEN** 请求内容只有该提示词，不包含连入的媒体

### Requirement: 未接入的音频模型不能提交

用户选择当前未接入的音频模型时，系统 MUST NOT 提交生成，并说明该模型尚未接入。

#### Scenario: 选择未接入的音乐模型

- **WHEN** 用户在音频素材卡上选择目录中标记为未接入的音乐模型并请求生成
- **THEN** 系统不提交请求，并说明该模型尚未接入

### Requirement: 生成文件可连到出片镜

图片素材卡 MUST 能连到出片镜并作为图片参考。音频素材卡 MUST 能连到出片镜并作为单条音频参考。该音频 MUST NOT 进入该镜的图片或视频参考。

#### Scenario: 图片卡给出片镜当参考

- **WHEN** 用户把已有地址的图片素材卡连到出片镜并出片
- **THEN** 出片请求的图片参考包含这张卡的地址

#### Scenario: 音频卡给出片镜当音频参考

- **WHEN** 用户把已有地址的音频素材卡连到出片镜并出片
- **THEN** 出片请求把该地址作为单条音频参考，且不把它放入图片或视频参考

### Requirement: 标明生图的镜头迁成图片素材卡

打开项目时，系统 MUST 把 `prod_kind` 明确为 `image` 的镜头从分镜序列中移除，并写成一张图片素材卡。迁移 MUST 只执行一次并写回项目。未写明 `prod_kind` 的镜头 MUST 留在序列中。

#### Scenario: 标明生图的镜头离开序列

- **WHEN** 用户打开含有 `prod_kind` 为 `image` 的镜头的项目
- **THEN** 该镜头不再出现在分镜序列，画布上改为对应的图片素材卡

#### Scenario: 只有静帧的旧镜头留下

- **WHEN** 镜头没有写明 `prod_kind`，但带有静帧且没有成片
- **THEN** 该镜头仍留在序列中，不变成素材卡

#### Scenario: 再次打开不重复迁移

- **WHEN** 迁移已经写回项目，用户再次打开
- **THEN** 已经迁出的镜头不会再次变成新的素材卡

### Requirement: 迁移带走提示词预览与参考

迁出的图片素材卡 MUST 保存原镜头的画面提示词和当前预览图。原来连到该镜头、且属于角色或图片素材的参考 MUST 改连到这张素材卡。

#### Scenario: 预览图成为卡地址

- **WHEN** 被迁出的镜头有当前预览图
- **THEN** 新图片素材卡的地址是这张预览图

#### Scenario: 原参考改连到素材卡

- **WHEN** 被迁出的镜头连有角色或图片素材
- **THEN** 这些参考改为连到新的图片素材卡，而不是连到已删除的镜头

### Requirement: 迁移把台词写入备注

被迁出镜头上的台词 MUST 写入新素材卡的备注。其余候选图、时长和运镜 MUST NOT 写入该素材卡。

#### Scenario: 台词进入备注

- **WHEN** 被迁出的镜头含有台词
- **THEN** 新素材卡的备注包含这段台词，序列中不再有该镜头

#### Scenario: 候选图不带走

- **WHEN** 被迁出的镜头除当前预览外还有其他候选图
- **THEN** 新素材卡只使用当前预览图，不保留其余候选

### Requirement: 迁出后镜号不重排

留下的出片镜 MUST 保持原镜号。系统 MUST NOT 为填补被迁出镜头的空号而重排镜号。

#### Scenario: 中间镜被迁出

- **WHEN** 同一集中 S02 被迁出，S01 与 S03 留下
- **THEN** S01 与 S03 的镜号不变

### Requirement: 迁出后接缝清除且不自动连线

指向被迁出镜头的接缝 MUST 清除。相邻留下的出片镜按序列直接相接。新素材卡 MUST NOT 自动连到这些出片镜。

#### Scenario: 原接缝被清除

- **WHEN** 上一镜的接缝指向被迁出的生图镜头
- **THEN** 该接缝被清除，上一镜与下一张留下的出片镜直接相接

#### Scenario: 新卡不自动连到出片镜

- **WHEN** 迁移完成
- **THEN** 新图片素材卡没有自动连到相邻出片镜
