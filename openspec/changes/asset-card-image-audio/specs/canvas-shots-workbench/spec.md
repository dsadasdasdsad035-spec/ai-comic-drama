# Spec Delta

## MODIFIED Requirements

### Requirement: 空白首帧不阻止水合画布

系统 MUST 允许 `keyframe_prompt` 为空的镜头水合到画布并显示为节点。空首帧 MUST NOT 阻止镜头进入画布，MUST NOT 因此跳过该镜或断开序列连线，MUST NOT 因此在镜头上提供出图。出片能否提交由出片提示词规则决定。

#### Scenario: 只有结构的导入

- **WHEN** 导入文件只有镜号与画面描述、没有首帧提示词
- **THEN** 该集全部镜头出现在画布上并保持顺序连线

#### Scenario: 出图仍然拦截

- **WHEN** 用户对首帧提示词为空的镜头请求出图
- **THEN** 系统不在该镜头上提交静帧生成

### Requirement: 画布增删插为正式镜头

画布 SHALL 提供新增镜头、在某镜之后插入与删除镜头。新增与插入 MUST 生成带集内唯一镜号的正式出片镜头并写入项目，MUST NOT 只建无业务 ID 的临时卡，MUST NOT 要求用户选择生图或出片。删除 MUST 先确认，确认后移除该项目镜头、画布节点与其连线，并清除指向它的 `transition_out`。

#### Scenario: 新增镜头

- **WHEN** 用户在画布新增镜头
- **THEN** 项目出现新的出片镜头，画布出现对应卡片并接在序列中

#### Scenario: 在中间插入

- **WHEN** 用户从某一镜插入新镜
- **THEN** 新镜紧跟在所选镜之后，镜号在集内唯一，且是出片镜头

#### Scenario: 删除带转场的镜头

- **WHEN** 用户删除一镜且上一镜配置了指向它的转场
- **THEN** 该镜从项目与画布移除，上一镜的 `transition_out` 被清除

#### Scenario: 镜号冲突

- **WHEN** 新增或改动的镜号与集内已有镜号重复
- **THEN** 写入被阻止并指出冲突的镜号

### Requirement: 画布不以全局模式决定单镜能力

系统 MUST NOT 使用画布级开关把镜头改成生图，或同时隐藏所有镜头的出片能力。若 UI 仍提供筛选控件，该控件 MUST 只影响展示，MUST NOT 改写镜头工位。

#### Scenario: 无全局 Tab 锁

- **WHEN** 用户选中序列中的镜头
- **THEN** 看到的是出片能力，无需切换顶栏的出图或出片模式

#### Scenario: 筛选不改数据

- **WHEN** 用户用筛选隐藏部分镜头后再取消筛选
- **THEN** 镜头工位与隐藏前一致

### Requirement: 顺序边按两端工位决定虚实

画布上相邻分镜之间的顺序边（硬切、转场、闪回、分支，不含角色或素材参考边）MUST 绘制为实线。系统 MUST NOT 再因为生图工位把顺序边画成虚线。关系的语义 MUST 仍通过颜色或其他非虚线样式区分。

#### Scenario: 出片链硬切实线

- **WHEN** 两镜以硬切相连
- **THEN** 连线为实线

#### Scenario: 出片链转场实线

- **WHEN** 两镜以转场相连
- **THEN** 连线为实线，不因转场关系单独使用虚线

#### Scenario: 含生图镜则虚线

- **WHEN** 项目加载并完成迁移后，序列中已没有生图镜
- **THEN** 不存在一端为生图镜的顺序边，留下的顺序边为实线

#### Scenario: 双生图镜虚线

- **WHEN** 项目加载并完成迁移后，序列中已没有生图镜
- **THEN** 不存在两端都是生图镜的顺序边
