# Spec Delta

## MODIFIED Requirements

### Requirement: 接缝只在画布编辑

相邻镜之间的接缝 MUST 只通过画布连线与连线菜单打开的接缝设置编辑，读写同一 `transition_out` 字段。系统 MUST NOT 提供表格式接缝行作为编辑入口。关系为转场的连线 MUST 在中点显示接缝摘要，使读者无需打开菜单即可知道这条缝是什么转场。

#### Scenario: 通过连线改接缝

- **WHEN** 用户单击两镜之间的连线并修改过渡效果
- **THEN** 源镜的 `transition_out` 更新，连线中点摘要与接缝设置、时间线显示一致

#### Scenario: 没有表格接缝行

- **WHEN** 用户寻找接缝列表
- **THEN** 系统不提供表格式接缝行，入口为画布连线与接缝设置

#### Scenario: 连线直接显示类型

- **WHEN** 画布上存在一条已配置效果转场的连线
- **THEN** 该连线中点显示效果名与时长，用户无需打开菜单即可辨认

## ADDED Requirements

### Requirement: 连线中点标签只表达接缝类型

画布 SHALL 在关系为转场的连线中点显示标签，内容为效果名与时长；标签 MUST NOT 因悬停、选中或状态变化切换内容，MUST NOT 可点击，MUST NOT 妨碍单击线身打开菜单。关系为硬切、闪回或分支的连线 MUST NOT 显示标签。标签 MUST 随画布缩放保持稳定的可读字号。

#### Scenario: 转场线显示摘要

- **WHEN** 画布上一条连线为转场且配置为「擦除·右 0.6 秒」
- **THEN** 该连线中点显示「擦除 → 0.6s」

#### Scenario: 其他关系无标签

- **WHEN** 画布上的连线关系为硬切、闪回或分支
- **THEN** 该连线不显示任何中点标签

#### Scenario: 标签不抢走点击

- **WHEN** 用户点击转场连线中点标签所在区域
- **THEN** 系统按点击线身处理，打开该连线的关系菜单

#### Scenario: 缩放保持可读

- **WHEN** 用户缩放画布
- **THEN** 标签文字大小保持稳定，不随画布缩放同步放大或缩小
