# Spec Delta

## MODIFIED Requirements

### Requirement: 设置页提供创意环节默认

系统 SHALL 在设置页「生成环节默认」中保留「创意（对话助手）」一行，绑定 `stageModels.creative`。该值 MUST 作为创意会话的模型回退：宿主侧未保存显式选择时使用它；它本身为空时 MUST 回退到「文本 · 常规」默认。界面 MUST 说明该值是回退而非唯一来源。保存后该绑定 MUST 被持久化，重新打开设置页 MUST 仍显示同一模型。

#### Scenario: 配置创意默认

- **WHEN** 用户在设置页为创意环节选择某文本模型并保存，且宿主侧未保存显式选择
- **THEN** 创意会话使用该模型

#### Scenario: 创意默认留空

- **WHEN** 用户未设置创意环节默认
- **THEN** 创意会话回退到「文本 · 常规」默认

#### Scenario: 创意默认保存后仍可见

- **WHEN** 用户为创意环节选择某文本模型并保存，随后重新打开设置页
- **THEN** 该行仍显示所选的同一个模型，不会回到空值

### Requirement: 创意会话模型由宿主设置解析

创意会话的文本模型 SHALL 在宿主设置中选择并持久化，发送下一轮对话前更换 MUST 从下一轮生效。解析顺序 MUST 为宿主显式选择 > 设置页 `stageModels.creative` > 「文本 · 常规」默认。创意视图 MUST NOT 再提供独立的文本模型下拉。解析不到可用模型时 MUST 以可读错误提示去设置页绑定。应用同步模型表时 MUST NOT 覆盖宿主已保存的显式选择；无法判定来源时 MUST 保留仍指向可用模型的现有值。

#### Scenario: 宿主内更换模型

- **WHEN** 操作员在宿主设置中选择另一文本模型并保存
- **THEN** 下一轮对话使用新模型，界面不再出现第二处模型选择入口

#### Scenario: 无可用模型

- **WHEN** 三层解析都得不到可用文本模型
- **THEN** 界面显示可读的未配置说明，发送入口保持禁用

#### Scenario: 模型表变化后保留宿主选择

- **WHEN** 操作员已在宿主设置中选定某模型，之后设置页新增或删除其他模型
- **THEN** 创意会话继续使用操作员选定的模型，不被回退值替换

## ADDED Requirements

### Requirement: 创意会话输出上限来自设置页创意环节

创意会话每轮请求的输出上限 SHALL 取自设置页「创意（对话助手）」的输出上限。该值为空时请求 MUST NOT 携带 `max_tokens`，由渠道默认上限决定；该值存在时 MUST 作为该轮请求的 `max_tokens` 提交。修改该值 MUST 在下一轮对话生效，不要求重启宿主。

#### Scenario: 未设置输出上限

- **WHEN** 设置页创意环节的输出上限留空
- **THEN** 创意会话的请求不携带 `max_tokens`，由渠道默认决定输出长度

#### Scenario: 设置了输出上限

- **WHEN** 设置页创意环节的输出上限为某个正整数
- **THEN** 创意会话的请求携带该值作为 `max_tokens`

#### Scenario: 修改后下一轮生效

- **WHEN** 操作员在运行中修改创意环节的输出上限并保存
- **THEN** 下一轮对话即使用新的上限，宿主无需重启
