# Spec Delta

## MODIFIED Requirements

### Requirement: 固定的两条操作带

系统 SHALL 在所有项目视图上提供最多两条横向上沿：全局带与视图上下文带。全局带 MUST 在所有项目视图中保持相同成分与顺序；创意视图作为非项目视图 MUST 保留导航与全局工具，但 MUST 隐藏项目选择器与集选择器。视图上下文带 MUST 仅在该视图拥有范围、设置或动作时出现。

#### Scenario: 切换视图不重排全局带

- **WHEN** 用户在八个视图之间依次切换
- **THEN** 导航与全局工具的位置和顺序保持不变，项目与集只在项目视图中出现且位置不变

#### Scenario: 创意视图的全局带

- **WHEN** 用户打开创意视图
- **THEN** 全局带保留品牌、导航、密钥告警、任务台账、主题切换与导出，不显示项目选择器与集选择器

#### Scenario: 无视图级内容的视图

- **WHEN** 用户打开画布或设置页
- **THEN** 界面不显示空的上下文带占位

#### Scenario: 上下文带三段位

- **WHEN** 任一视图显示上下文带
- **THEN** 范围、设置、动作三段在带内的相对位置一致，切换视图时不对调
