# Spec Delta

## MODIFIED Requirements

### Requirement: 全站可见的项目选择

系统 SHALL 在顶栏提供全局项目选择器，并在画布、剧本、角色、镜头表、提示词、设置页都显示当前项目或“未选项目”状态；切换项目 MUST 立即更新全局项目上下文。创意视图 MUST NOT 显示项目选择器与集选择器，其会话内容 MUST NOT 因当前项目变化而重载或清空。

#### Scenario: 各视图都能看到项目

- **WHEN** 用户依次打开画布、剧本、角色、镜头表、提示词和设置页
- **THEN** 顶栏始终显示当前项目名或“未选项目”，并提供项目选择入口

#### Scenario: 切换项目更新上下文

- **WHEN** 用户在任意项目视图切换项目
- **THEN** 全局项目名更新，其他项目视图再次打开时使用新项目

#### Scenario: 没有项目

- **WHEN** 系统里没有任何项目
- **THEN** 顶栏显示“未选项目”，项目数据视图进入空/只读状态，不自动创建项目

#### Scenario: 创意视图不参与项目上下文

- **WHEN** 用户打开创意视图或在该视图中切换全局项目
- **THEN** 顶栏不显示项目与集选择器，创意会话的消息、源视频与产物保持不变
