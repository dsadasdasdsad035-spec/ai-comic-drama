# Spec Delta

## Purpose

规定画布上分镜、角色、素材（含表情总图）四类节点的落位与整理规则，使同类型卡片不重叠、不同类型分区清楚，且用户的拖放布局不会在数据变化时被自动打乱。

## ADDED Requirements

### Requirement: 节点按类型分区落位

画布 SHALL 为分镜、角色、素材三类节点各保留互不重叠的纵向区域。MUST NOT 让不同区域的卡片在默认落位时相交。

#### Scenario: 首次打开同时有素材与分镜的项目

- **WHEN** 项目里既有素材卡又有分镜，画布首次水合
- **THEN** 素材卡落在分镜带之外（不插入任何两行分镜之间），分镜与角色卡也不与素材卡重叠

#### Scenario: 运行时新增素材卡

- **WHEN** 用户通过手动添加、设定图发布、在线素材导入或表情总图发布新增素材卡
- **THEN** 新卡落在与首次恢复相同的素材区域内

### Requirement: 同类型新节点不与现有节点重合

新增节点 SHALL 落到第一个可用槽位，其位置 MUST NOT 与同类型已有节点完全重合或明显遮挡。

#### Scenario: 连续手动添加素材卡

- **WHEN** 用户连续三次点「添加素材卡」
- **THEN** 画布上出现三张互不重叠的素材卡，而不是三张叠在同一个点

#### Scenario: 已拖开的卡片不受影响

- **WHEN** 用户把已有的素材卡拖到远处，再添加一张新素材卡
- **THEN** 新卡落在一个不与任何现有卡重叠的位置，被拖开的卡位置不变

### Requirement: 分镜列栅格不因时长差异重叠

分镜的列位置 SHALL 由已占用宽度决定，卡片宽度随时长变化时 MUST NOT 使后一张卡落入前一张卡内部。

#### Scenario: 长镜后接短镜

- **WHEN** 同一集前三个镜头时长均为 8 秒、第四个镜头为 3 秒，且都还没有画布位置
- **THEN** 第四张卡完整落在第三张卡右侧，两者不重叠

#### Scenario: 卡片宽度变化后重新落位

- **WHEN** 某镜时长改变导致卡片变宽，且该镜尚未被用户拖放
- **THEN** 同一行后续卡片的落位按新的宽度重新计算，不产生重叠

### Requirement: 分镜落位顺序由镜号决定

尚未有画布位置的分镜 SHALL 按镜号数值决定栅格顺序。MUST NOT 由项目镜头数组或写回时的提交顺序决定。

#### Scenario: 单镜写回后新增镜头

- **WHEN** 一次单镜写回改变了项目镜头数组的顺序，随后用户新增一个镜号更大的镜头
- **THEN** 新镜头落在按镜号应得的位置，不因写回顺序变化而提前或后移

#### Scenario: 镜号带前导零

- **WHEN** 镜号为 S02 与 S10
- **THEN** 按数值顺序落位（S02 在 S10 之前），不按字符串排序把 S10 排在 S02 前面

### Requirement: 已有节点的位置不被自动改写

画布 SHALL 保留节点已有位置。MUST NOT 在数据刷新、水合、写回或新增其它节点时移动用户摆放过的节点。

#### Scenario: Agent 写回后刷新

- **WHEN** Agent 写回镜头导致画布重新水合，用户此前拖动过分镜卡
- **THEN** 该分镜卡仍在用户放置的位置

#### Scenario: 重复发布素材卡

- **WHEN** 用户重新发布一张已在画布上的设定卡
- **THEN** 对应素材卡更新内容但位置不变

### Requirement: 显式整理画布

画布 SHALL 提供「整理画布」动作，按上述分区与栅格重排当前画布上的所有节点。MUST 只在用户明确触发时执行，MUST NOT 自动重排。

#### Scenario: 用户主动整理

- **WHEN** 用户点击「整理画布」
- **THEN** 分镜、角色、素材按各自区域与栅格重新排列，重叠被消除，且不改变任何镜头或素材的业务数据

#### Scenario: 不点击则不动

- **WHEN** 用户从未点击「整理画布」
- **THEN** 系统不会因加载、写回或新增节点而重排已有卡片

#### Scenario: 整理后仍可手动微调

- **WHEN** 用户在整理之后拖动某张卡片
- **THEN** 该卡片保持在拖放位置，后续整理之外的自动落位不会把它拉回
