# Spec Delta

## REMOVED Requirements

### Requirement: 就绪条展示出片阻塞摘要

**Reason**: 出片镜收敛为单页四槽位后，槽位本身就是就绪状态的可见载体（空槽位不阻止、失效条目在槽位内标注）。吸底主操作已直接显示阻断原因，顶部的只读就绪条是同一信息的第一份重复展示，且其中「出片模式标签」在原生音轨默认开启后恒为同一值。

**Migration**: 阻断与警告信息改由吸底主操作下方的说明行承担（与本次 `shot-outgoing-slots` 的「提示词是唯一必填项」「槽位内容失效时阻止出片」一致）。需要逐条诊断时使用验收脚本与 `buildShotVideoRequest` 返回值，不再有界面聚合条。

### Requirement: 工位徽章与过滤状态 chip

**Reason**: 状态 chip 只做计数与跳转，不参与出片判断。单页四槽位之后已没有可跳转的目标页面，chip 退化为纯装饰。工位徽章本身随头部保留，但不再需要 chip 这一附加层。

**Migration**: 参考数量、成片有无在对应槽位与「成片」区块直接可见；工位徽章（生图镜 / 出片镜）保留在 Inspector 头部。

### Requirement: 音画 Tab 聚合表演与音频

**Reason**: 与本次决策直接冲突。用户要求出片镜只保留参考槽位，台词、表演、字幕、旁白 TTS 在画布上不再有编辑入口，只由 Agent（`submit_shots`）与剧本导入写入；原生音频的开关语义也随之取消（原生音轨默认开启，音频槽位只承载音色参考）。

**Migration**: 台词、表演、投递参数仍存于镜头数据并被字幕生成、音色推断与导出消费，Agent 可通过 `submit_shots` 按镜号增量写入，剧本导入照常落库。需要人工改台词时走创意会话。存量镜头的数据不做迁移，字段原样保留。

### Requirement: 无模板渲染过期提示

**Reason**: 该要求约束的是「面板不得显示模板渲染过期警告」。出片提示词面板改写为槽位面板后，正文只保留三种来源（镜头正文 / 已手改 / 升级前旧版本正文），模板渲染相关的徽章与警告路径已不存在，该要求失去约束对象。

**Migration**: 无需迁移。正文来源徽章由新增的「出片提示词正文来源徽章」继续约束；`video_prompt_rendered` 与 `video_prompt_render_meta` 保留在数据中但不参与任何展示判定。

## MODIFIED Requirements

### Requirement: 出片 Tab 区块顺序

对出片镜，Inspector MUST 只呈现单个 `出片` 页面。页内区块 MUST 按下列顺序自上而下排列：参考槽位（图片、视频、音频、提示词）、生成设置（模型、分辨率、时长、画幅）、成片（预览、保存、发布首尾帧）、吸底主操作。参考槽位 MUST NOT 折叠，其条目在进入页面时 MUST 直接可见。

#### Scenario: 默认看见附件

- **WHEN** 用户首次选中出片镜
- **THEN** 图片、视频、音频、提示词四个槽位无需额外点击即可见（有附件或显式空态）

#### Scenario: 生成设置在槽位之后

- **WHEN** 用户浏览出片镜页面
- **THEN** 模型、分辨率、时长与画幅控件位于四个槽位下方

#### Scenario: 只有出片一页

- **WHEN** 用户选中出片镜
- **THEN** 页面集合不含音画与元数据

## ADDED Requirements

### Requirement: 出片提示词正文来源徽章

出片镜提示词槽位 MUST 以徽章区分正文来源：`正文`（来自该镜 `video_prompt`）、`已手改`（人工编辑过）、`旧版本正文`（升级前保存的手改快照）。系统 MUST NOT 展示 `语义层`、`脚本拼装` 或 `模板渲染` 作为来源徽章。

#### Scenario: 镜头正文

- **WHEN** 正文来自该镜 `video_prompt` 且未手改
- **THEN** 徽章文案为「正文」

#### Scenario: 已手改

- **WHEN** 正文由人工编辑并保存
- **THEN** 徽章文案为「已手改」

#### Scenario: 升级前快照

- **WHEN** 正文来自升级前保存的 `video_prompt_override`
- **THEN** 徽章文案为「旧版本正文」，并提示保存一次即迁移到镜头正文
