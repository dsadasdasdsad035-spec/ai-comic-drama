# Spec Delta

## Purpose

定义画布出片镜 Inspector 的唯一输入形态：图片、视频、音频、提示词四类参考槽位。四槽位是能进入出片请求的全部输入集合，槽位内容可空，正文是唯一必填项。

## ADDED Requirements

### Requirement: 出片镜只有一页四槽位

对 `prodKind === 'video'` 的镜头，Inspector MUST 只呈现单个 `出片` 页面，页内 MUST 按下列顺序自上而下排列：参考槽位（图片、视频、音频、提示词）、生成设置、成片、吸底主操作。Inspector MUST NOT 提供 `音画` 或 `元数据` 页面。

#### Scenario: 出片镜的页面集合

- **WHEN** 用户选中 `prodKind === 'video'` 的镜头
- **THEN** Inspector 可见页面仅为 `出片`，不存在 `音画` 与 `元数据`

#### Scenario: 页内区块顺序

- **WHEN** 用户打开出片镜的 `出片` 页面
- **THEN** 自上而下依次为参考槽位、生成设置、成片、吸底主操作

### Requirement: 四槽位是出片请求的唯一输入集合

出片请求的参考图 MUST 只来自图片槽位，参考视频 MUST 只来自视频槽位，音色参考 MUST 只来自音频槽位，正文 MUST 只来自提示词槽位。系统 MUST NOT 提交任何未在任何槽位中显示为条目的参考。

#### Scenario: 槽位与实际附件一一对应

- **WHEN** 用户点生成视频
- **THEN** 请求中的参考图、参考视频、音色参考与正文分别与该镜四个槽位显示的条目一致

#### Scenario: 隐藏的旧字段不参与

- **WHEN** 镜头仍保存着 `useScheduleVideoRef`、`useScheduleFrames` 或 `scheduleVideo` 等历史字段
- **THEN** 这些字段不产生任何槽位条目，也不进入请求

### Requirement: 图片槽位聚合全部图片来源

图片槽位 MUST 汇总该镜全部可用图片来源：画布连线（角色外观、场景、道具、图片素材、相邻镜、表情单格）、素材选择器选中的图片、以及手工填写的图片地址。槽位 MUST 为每个条目显示来源标签与主体身份（角色名 / 场景名 / 道具名 / 相邻镜号 / 素材标题 / 手工参考）。槽位 MUST NOT 截断张数。

#### Scenario: 多来源共存

- **WHEN** 镜头连了一角色、一场景，并通过手工地址补了一张图
- **THEN** 图片槽位列出三条，各自标注来源与身份，全部随请求提交

#### Scenario: 手工地址的入口

- **WHEN** 用户在图片槽位添加一条手工图片地址
- **THEN** 该地址成为槽位条目并随请求提交，无需切换到其他页面

#### Scenario: 静帧预览不算参考

- **WHEN** 镜头有 `refImage` 但没有任何图片槽位条目
- **THEN** 图片槽位显示为空态，请求不含参考图

### Requirement: 视频槽位聚合全部视频来源

视频槽位 MUST 汇总该镜全部可用视频来源：画布连线的视频素材、镜头语言库选定的运镜参照、素材选择器选中的视频。槽位 MUST NOT 提供第二条视频的提交能力；超出第一条的视频 MUST 在槽位内显式列为被忽略并给出原因。

#### Scenario: 运镜参照进入视频槽位

- **WHEN** 用户在视频槽位选择一条镜头语言库条目并开启作为参考视频
- **THEN** 该运镜视频成为视频槽位条目，请求以 `reference_video` 提交它

#### Scenario: 多条视频只提交第一条

- **WHEN** 视频槽位存在两条及以上视频条目
- **THEN** 只有第一条随请求提交，其余在槽位内显示被忽略原因

### Requirement: 音频槽位可选单条音频

音频槽位 MUST 允许用户选择单条音频作为音色参考，来源包括角色音色样本、素材库音频、画布连线的音频素材与手工填写的地址。音频槽位 MUST NOT 接受第二条音频。未选择音频时请求 MUST NOT 包含 `audio_url`。

#### Scenario: 手选素材库音频

- **WHEN** 用户在音频槽位从素材库选择一条音频并出片
- **THEN** 该音频作为音色参考随请求提交

#### Scenario: 连线音频素材生效

- **WHEN** 镜头连了一个音频素材卡
- **THEN** 该音频出现在音频槽位并随请求提交，不被静默忽略

#### Scenario: 移除音频

- **WHEN** 用户移除音频槽位的条目
- **THEN** 请求不再包含 `audio_url`

### Requirement: 原生音轨默认开启

当当前出片模型声明了原生音频能力时，出片请求 MUST 始终包含 `generate_audio: true`，与槽位内容无关。系统 MUST NOT 因为多说话人、说话人不在角色库、缺少音色样本或样本不合规而关闭原生音轨，也 MUST NOT 为此阻止出片；这些情况只影响是否携带 `audio_url`。

#### Scenario: 有可用音色样本

- **WHEN** 镜头有一个说话人且该角色有合规音色样本
- **THEN** 请求同时包含 `generate_audio: true` 与 `audio_url`

#### Scenario: 无可用的音色样本

- **WHEN** 镜头有多个说话人，或说话人不在角色库，或样本缺失
- **THEN** 请求包含 `generate_audio: true` 且不包含 `audio_url`，声音由模型决定

#### Scenario: 模型无原生音频能力

- **WHEN** 当前出片模型未声明原生音频能力
- **THEN** 请求 MUST NOT 包含 `generate_audio: true`

### Requirement: 提示词是唯一必填项

四类槽位全部为空时，系统 MUST 仅在提示词正文为空时阻止出片。图片槽位与视频槽位皆空而正文非空时，系统 MUST 允许出片并以提示说明画面与声音由模型决定。

#### Scenario: 四槽位中只有提示词

- **WHEN** 图片、视频、音频槽位皆空且提示词正文非空
- **THEN** 生成视频可用，并显示一条无参考提示

#### Scenario: 正文为空

- **WHEN** 提示词正文为空，无论其他槽位是否有内容
- **THEN** 生成视频禁用并显示补写正文的阻止原因

### Requirement: 槽位内容失效时阻止出片

槽位条目引用的媒体已不存在时，系统 MUST 阻止出片并指出失效条目，MUST NOT 提交一个缺少该附件的请求。此规则不适用于空槽位。

#### Scenario: 连线视频被删

- **WHEN** 视频槽位条目指向的视频素材卡已从画布删除
- **THEN** 生成视频禁用并说明该视频素材缺失

#### Scenario: 空槽位不阻止

- **WHEN** 某个槽位完全没有条目
- **THEN** 该空槽位不产生阻止原因
