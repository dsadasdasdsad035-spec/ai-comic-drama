# Spec Delta: canvas-shots-workbench

## ADDED Requirements

### Requirement: 画布集目录以分镜为主并深链剧本

画布集目录屏 SHALL 以进入单集分镜画布为主要动作。每卡 MAY 显示剧本状态徽标（缺剧本 / N 场），点击徽标或「看剧本」 MUST 导航至剧本视图对应集详情，MUST NOT 在画布上打开全屏剧本详情作为主路径。画布集目录 MUST NOT 在工具条提供与剧本视图同等的「导入剧本大纲」主按钮；MAY 提供次要链接「去剧本导入」。

#### Scenario: 看剧本跳转

- **WHEN** 用户在集目录点击某集「看剧本」或剧本徽标
- **THEN** 应用切换到剧本视图并打开该集详情

#### Scenario: 目录无剧本导入主按钮

- **WHEN** 用户处于画布集目录屏
- **THEN** 工具条不出现独立的「导入大纲」主按钮（与分镜「导出全部」并列的那一组剧本导入）

## MODIFIED Requirements

### Requirement: 画布提供分镜导入入口

系统 SHALL 在画布**单集画布**阶段提供「导入」入口，复用分镜文本导入的解析与预览能力，支持上传文件与粘贴文本，支持仅结构、仅提示词、或两者兼有。入口 MUST 在未选择项目时不可用并说明原因，且 MUST NOT 要求先经过模型。集目录屏 MUST NOT 提供分镜导入落库入口。

#### Scenario: 有项目时导入

- **WHEN** 用户在单集画布点击导入并选择一个表格文件
- **THEN** 系统进入解析与预览流程，不要求先保存或先推画布

#### Scenario: 没有项目

- **WHEN** 用户尚未选择项目时查看导入入口
- **THEN** 入口不可用，并提示先选择项目

#### Scenario: 目录屏无分镜导入

- **WHEN** 用户处于集目录屏
- **THEN** 分镜导入入口不可用或引导先选集进入单集画布
