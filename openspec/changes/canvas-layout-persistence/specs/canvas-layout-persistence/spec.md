# Spec Delta

## Purpose

规定画布节点几何与素材卡节点身份的持久化契约：位置随项目保存并跨会话、跨设备恢复，素材卡节点 id 由项目数据确定派生并与参考连线 token 同源，从而让「素材卡 → 分镜」的参考连线在重开项目后仍然成立。

## ADDED Requirements

### Requirement: 画布几何随项目保存

系统 SHALL 把画布上分镜节点与素材卡的位置保存为项目级数据，MUST 在重新打开同一项目时按已保存位置恢复。位置 MUST NOT 只保存在浏览器本地存储，MUST NOT 因浏览器存储被清空、页面 origin 变化或换设备而丢失。

#### Scenario: 重开项目位置不变

- **WHEN** 用户把某张素材卡拖到新位置后关闭并重新打开该项目
- **THEN** 该卡片出现在拖放后的位置，其他卡片位置也保持不变

#### Scenario: 换 origin 后位置不变

- **WHEN** 应用以与上次不同的本地服务端口（不同 origin）重新载入同一项目
- **THEN** 画布节点位置与上次相同，不回到默认栅格

#### Scenario: 没有被保存过位置的节点

- **WHEN** 项目中的镜头或素材卡从未被拖放、也没有历史位置
- **THEN** 仍按既有落位规则放置，不因缺少位置记录而失败或叠在一起

### Requirement: 素材卡节点标识由项目数据派生

每张素材卡 SHALL 在首次落库时获得一个项目级稳定标识，画布节点 id MUST 由该标识确定派生。同一张卡在任意会话、任意设备上 MUST 得到同一个节点 id，MUST NOT 因本地存储状态不同而重新随机生成。

#### Scenario: 重启后参考连线仍在

- **WHEN** 某镜头连着一张素材卡，用户关闭并重新打开应用
- **THEN** 该素材卡节点 id 与之前一致，画布上仍显示这条参考连线

#### Scenario: 与参考 token 同源

- **WHEN** 镜头 `refIds` 中含某素材卡的引用 token
- **THEN** 画布上存在 id 与该 token 逐字相同的素材卡节点（卡片未被删除时）

#### Scenario: 改标题不破坏引用

- **WHEN** 用户把一张已连线的素材卡改标题后重开项目
- **THEN** 该卡节点 id 不变，参考连线仍然成立

### Requirement: 存量本地画布的一次性迁移

系统 SHALL 在首次载入项目、且该项目还没有画布位置数据时，尝试从既有本地画布存档迁移位置与素材卡标识。迁移 MUST NOT 覆盖项目里已有的画布位置数据，MUST 保留旧存档（改名留存，不删除）。

#### Scenario: 旧 uid 被写回项目

- **WHEN** 本地存档里某素材卡节点的位置与标识可用，且能按设定标识或「类型 + 标题」匹配到项目素材卡
- **THEN** 该素材卡的标识与位置写入项目，原先连向它的参考连线仍能解析

#### Scenario: 匹配不到不猜

- **WHEN** 本地存档里的素材卡节点在项目素材库里找不到对应卡片
- **THEN** 不写入任何猜测的标识，该节点与无法解析的参考逐条进入迁移报告

#### Scenario: 重复迁移不覆盖

- **WHEN** 项目已经存在画布位置数据，而本地仍有旧存档
- **THEN** 以项目数据为准，旧存档不生效、也不被删除

### Requirement: 位置只在显式落点后写回

系统 SHALL 只在用户完成拖动、或新增/删除画布卡片之后写回位置。MUST NOT 在拖动过程中逐帧写回，MUST NOT 在按项目数据水合画布时回写位置。

#### Scenario: 拖动中不写

- **WHEN** 用户按住卡片拖动并在中途停下观察
- **THEN** 期间不产生位置写入请求

#### Scenario: 松手后只写变动项

- **WHEN** 用户拖动一张卡片后松手
- **THEN** 只提交这张卡片的位置变动，未移动的卡片不产生写入

#### Scenario: 水合不回写

- **WHEN** 项目数据变化触发画布重新水合，且节点没有用户移动
- **THEN** 不产生位置写回请求

### Requirement: 布局随卡片与项目生命周期清理

卡片或项目被删除时，系统 MUST 同时移除其位置记录，MUST NOT 留下无法回收的孤立布局数据。

#### Scenario: 删除素材卡

- **WHEN** 用户删除一张素材卡
- **THEN** 该卡的位置记录被移除，重新发布同一设定卡时按新卡落位而不是回到旧坐标

#### Scenario: 删除项目

- **WHEN** 用户删除整个项目
- **THEN** 该项目的画布位置数据随项目一并清除，不留残余

### Requirement: 未选择项目时不依赖项目数据

未选择项目（沙盒画布）时，系统 SHALL 继续把画布保存在浏览器本地，MUST NOT 因缺少项目而报错或阻止摆放卡片。

#### Scenario: 沙盒模式摆放

- **WHEN** 用户在没有选择项目的情况下添加并拖动卡片
- **THEN** 操作正常完成，刷新页面后沙盒画布保持原样
