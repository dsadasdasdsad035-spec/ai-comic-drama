# Spec Delta

## ADDED Requirements

### Requirement: 自动流程投递已准备的封面

当目标平台的发布表单支持自定义封面时，自动流程 MUST 在保存草稿前把该平台所需比例的已准备封面上传到平台，MUST NOT 只上传视频与文案而让平台自行截取封面。平台不支持自定义封面、或封面选择步骤尚未在真实登录态下验证时，自动流程 MUST 如实报告封面未上传，MUST NOT 在阶段说明或回执中声称封面已填写。

#### Scenario: 有可用封面

- **WHEN** 自动草稿任务的目标平台需要 9:16 封面且该比例已准备
- **THEN** 任务在上传视频后把该封面投递到平台，平台草稿中的封面为所选封面而非自动截帧

#### Scenario: 平台不支持自定义封面

- **WHEN** 目标平台没有自定义封面入口
- **THEN** 任务说明封面由平台自动生成，不声称已上传封面

#### Scenario: 封面步骤未验证

- **WHEN** 平台的封面选择步骤尚未在真实登录态下验证
- **THEN** 任务如实记录该平台封面未自动投递，发布记录中可看到该结论

#### Scenario: 多平台各自取所需比例

- **WHEN** 一条成片同时提交到分别要求 9:16 与 16:9 封面的两个平台
- **THEN** 每个平台收到自己声明的比例，不互相串用

### Requirement: 适配器阶段声明与实际动作一致

任务阶段与适配器步骤声明 MUST 反映实际执行的动作：只有在确实执行了封面上传或选择步骤时，阶段说明才能出现封面相关表述。

#### Scenario: 阶段说明不夸大

- **WHEN** 自动任务运行到填写元数据的阶段而该阶段只填写标题与简介
- **THEN** 阶段说明只描述实际发生的动作，不使用「填写封面」等未发生的行为
