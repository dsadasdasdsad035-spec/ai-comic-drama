# Spec Delta

## ADDED Requirements

### Requirement: 助手准备的封面必须是可投递的封面

助手为某个比例准备封面时，MUST 产生与用户手动准备封面同形的结果：写入配置的地址能被服务端解析为可读取的文件，并在预检与后续投递中被同样认可。助手 MUST NOT 把仅在当前页面内存中有效的内联图片数据写入配置。

#### Scenario: 助手从成片抽帧

- **WHEN** 用户要求助手「用成片第 30% 的画面当 9:16 封面」
- **THEN** 该比例被标记为已准备，刷新后仍可预览，预检不报告该比例缺失

#### Scenario: 助手不得虚报已准备

- **WHEN** 助手准备的封面地址无法被服务端解析为文件
- **THEN** 助手如实报告该比例未准备好，MUST NOT 在回执中称封面已备好

#### Scenario: 与手动准备一致

- **WHEN** 同一比例分别由助手准备与由用户在封面区准备
- **THEN** 两种结果在配置结构、预检判定与可投递性上一致
