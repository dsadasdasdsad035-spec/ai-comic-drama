# Spec Delta: dsh-tool-bridge

## ADDED Requirements

### Requirement: 工具调用的项目数据不得跨调用陈旧

桥 MUST 在每个工具调用边界重新读取当前已落库的项目数据，MUST NOT 跨调用复用上一次调用取得的项目快照。同一调用内的多次读取 MAY 复用同一份快照，以避免重复请求。写工具 MUST 以本次调用刚取得的项目数据作为合并基准。

#### Scenario: 画布改动后的再次读取

- **WHEN** 用户在同一项目里改镜头或删镜头并已落库，随后专家再次调用 `read_shots`
- **THEN** 返回的是改动后的镜头集合，不包含已删除的镜头，也不包含被覆盖前的旧字段

#### Scenario: 连续两次调用之间落库了改动

- **WHEN** 同一桥、同一项目连续执行两次读工具，且两次调用之间项目数据发生了写入
- **THEN** 第二次调用返回改动后的数据，而不是第一次调用时的快照

#### Scenario: 写工具不以旧快照为基准

- **WHEN** 用户在画布上手工改过某镜，随后调用 `submit_shots` 只提交另一镜的改动
- **THEN** 合并基准是本次调用刚读取的项目数据，用户手工改过的字段不被旧快照覆盖

#### Scenario: 画布实况已进入读工具

- **WHEN** 浏览器已推送当前项目的画布实况，用户在防抖落库前让专家调用 `read_shot_detail`
- **THEN** 该镜字段与画布节点一致，参考连线解析与 `read_shot_video_inputs` 使用同一批节点
