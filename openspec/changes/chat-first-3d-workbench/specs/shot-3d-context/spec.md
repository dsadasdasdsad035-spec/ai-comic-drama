# Spec Delta

## RENAMED Requirements

- FROM: `### Requirement: 默认选择与沿用上一镜`
- TO: `### Requirement: 参考内容手动选择与沿用上一镜`

## MODIFIED Requirements

### Requirement: 参考内容手动选择与沿用上一镜

首次打开没有选择记录的镜头时，系统 MUST NOT 自动选中任何参考内容：媒体（首帧/候选图、角色、场景卡、道具、素材、视频）、镜头文本和场次键都从 0 项开始。用户 MUST 能一键清空、全选当前分类，或沿用同集同场上一镜的选择；沿用 MUST 只复制选择，不复制代码。

#### Scenario: 默认上下文

- **WHEN** 用户首次打开一个已有首帧、角色和场景卡的镜头
- **THEN** 参考内容为 0 项，聊天参考条为空并提示从左侧添加
- **AND** 不因为镜头里存在这些资源就自动勾选

#### Scenario: 沿用上一镜

- **WHEN** 用户点击“沿用上一镜选择”
- **THEN** 当前镜选择变为上一镜的同类资源和新镜头自身文本，代码不变

#### Scenario: 清空

- **WHEN** 用户清空所有参考内容
- **THEN** 生成前提示至少选择一项，不静默使用全项目资源

### Requirement: 选择内容必须真正进入生成和聊天

代码生成和聊天 MUST 只使用当前已选媒体和文本，加上运行所必需的镜头元数据（时长、画幅、镜号）；MUST NOT 静默加入未选角色、素材或全项目图片。聊天输入区 MUST 显示当前已选项，并允许在发送前移除。聊天输入框 MAY 预填镜头文本作为可编辑草稿；预填文本 MUST NOT 自动发送，也不计入参考选择，只有用户发送后才作为用户消息进入对话。

#### Scenario: 只选一张图

- **WHEN** 用户只选择一张分镜生成图并发送聊天
- **THEN** 聊天上下文只包含该图和必要镜头元数据，不包含其他项目图片

#### Scenario: 未选台词

- **WHEN** 用户从输入框删除预填台词后发送
- **THEN** 本轮聊天不会因为台词存在于镜头里就包含该台词

#### Scenario: 预填文本发送

- **WHEN** 用户直接发送预填的镜头文本草稿
- **THEN** 文本作为用户消息进入对话，参考列表仍只列已选媒体

#### Scenario: 聊天前移除

- **WHEN** 用户在聊天输入区移除一个已选素材
- **THEN** 下一条聊天不再包含该素材
