# Spec Delta

## Purpose

在素材视图提供统一的平台链接下载入口，将摄取结果登记为项目内可复用的视频素材，供几何分析与其他素材能力消费。

## ADDED Requirements

### Requirement: 素材页平台链接下载入口

当用户打开素材视图且已选中项目时，系统 SHALL 在主内容区提供可见的「链接下载」（或等价标题）入口，接受 http(s) 平台分享页或视频直链。用户提交后 MUST 调用与项目参考摄取相同的摄取 API 与适配器配置。未选项目时 MUST 禁用或提示先选项目，不发起摄取。

#### Scenario: 素材页提交抖音链

- **WHEN** 用户在素材页粘贴已配置适配器可解析的抖音链接并确认下载
- **THEN** 摄取成功，界面提示成功并刷新可选素材列表

#### Scenario: 无项目

- **WHEN** 用户未打开任何项目却尝试链接下载
- **THEN** 显示明确错误，不写盘

### Requirement: 下载结果登记为视频素材

链接下载或同 API 上传成功的文件 MUST 写入当前项目的媒体目录，并 MUST 在 `project.assets` 中新增或更新一条 **视频** 类型条目（含可读标题与站内 URL）。条目 MUST 出现在素材页的「视频」或等价分类中。摄取 MUST NOT 自动创建画布素材卡，除非用户另行触发发布。

#### Scenario: assets 表有视频行

- **WHEN** 摄取返回站内 `/project-assets/...` URL
- **THEN** 重新加载项目后 `assets` 数组包含 `kind` 为视频（或等价）且 `url` 匹配该站内路径的条目

#### Scenario: 不自动发布画布

- **WHEN** 摄取成功且用户未点发布
- **THEN** 画布节点集合与摄取前一致

### Requirement: 摄取失败可行动提示

适配器未启用、探测失败、超限或非视频响应时，素材页 MUST 展示服务端返回的原因，并 SHOULD 引导用户打开设置中的平台链接下载配置。

#### Scenario: yt-dlp 未配置

- **WHEN** 用户提交需要 yt-dlp 的链接但设置中未启用
- **THEN** 请求失败且文案说明需在设置中配置素材/媒体摄取
