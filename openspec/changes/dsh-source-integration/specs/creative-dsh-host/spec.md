# Spec Delta

## MODIFIED Requirements

### Requirement: 运行时基线满足宿主最低版本

应用运行环境 MUST 满足宿主声明的最低 Node 版本，服务端打包目标与桌面端内置运行时 MUST 与该基线一致。应用启动时 MUST 校验运行时版本，不满足时 MUST 以可读错误阻止启动并指明所需版本。宿主运行时 MUST 来自与本仓库钉定版本一致的自有构建产物；该构建产物缺失时 MUST 阻止创意视图启动并给出可读说明，MUST NOT 阻止应用其它视图启动。

#### Scenario: 版本达标

- **WHEN** 应用在满足最低版本要求的运行时上启动
- **THEN** 启动自检通过，创意入口可用

#### Scenario: 版本过低

- **WHEN** 运行时不满足最低版本要求
- **THEN** 启动以可读错误终止，错误指明当前版本与所需最低版本

#### Scenario: 宿主构建产物缺失

- **WHEN** Node 版本达标但宿主构建产物不存在
- **THEN** 应用启动成功，创意视图给出构建缺失的可读说明，工作台与画布仍可用

#### Scenario: 宿主版本与钉定版本不符

- **WHEN** 实际启动的宿主版本与本仓库钉定的版本不一致
- **THEN** 应用报告版本不一致，创意视图不以该宿主提供服务
