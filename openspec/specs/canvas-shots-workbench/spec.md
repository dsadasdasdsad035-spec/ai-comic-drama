# canvas-shots-workbench Specification

## Purpose
让画布成为分镜序列的唯一工作台：导入与 Agent 写回直接落库并出现在画布上，单镜编辑、集级摘要与镜间接缝都在画布完成，不再维护整张可编辑表格。

## Requirements

### Requirement: 画布是分镜唯一工作台

系统 SHALL 以画布作为分镜的查看与编辑视图，MUST NOT 提供「镜头表」项目视图或等价的全集可编辑表格（含抽屉、只读表、批量字段编辑）。分镜字段的人手编辑 MUST 只在画布单镜面（Inspector、时间尺、转场面板）或 Agent 内进行。

#### Scenario: 顶栏没有镜头表

- **WHEN** 用户查看顶栏的项目视图导航
- **THEN** 导航中不出现「镜头表」，画布仍可打开并编辑当前集分镜

#### Scenario: 没有隐藏的表格

- **WHEN** 用户寻找批量编辑镜号、景别、台词或提示词的界面
- **THEN** 系统只提供单镜编辑面与 Agent，不提供表格或表格替代抽屉

### Requirement: 画布提供分镜导入入口

系统 SHALL 在画布提供「导入」入口，复用分镜文本导入的解析与预览能力，支持上传文件与粘贴文本，支持仅结构、仅提示词、或两者兼有。入口 MUST 在未选择项目时不可用并说明原因，且 MUST NOT 要求先经过模型。

#### Scenario: 有项目时导入

- **WHEN** 用户在画布点击导入并选择一个表格文件
- **THEN** 系统进入解析与预览流程，不要求先保存或先推画布

#### Scenario: 没有项目

- **WHEN** 用户尚未选择项目时查看导入入口
- **THEN** 入口不可用，并提示先选择项目

### Requirement: 导入确认即落库并水合画布

导入确认后，系统 MUST 把结果写入当前项目当前集的镜头数据，MUST NOT 只留在未保存的工作台草稿里；写入成功后 MUST 立即把受影响的当前集镜头水合为画布节点与顺序连线，并定位到新内容。写入 MUST 幂等，重复导入同一文件 MUST NOT 产生重复镜头。

#### Scenario: 确认后立刻可见

- **WHEN** 用户在预览中确认导入
- **THEN** 镜头写入项目，画布立即出现对应卡片与顺序连线，无需再点「生成到画布」

#### Scenario: 写入失败不留半份

- **WHEN** 落库请求失败
- **THEN** 不产生部分写入，画布保持导入前状态，并提示可重试

#### Scenario: 重复导入不翻倍

- **WHEN** 同一份文件连续导入两次
- **THEN** 第二次按镜号更新已有镜头，镜数与画布节点数不翻倍

### Requirement: 空白首帧不阻止水合画布

系统 MUST 允许 `keyframe_prompt` 为空的镜头水合到画布并显示为节点。空首帧 MUST 只阻止出图与出片等生成动作，MUST NOT 阻止镜头进入画布，MUST NOT 因此跳过该镜或断开序列连线。

#### Scenario: 只有结构的导入

- **WHEN** 导入文件只有镜号与画面描述、没有首帧提示词
- **THEN** 该集全部镜头出现在画布上并保持顺序连线

#### Scenario: 出图仍然拦截

- **WHEN** 用户对首帧提示词为空的镜头请求出图
- **THEN** 请求被阻止并提示先填写画面提示词

### Requirement: 画布承载分镜 Agent

系统 SHALL 在画布提供分镜助手的聊天面板，使用 `shotlist` 与 `prompt` 技能，经 `submit_shots`、`submit_prompts` 与 `submit_joins` 写回当前项目当前集。写回后 MUST 与导入走同一套落库与水合规则。线程范围 MUST 仍按项目与集。

#### Scenario: 聊天拆镜

- **WHEN** 用户在画布聊天要求拆本集
- **THEN** 草稿写回项目，画布出现本集镜头与顺序连线

#### Scenario: 只刷提示词

- **WHEN** Agent 只提交提示词更新
- **THEN** 分镜结构与画布节点不变，只更新提示词列

#### Scenario: 切集不串线程

- **WHEN** 用户在画布从一集切到另一集
- **THEN** 聊天上下文与本集镜头一起切换，其他集不被写入

### Requirement: 画布提供集级摘要与目标时长

画布 SHALL 在视图上下文带或画布工具条显示当前集镜数、总时长与目标时长的对比，并提供目标时长编辑。目标时长 MUST 写入该集元数据，与剧本分集信息共用同一字段。

#### Scenario: 超时提示

- **WHEN** 本集总时长超过目标时长
- **THEN** 摘要显示超出的秒数

#### Scenario: 修改目标时长

- **WHEN** 用户修改当前集目标时长
- **THEN** 新值写入该集并立即更新摘要，其他集不受影响

### Requirement: 画布增删插为正式镜头

画布 SHALL 提供新增镜头、在某镜之后插入与删除镜头。新增与插入 MUST 生成带集内唯一镜号的正式镜头并写入项目，MUST NOT 只建无业务 ID 的临时卡。删除 MUST 先确认，确认后移除该项目镜头、画布节点与其连线，并清除指向它的 `transition_out`。

#### Scenario: 新增镜头

- **WHEN** 用户在画布新增镜头
- **THEN** 项目出现新镜头，画布出现对应卡片并接在序列中

#### Scenario: 在中间插入

- **WHEN** 用户从某一镜插入新镜
- **THEN** 新镜紧跟在所选镜之后，镜号在集内唯一

#### Scenario: 删除带转场的镜头

- **WHEN** 用户删除一镜且上一镜配置了指向它的转场
- **THEN** 该镜从项目与画布移除，上一镜的 `transition_out` 被清除

#### Scenario: 镜号冲突

- **WHEN** 新增或改动的镜号与集内已有镜号重复
- **THEN** 写入被阻止并指出冲突的镜号

### Requirement: 接缝只在画布编辑

相邻镜之间的接缝 MUST 只通过画布连线与转场面板编辑，读写同一 `transition_out` 字段。系统 MUST NOT 提供表格式接缝行作为编辑入口。

#### Scenario: 通过连线改接缝

- **WHEN** 用户选中两镜之间的连线并修改过渡效果
- **THEN** 源镜的 `transition_out` 更新，序列摘要与转场面板显示一致

#### Scenario: 没有表格接缝行

- **WHEN** 用户寻找接缝列表
- **THEN** 系统不提供表格式接缝行，入口为画布连线与转场面板

### Requirement: 画布提供批量补齐锚点

画布 SHALL 提供针对当前集的一次性「补齐锚点」动作，把首帧提示词中无法展开的 `{{角色名}}` 替换为角色外观锚点，并把改动字段标记为人改。动作 MUST 只在当前集生效，并回报补齐的镜数。

#### Scenario: 补齐缺锚点镜头

- **WHEN** 当前集有 3 镜的首帧提示词含无法展开的角色占位
- **THEN** 动作补齐这 3 镜并回报补齐数量

#### Scenario: 没有可补内容

- **WHEN** 当前集没有缺锚点镜头，或缺失角色没有外观锚点
- **THEN** 系统不修改任何镜头，并说明原因
