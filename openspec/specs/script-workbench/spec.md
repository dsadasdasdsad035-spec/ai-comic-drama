# script-workbench Specification

## Purpose
定义剧本工作台主区域只承载分集结构化编辑、从零拆集与改稿生成仅经 Agent 聊天的布局与行为契约。

## Requirements

### Requirement: 剧本主区域只展示分集结构

剧本工作台主内容区 SHALL 全宽展示分集、场次与相关编辑控件；MUST NOT 在主区域提供原著全文或 logline 的表单编辑区，MUST NOT 提供「手动加一集」按钮。

#### Scenario: 打开剧本页

- **WHEN** 用户进入剧本视图且项目已加载
- **THEN** 主区域显示分集列表（或空态），不出现左栏原著/logline 编辑区

#### Scenario: 手改分集仍可用

- **WHEN** 用户编辑某集标题、钩子、场次 beats 或新增/删除场次
- **THEN** 变更进入本地草稿并可通过顶栏保存写入项目

### Requirement: 拆集生成入口仅在 Agent

系统 SHALL 在剧本视图上下文带中移除「生成分集 / 重新生成分集」按钮。从零拆集 MUST 通过 Agent 聊天触发：内置动作「生成分集/重新生成分集」，或自由对话经提交工具写入剧本草稿；两条路径 MUST 沿用现有输出契约与合并逻辑。

#### Scenario: 顶栏无拆集按钮

- **WHEN** 用户查看剧本视图上下文带的动作区
- **THEN** 不出现「生成分集」或「重新生成分集」强调或非强调按钮

#### Scenario: 聊天内置拆集

- **WHEN** 用户在 Agent 中点击「生成分集」且项目已绑定、具备可用文本模型与原著输入
- **THEN** 分集草稿写入主区域，回执标明全剧范围与显式保存语义

#### Scenario: 对话改稿

- **WHEN** 用户在 Agent 输入改稿要求且模型调用提交工具返回合法剧本 JSON
- **THEN** 草稿合并进主区域分集列表，与改稿前未涉及集次按既有 merge 规则处理

### Requirement: 空态与提示指向 Agent

剧本主区域在无分集时 SHALL 提示用户打开 Agent 生成或改稿；MUST NOT 指引用户在已移除的左栏粘贴原著或点击已移除的顶栏拆集按钮。

#### Scenario: 无分集空态

- **WHEN** 项目尚无分集且未在运行拆集
- **THEN** 空态文案说明可通过 Agent 生成分集或粘贴故事改稿，不提及左栏或顶栏拆集

### Requirement: 顶栏仍提供拆集参数

剧本视图上下文带的设置段 SHALL 继续提供集数、每集目标时长与环节模型选择；这些值 MUST 作为剧本技能输入供 Agent 内置动作与任务卡使用。

#### Scenario: 调整集数后拆集

- **WHEN** 用户修改顶栏集数后从 Agent 运行「生成分集」
- **THEN** 请求使用更新后的集数参数
