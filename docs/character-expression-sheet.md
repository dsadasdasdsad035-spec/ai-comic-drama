# 角色表情总图

## 一张图，八个情绪

每个角色只维护一张 4 列 × 2 行的表情总图，固定顺序：

`neutral / happy / sad / angry / fearful / disgusted / surprised / calm`

- 生成只请求 **1 张图**，不再默认生成 2 张候选。
- 角色已有三视图时，三视图作为身份参考；没有三视图时只使用 `lookEn`，界面会标注“无身份图参考”。
- 生成成功后才替换旧总图；失败/超时保留旧图和旧裁剪。
- 允许上传自己的 4×2 总图；上传按固定格序映射，不自动识别格子内容。
- 成本按“1 张图”估算；角色卡主按钮旁显示 `¥` 单价。

## 单格裁剪与分镜

总图本身不会进入生成参考。系统按情绪从总图裁出 8 个单格，写入项目媒体目录并缓存：

- 分镜有 `performance[].emotion` 时，优先发送对应单格；
- 没有总图时，旧 `expressions[emotion]` 单图只读回退；
- 总图失效、单格未裁剪或文件缺失时回退文字表演，不阻塞出图；
- 首帧生成仍最多 10 张参考图，超限会列出省略项。

## 画布素材

角色卡「发布表情总图到画布」会创建一张 `expression-sheet` 素材卡：

- 每个角色只有一张卡；重复发布更新图片和标题；
- 角色改名会同步卡标题和归属；
- 删除角色会删除这张卡并清理解除相关引用；
- 右键可以把卡连到分镜，但连线不会把整张总图发给模型；实际参考仍由镜头表演选单格。

## 视频参考预算

视频出片默认 **不带表情参考**；首帧/关键帧承担表情。需要更强约束时，在 Inspector「声音」页显式开启“带说话角色表情参考”。

4 张参考按以下顺序分配：

```text
当前画面 -> 全部入画角色身份图 -> 场景/道具/相邻/手工 -> 可选说话角色单格
```

- 超限时先省略表情，再省略场景/道具；
- 当前画面和身份图不会被静默省略；当前画面 + 身份图超过 4 张时提交前阻止并提示取舍；
- 出片面板在提交前显示开关状态、实际槽位和省略原因，不再只在提交后弹 Toast。

## 角色卡 UI

角色卡首屏是「三视图 / 表情总图 / 音色」三个页签和一张主图，下面是摘要：

- 姓名、定位、年龄、状态、音色、表情完成度；
- 一个状态化主操作：生成三视图 / 生成表情总图 / 发布到画布；
- 身份字段和试音稿收进编辑抽屉，保存/取消明确；
- 8 个表情格至少 44×44，点击只预览，不静默改镜头 `performance`；
- 成本 chip 和选中镜头的参考占用（如 `参考 3/4 · 表情开`）。

## 已知边界

- 不做单格局部重绘；单格不满意时重生成整张或上传替换。
- 不自动把旧逐情绪图迁移成总图，也不删除旧图。
- 总图生成质量依赖当前 view 模型；4×2 格子的分辨率不足时，系统只提示，不会把整图当参考。
- 自动化测试全部使用 mock；真实图片/视频调用按项目付费确认规则执行。
