# 在线素材库

在线素材库让素材环节直接从公开图库检索图片、视频和音频，预览授权信息后下载进当前项目。检索在服务端完成，客户端只提交导入令牌，不接触来源 Key，也不能指定下载地址。

## 来源

| 来源 | 媒体类型 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| Pexels | 图片 / 视频 | 需 Key | 图片取原图，视频取 ≤1080p 的最高清变体 |
| Pixabay | 图片 / 视频 | 需 Key | 检索带 `lang=zh`、`safesearch=true`，中文关键词更友好 |
| Openverse | 图片 / 音频 | 可选 | 匿名可用但额度很低；CC0/PDM 不要求署名，其余 CC 许可要求署名 |

新增来源只需在 `server/stock.mjs` 加一个适配器并在 `server/stock-settings.mjs` 登记默认地址与环境变量，检索、导入与界面都不改。

## 配置

设置页「素材库」分区：

- 每个来源有启用开关、API Key、可选 Base URL。
- Key 只存在本地设置库或环境变量；读取设置时只返回「是否已保存」，不回传原文。保存时留空表示沿用已保存的 Key。
- 环境变量兜底：`PEXELS_API_KEY`、`PIXABAY_API_KEY`、`OPENVERSE_API_KEY`。填了对应环境变量会自动启用该来源，并在设置页标注「来自环境变量」。
- 「检测可用性」会先保存当前配置，再请求一次来源列表所需的最小信息，只读本地配置与一次轻量查询，不做检索。

```bash
# 例：只启用 Pexels
export PEXELS_API_KEY="your-key"
```

## 检索

- 关键词至少 2 个字符，且只在按回车或点「搜索」时请求来源；输入过程中不发请求（来源额度很紧）。
- 相同来源、类型、关键词与分页在 10 分钟内复用缓存，命中时界面标注「来自缓存」。
- 一次只检索一个来源；切换来源或媒体类型会清空当前结果。
- 来源返回 429 或额度不足时显示「来源限流或额度不足，请稍后重试」，不会伪装成空结果。
- 每条结果都有 30 分钟有效的导入令牌；令牌过期后点导入会提示重新检索。

## 导入

导入只接受 `provider + itemId` 派生的令牌与项目名。服务端拿到令牌后重新解析下载地址，并依次校验：

1. 地址必须是 http/https 公网地址，拒绝环回、私网与链路本地地址（复用 `server/ingest.mjs#assertPublicUrl`）。
2. 跟随重定向后的最终地址同样必须是公网。
3. Content-Type 必须在白名单内；`application/octet-stream` 时才退回扩展名判断，声明的其他类型直接拒绝。
4. 流式写入并在超限时中止：图片和音频 30MB，视频 200MB。
5. 超时 120 秒；任何失败都删除 `.part` 临时文件，不写素材卡与来源记录。

文件落在 `projects/<项目>/assets/stock-<来源>-<条目>.<ext>`，同一项目内重复导入直接复用已有文件（界面标「已存在」），文件被删后会重新下载。不同项目各自保存独立文件。

## 入口

- **素材选择器**：Inspector 的「选择素材」新增「在线素材」页签；确认后先下载进项目，再按既有规则写回素材卡与类型（视频自动切视频、音频自动切音频、场景/道具卡换普通图保留原类型）。
- **素材页**：工具栏的「在线素材库」打开同一套浏览界面，导入时可选择落到「普通素材卡 / 场景设定 / 道具设定」。落到场景/道具会生成一张没有英文锚点的设定卡，补锚点后即可生成设定图。

## 授权与署名

每条结果显示作者、来源页面和许可证。需要署名的许可证（例如 CC BY）会在详情区给出可复制的署名文本；Pexels / Pixabay 的许可不要求署名，但作者信息同样留档。

来源信息存在 `stock_imports` 表（按项目 + 来源 + 条目唯一），与素材卡地址关联。画布素材表在同步时会整表替换，所以来源元数据不放进 `assets` 表；素材卡 Inspector 按地址反查并显示来源、作者与许可。

许可证展示不等于合规判断：是否可用、是否需要额外署名，由使用者按来源条款决定。

## 音频边界

音频可以检索、预览、下载和管理，但**本期不参与出片**：

- 不作为镜头参考图或参考视频提交；
- 不进入镜头图片清单与 3D 上下文；
- 不进入成片音轨。

卡片和 Inspector 都会明确标注这一点。BGM/音效轨需要单独设计与时间线 UI。

## 换行与限制

- 结果缩略图懒加载，避免一次性解码整个列表。
- 视频不自动裁剪或转码；超出 Seedance 参考视频时长/体积限制时需自行处理。
- 令牌与检索缓存在进程内存里；服务重启后旧令牌失效，重新检索即可。
- 多实例部署时令牌与缓存不共享，需要改成共享存储。

## 排障

| 现象 | 原因与处理 |
| --- | --- |
| 来源显示「未配置 Key」 | 设置页「素材库」填 Key，或设置对应环境变量后重启 |
| 检索报「来源限流或额度不足」 | 触发来源配额，等一段时间再试；也可切换另一个来源 |
| 导入报「检索结果已过期」 | 令牌超过 30 分钟，重新检索后再导入 |
| 导入报「下载地址不被允许」 | 来源把文件放在内网或本机地址，已被 SSRF 防护拦下 |
| 导入报「下载内容不是图片/视频/音频」 | 来源返回了 HTML 或其他类型，换一个条目 |
| 导入报「文件超过 30MB 上限」 | 图片/音频上限 30MB，视频 200MB |
| 素材卡看不到来源信息 | 只有在线导入的素材才有来源记录；生成图和手工上传不显示该区块 |

## 验收

```bash
node verify-stock-api.mjs   # 来源适配器、缓存/令牌、导入校验、来源记录、设置脱敏、路由
node verify-stock-ui.mjs    # 素材页入口、检索、预览、授权、导入落点、设置分区、窄屏（全部拦截 /api/stock/*）
node verify-media-picker.mjs # 选择器含在线页签与音频预览/类型修正
node verify-skills-unit.mjs  # 媒体类型三态、许可与格式化纯函数
```

三个脚本都不访问真实图库：`verify-stock-api.mjs` 用本地 mock 与注入的 `fetchImpl`，`verify-stock-ui.mjs` 用 `page.route` 拦截 `/api/stock/*`。
