# DCC 预演技能包（Blender bpy · 调度预演尺度）

面向镜头预演（previs），不是绑定/雕刻/灯光农场终稿。与宿主 `build(ctx) / pose(t, mode) / dispose` 配合使用。

## 1. 景别与画幅意识

| 代号 | 含义 | 预演落地 |
|------|------|----------|
| EWS | 大远景 | 环境占 70%+，人成点 |
| WS | 全景 | 人物全身 + 环境关系 |
| FS | 全身 | 头顶到脚，头顶留气 |
| MS | 中景 | 腰/膝上，对话常用 |
| CU | 近景 | 胸上，情绪 |
| ECU | 特写 | 眼/手/道具，慎用 |

画幅：16:9 横向用左右重量平衡；9:16 纵向主体居中偏高，避免脚裁切。

## 2. 机位与运镜语法

- **静态建立**：起幅 1–2 秒稳定，交代方位。
- **推（Dolly In）**：`camera.location` 沿视线向主体插值；加速用 smoothstep，勿线性撞脸。
- **拉（Dolly Out）**：揭示环境，末尾留 10% 余量。
- **环绕（Orbit）**：绕场景兴趣点圆周，`radius`/`height` 随 `t`；`_look_at` 锁住中点（两人对峙取中点，单人取胸部）。
- **摇（Pan）**：原地转 `rotation_euler`，幅度小于 45° 以免眩晕。
- **跟拍（Follow）**：相机与主体同步平移，保持相对偏移恒定。
- **升降（Crane）**：`location.z` 随 `t`；俯视时提高 key 光，避免地面糊成一片。

预演禁忌：一镜内多种运镜杂糅；相机不穿地；主体出画超过 2 秒。

## 3. 三点照明（预演能量级）

- **Key**：主光，Sun 或 Area，与叙事方向一致（窗/火光在画外暗示即可）。
- **Fill**：较弱 Area 或环境色，roughness 略高，填暗部可读。
- **Rim**：背侧弱光，勾勒轮廓，分离主体与背景。

白天室外：Sun energy 3–8，天空用浅蓝 principled 地面。室内：Area 200–800（视场景尺度）。夜景：提高 fill，避免 pure black。

## 4. 色彩与材质（可读性）

- 主体与背景 **明度/色相** 分离；两人用不同 hue（冷/暖）。
- Principled：roughness 0.3–0.7；金属仅小道具；避免全屏高 specular。
- 参考图：`ctx.asset` → `images.load` → Base Color；无图时用高饱和度色块区分角色。

## 5. 场面调度（Blocking）

- **对话**：轴线不越线；双人呈 30°–90°；视线高度差体现权力。
- **打斗**：保持 **剪影可读**；武器用细长几何；位移幅度随 `t` 正弦，留前后景层次。
- **群像**：主角大，配角灰阶简化，避免同色相糊成一团。

## 6. 体块角色（无绑定）

- 头：uv_sphere；躯干：cube/cylinder；四肢：cylinder ± sphere；hair 可加薄 cube。
- capsule 可用则用；否则圆柱替代。
- 武器、道具独立 mesh，颜色对比强。

## 7. 时间与 `pose(t)`

- 所有变换是 `t` 的函数；`t=0` 与 `t=duration` 帧应能讲清叙事（起幅/落幅）。
- 缓动：`u = t/duration`；`smooth = u*u*(3-2*u)` 用于相机与走位。
- 随机仅用于 **固定种子** 装饰（如地面石块旋转），不用 `time` 或墙钟。

## 8. 预演质量标准（交付前自检）

- [ ] 试跑通过：至少一物体，相机 `_look_at` 主体
- [ ] 首尾帧构图不同（有运镜或表演）
- [ ] 主体占画 15–70%
- [ ] 五抓帧中间无全黑/全空
- [ ] 清单项（用户 requirements）在画面中可辨认

## 9. 与宿主边界（技能包不重复 ABI）

- 渲染分辨率/FPS/引擎由宿主；代码不改。
- 入库 MP4 / 项目 sceneCode 仅经 `run_render` → `finish` 链。
- job 内文件与项目隔离；聊天不贴长代码，用 adopt。
